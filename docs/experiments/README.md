# DSPN 实验记录（目录）

唯一的实验记录。每次运行登记一行：编号、配置、结果、对设计的影响、原始数据。
设计文档只引用这里的编号，不复制数字。

- 新运行的原始结果（JSON）放在 [runs/](../../runs)，文件名 `日期-时间_类型.json`，必须在对应分段文件的“原始数据”列里链接；`tools/check_docs.py` 会查漏登记。
- E01–E13 来自 v0.12–v0.14，原始数据未随项目保存，代码在 [legacy/](../../legacy)。
- 不复现 E13（2026-11-19 决定）。
