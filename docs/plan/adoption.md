# 采纳决定与排期

返回 [排期](README.md)。文献条目见 [literature/](../literature/README.md)。

## 文献检索的采纳排期（2026-11-19）

- 下一次训练前（改动小、有量化收益）：快记忆层照搬生产配方——q/k/v 短卷积、通道级衰减门、输出 RMSNorm + sigmoid 门（Kimi Linear、Qwen3-Next）；优化器试 Muon。
- 睡眠（demo 后）：回放用自生成样本 + 按困惑度的间隔重复调度；跨会话写入用“稀疏槽 + 按访问频率选择”（Sparse Memory Finetuning）；先测模型是否饱和；外部对照 SuRe 与 Google 的 Language Models Need Sleep。
- 睡眠接受（demo 后，不用重训）：保留被接受检查点的档案，按之后的睡眠是否持续过关评价（Darwin / Huxley-Gödel Machine）；探针加反事实项与跨会话召回；回放可加模型自己复述的当天内容（SEAL）。
- 工作空间与快记忆（v2，S 档对照）：竞争式 top-k 写入 + 广播门槛并做噪声测试；SRWM 式由快权重自己生成写入键和 β。
- 长期在线学习：可塑性监控（死单元、有效秩、新数据学习速度），下降时 FIRE 式重置；定期测快记忆 / 上下文内学习是否衰减。
- 快记忆规则消融：Kronecker delta、对角预条件、Palimpsa 元可塑性门、写入目标对齐下一字节预测。
- 实现卡（[快记忆](../literature/cards/fast-memory.md)、[睡眠](../literature/cards/sleep.md)）带来的调整：FIRE 不放进睡眠（短睡眠后必回滚），只在离线训练阶段之间用、配新优化器；SuRe 相对现有惊奇优先回放只新增“慢 EMA LoRA”；间隔重复证据弱，只作“均匀 / NLL 优先 / SM-2”三臂对照之一；稀疏记忆微调需加乘积键记忆层，归入 v2 重训；SRWM 无语言建模结果且不能分块并行，排最后；Muon 须按参数名分组（w_beta、w_gam 不进 Muon）；输出门用 sigmoid 不用 Swish。
- 层级与自上而下：小规模先不做（与 E38、E40 及社区复现一致）；规模更大后按“后期引入、不占主干参数”再试。离线训练继续用反向传播，局部规则只用于快记忆。

## 文献调研的采纳决定（2026-11-19）

来源与链接见 [design/basis/7-references.md](../design/basis/7-references.md) 末段“2026-11 文献调研”。标“代理调研所报”的条目未逐篇独立核对，真正依赖时再读原文。

- 阶段 1 第 2 轮：β 取值扩到 (0,2)（负特征值），模块快记忆与中枢都改，单独一组对照。
- 阶段 2 之后：快记忆试按通道擦除门（Gated DeltaNet-2 式），消融。
- 阶段 4：在线参数只放在高层 MLP 偏移与读出，保留冻结副本；偏移加向 0 的权重衰减（MIRAS 式保留正则，即连续版“睡眠下调”，替代阶段 5 第 3 项）；在线阶段混入 10–25% 重放；在线块长作为超参数调。信用分配第二版先用“只算即时导数 + Adam”作零成本基线，再与对角精确痕迹比较。
- 阶段 5：做梦式自蒸馏只作 KL 锚，教师固定为巩固前的慢权重，保留回滚验收。
- demo 之后的候选结构：Nested Learning 式多频率分层（局部 MLP 拆为每拍 / 每块 / 每次睡眠更新的几段）。
- 研究线：层级自发涌现（不手工规定各层职能）。每个训练好的 DSPN 检查点都跑 [tools/analyze_hierarchy.py](../../tools/analyze_hierarchy.py)，与随机初始化（--random）对照，逐层报告门控时间常数中位数与 τ>100 比例、快记忆保持时长、读出权重占比；跨 S/M/L、有无中枢比较，结果登记进实验记录。层级弱时先加压力（更长上下文、长程任务），不直接写死“上层更慢”。下一步候选：块延迟的自上而下预测。设计已有“上层本地预测头预测下层下一拍消息”（作为学习信号，设计第 1、3 节；文本代码尚未实现）；候选把这一预测按块延迟送回下层，下层往上传“消息 − 预测”（预测误差）而非完整消息，构成完整预测编码；块内仍并行（逐拍送回会形成跨层非线性时间循环）。另一较弱版本：只把上一块末顶层状态作为上下文输入下层。对照分化程度、bpc 与长程召回。同层输入暂不做（会引入跨模块非线性时间循环，失去并行训练，见 E13）；跨层直连暂不做（会冲淡层级）。
- demo 之后找回“动态稀疏”（现状：模块内稠密；层间只连正下方 + 四邻居，但文本输入、读出、中枢是全连接；文本模型无换边）。候选，各与稠密版对照：文本模型加少量动态远程入边（沿用流式换边）；稀疏激活（每拍只更新部分模块，类 MoE）；中枢稀疏写入（只让少数模块写，对应记忆分配）。
- 结果判读参考：1–3M 参数字节级模型在 TinyStories 上约 1.0–1.4 bpc（推测，不确定）。

## 第二轮实现卡与架构调研带来的调整（2026-11-19）

出处见 [literature/README.md](../literature/README.md) 的总结论与 cards/。

- 不换模块；先把基线做严（形状扫描、调学习率、3 种子、MQAR 类探针），10M 以下架构差别多在噪声内。
- 层级：HRM/TRM 的收益来自外层反复细化与全程反传，不来自快慢两级；若再试，做“同参数同一网格每字节跑两遍”对加宽，预期放低。
- 睡眠（不用重训，demo 后）：先测模型余量 / 饱和；sleep 返回 KL(早晨‖当前)；探针加换名 / 字节置换 / 答案顺序对照；检查点档案树，只在反复回滚时切换祖先。
- v2 重训候选新增：对角预条件 PDN（吸收 Palimpsa）、Mamba-3 复数旋转；训练目标加延迟提问监督与抗上下文内遗忘（make_chat_data.py 加答案掩码与更多插入对话，训练须跨批次延续状态）。
- 工作空间：先在现有检查点上做噪声测试，有问题再改写入规则。
- 自上而下：下一次试 Full-bandwidth 式顶层输出回送（不占主干，续训后期加入），见 [cards/topdown-data.md](../literature/cards/topdown-data.md)。
- 对话数据（对话微调前，不用重训）：make_chat_data.py 加 TinyChat / TinyDialogues，SODA 降为少数。
