## 15（续）　回响网络 Echo：依据、取舍、验证与风险

正文见 [15-echo.md](15-echo.md)。实验只写编号，数字在 [experiments/](../../experiments/README.md)。

### 15.8　每个决定的依据

| 决定 | 依据 |
|---|---|
| 主干用门控 delta + 少量滑窗注意力（3:1） | 极小规模下门控对角递归不输任何架构，差距多在噪声内；困惑度差主要来自召回（Zoology），局部注意力是最便宜的召回补丁（Griffin、Samba）；生产配方 KDA、Qwen3-Next 均为 3:1（[topics/architectures.md](../../literature/topics/architectures.md)、[topics/fast-memory.md](../../literature/topics/fast-memory.md)）。E28、E32：delta 快记忆在合成召回上有效 |
| 分词用 BPE 而不是字节 | 字节级的正面结果都在 ≥250M；同样文本 BPE 的步数约少 4 倍，直接换训练速度；E38、E40 显示小规模下为字节级加层级都变差，不如把问题绕开 |
| 不做层级 / 动态分块 | H-Net 小规模复现中纯字节胜过空格与动态分块；E38、E40（[topics/hierarchy-topdown.md](../../literature/topics/hierarchy-topdown.md)） |
| 思考回路（权重共享、多遍、深监督） | HRM / TRM 的消融：有效的是同一小网络反复迭代、完整反传穿过迭代、每轮都监督，而不是快慢两级；Looped Transformer、Mixture-of-Recursions 在同参数下推理更好（[topics/architectures.md](../../literature/topics/architectures.md)）。不加参数，正好回应 E38、E40“新层级抢主干参数”的失败 |
| 时间回送后期引入 | Full-bandwidth：后期引入、不占参数，约等于多训 1.5 倍词元（1B 规模）；E38 显示“预测与误差相遇”本身有小益处（[cards/topdown-data.md](../../literature/cards/topdown-data.md) 第 1 张） |
| 稠密权重成年冻结，只改稀疏槽表 | E25、E29：遗忘来自共享权重；Sparse Memory Finetuning 学新事实时的遗忘远小于全量微调与 LoRA；Memory Layers at Scale：加参数不加计算（[cards/sleep.md](../../literature/cards/sleep.md) 第 6 张） |
| 持久头 + 来源门 + 延迟提问训练 | 第 9、13、14 章共识；E18、E23 名字召回失败主要是训练信号问题（第 9 章诊断）；Delayed Supervision、ACL 目标（[cards/memory-workspace.md](../../literature/cards/memory-workspace.md) 第 7、8 张） |
| 自我模型与调质 | 自我建模辅助损失、Phua 的元认知结果；惊奇门控写入（Titans、TRC²，证据弱）；SuRe 惊奇优先回放 |
| 睡眠：转移 + 做梦锚 + 档案 | E31 锚定睡眠是唯一稳定提交的做法；E33、E36、E37：锚老师要用早晨模型、梦不能从白天片段续写；LMs Need Sleep 结构相同；DGM / HGM 档案 |
| 不做全局工作空间 | E34、E35：基础版与完整版都不优于无工作空间，稀疏更新会锁死 |
| 不做纯局部学习的慢权重 | 局部规则或前向梯度与反传有 2 倍以上困惑度差距（[topics/learning-rules.md](../../literature/topics/learning-rules.md)）；局部规则只用在快状态（delta 写入）与槽表选格写入上 |
| 优化器 Muon（矩阵参数）+ AdamW（其余） | Linear Attention Cross-Layer Routing：350M 下 Muon 一贯优于 AdamW |

### 15.10　验证顺序

每步写对照、指标、门槛、不过怎么办。语言指标统一折成每字节比特数（bpb），可与 DSPN 通宵检查点比较。

| 步 | 内容 | 对照 | 门槛 | 不过 |
|---|---|---|---|---|
| V0 环境（约 1 小时） | 装 triton-windows 与 flash-linear-attention；门控 delta 内核与纯 PyTorch 分块对拍；训练 16384 BPE；下载 FineWeb-Edu 与 Cosmopedia 各约 2 GB | — | 对拍误差 < 1e-3；1000 万参数配置实测吞吐 | 内核装不上：用纯 PyTorch 分块，按实测吞吐重算规模 |
| V1 主干（约 3 小时） | 1000 万参数，四组各 40 分钟同墙钟：同参数 Transformer；门控 delta + 滑窗；再加槽表；再加自我模型 | Transformer | 主干 bpb 不差于 Transformer 超过 2%，吞吐 ≥ 其 70%；槽表组 bpb 更低；自我模型组 bpb 不变差，ℓ̂ 与实际损失相关 > 0.5 | 主干差：调形状与学习率再比；槽表无益：去掉，在线写入改用持久头 + 低秩偏移 |
| V2 思考回路（约 2 小时） | 接 V1 最佳检查点续训：单遍 vs 回路（K 随机 1–3）vs 回路 + 时间回送；同算力再加一组“加宽单遍” | 同算力加宽 | 回路组 bpb 或推理探针（多步算术、反事实字母串）优于加宽组；自适应 K 下难词元平均遍数更高 | 无益：只留单遍，思考回路降为研究项 |
| V3 记忆与学习（约 3 小时） | 一次性事实学习：只读一遍，隔 1k / 4k / 16k 词元与跨 SEP 提问；对照“只靠上下文”“低秩偏移在线”“全量微调”“随机选格”；学 30 条新事实后旧语料 bpb 与常识探针 | 低秩偏移、全量微调 | 跨会话答对率高于只靠上下文；旧语料 bpb 上升小于低秩偏移的一半 | 选格写入无效：退回持久头 + 锚定睡眠的低秩偏移 |
| V4 睡眠（约 2 小时） | 连续 3 个昼夜，每天新事实 20 条；关调质、关储备格、关档案的消融 | 不睡 | 睡后持久头清空，白天事实仍答对 ≥ 50%；第 3 天单次学习能力不低于第 1 天 | 转移太慢：睡眠多步或放宽选格数量；仍不行就删掉睡眠，持久头只靠容量 |
| V5 放大 | 通宵 5000 万稠密：A + B 阶段；然后两天档 7500 万 + 对话续训 | 同算力 Transformer（同数据） | bpb 优于或持平；聊天脚本 tools/chat_scripts/memory.txt 的会话内、跨会话、睡后召回均过 | 按 V1–V4 哪一项退化回查 |

测量（与任务指标分开）：每词元遍数分布及与 ℓ̂ 的关系；各层有效时间尺度（E17、E19 的方法）；槽表读取次数分布、储备格启用速度；校准曲线；上下文替换测试的剩余信息量（E19）。

### 15.11　风险（按可能性排序）

1. **思考回路在语言上不值算力**：自回归字符任务上完整 TRM 无可靠收益，语言数据充足时迭代多半只值“同算力加宽”的量。代价：V2 结论可能是“不用”。即使如此，自我模型与槽表仍成立。
2. **槽表在小规模下学不起来或大量死格**：原文规模大两个数量级。V1 会先暴露；退路是持久头 + 低秩偏移（E31 已验证可提交）。
3. **调质信号太噪**：单个词元的 ℓ − ℓ̂ 方差大。对策：按词元滑动平均、按段取均值后再用；V4 有关调质的消融。
4. **持久头跨会话取回换了说法的问题**：只有 C 阶段的记忆对话教过，可能只对模板句式有效。V3 加模板外问法。
5. **工程**：Windows 上 Triton 兼容性；三种并行（分块 delta、滑窗注意力、多遍回路）与跨批带状态叠在一起，代码复杂度上升。每加一个部件都要有逐词元与整段一致的测试。
6. **智力上限**：5000 万到 1 亿参数、几十亿词元，常识与推理仍弱，编造多。这是规模决定的，任何架构在这块卡上都一样；本方案能比的是同条件下记得更牢、学得更快、更知道自己不知道。

失败也有收获：思考回路在小规模语言上值多少；稀疏槽表能否替代低秩偏移做终身学习；自我模型的意外信号作为写入门是否优于学出的门；关键期冻结后靠槽表能走多远。
