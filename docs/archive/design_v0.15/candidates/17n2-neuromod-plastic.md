## 17-N2　神经调质三因子可塑性：边聊边改权重，不用反向传播，学习规则本身是学出来的

### 一段话总述

在一个冻结的现成小对话模型的每一层里，插一小块**可塑突触**（一个小矩阵，属于这个用户，存盘后跨会话保留）。聊天时它按一条**局部规则**每句话都在变：变化量 = “刚才哪些输入和输出一起活跃过”（资格迹）× “现在该不该学、往哪边学”（三种模拟神经调质的信号：意外、不确定、奖惩）。使用时完全不做反向传播，改权重只是几次矩阵加法。规则里的系数、调质信号怎么算，是离线用反向传播**元训练**出来的：把“第一段会话教 → 隔开 → 第二段会话考”整段展开，让梯度告诉我们什么样的规则能让后面的回答变好。这是四套方案里最直接满足“参数在使用中改变”的一套。

### 借鉴的科学原理

- **三因子学习规则 / 资格迹**（Gerstner 等 2018 综述）：突触先记下“前后神经元一起活跃”的痕迹，几秒后调质信号到来才真正改变权重。本项目早期实验已在小任务上验证过：带滞后的痕迹能利用延迟反馈（E09、E11）。
- **神经调质分工**（Doya 2002；Yu 与 Dayan 2005）：多巴胺≈奖励预测误差；去甲肾上腺素≈意料之外的不确定（环境变了，加大学习）；乙酰胆碱≈意料之中的不确定（该多依赖新输入还是旧记忆）。简化：每种调质是一个由小网络算出的标量或每层一个标量，真实大脑里它们有空间分布和受体差异。
- **情绪作为价值信号**（Damasio 的躯体标记假说）：用户下一句话的情绪就是对上一句回答的评价。简化：一个小“价值头”读用户下一句，输出一个标量（谢谢、继续追问 = 正；纠正、重复提问、“不是这个意思”= 负）。
- **活性树突**（Iyer 等 2022）：树突段根据情境向量决定这个神经元现在开不开，不同任务用不同的稀疏子网，互不干扰。
- **级联巩固模型**（Benna 与 Fusi 2016）：每个突触有一串由快到慢的隐藏变量，快变量慢慢渗进慢变量，使记忆容量随时间优雅衰减而不是被覆盖。
- **可微可塑性 / Backpropamine**（Miconi 等 2018、2019）：可塑规则的系数可以用梯度下降学出来，调质信号由网络自己产生。原文在百万参数 LSTM 上做语言建模；本方案把它搬到冻结的预训练模型旁边，是没人验证过的外推。

### 结构与规模

- **基座**：SmolLM2-360M 或 Qwen2.5-0.5B-Instruct，冻结。
- **可塑块**（挂在其中 8 层的 MLP 旁）：`h ← h + U · [g(c) ⊙ ((W + A_快 + A_慢) · Vᵀh)]`
  - V、U：把隐藏状态压到 r=256 维再放回去，慢参数，元训练得到；W：r×r 慢矩阵。
  - **A_快、A_慢**：r×r，属于用户，使用中改变。8 层合计约 100 万个数，几 MB。
  - g(c)：树突门。情境向量 c（最近若干句的滑动平均表示）与每个单元的若干树突段匹配，只让前 20% 的单元通过。
- **调质核**（约 200 万参数）：惊奇（用户话语的平均损失相对其滑动均值的偏差，不用学）；不确定（一个小头预测模型自己下一句的损失）；价值头（读用户下一句的表示，输出奖惩）。
- **更新规则**（每个词元、每层；η、λ、各调质的增益都是元训练出的逐层标量）：
  - 资格迹：`E ← λE + post · preᵀ`（post、pre 是可塑块内 r 维的输出与输入）
  - 误差项：`δ = 目标 − 预测`，在块内局部可得的简化版：用下一词元嵌入经固定投影后的 r 维向量与块当前输出之差（In-Place TTT 的“写入目标对齐下一词元”思路，见本地卡片）
  - `A_快 ← (1−衰减)·A_快 + η_惊奇·NE·(δ · preᵀ) + η_奖惩·DA·E`
  - `A_慢 ← A_慢 + κ·(A_快 − A_慢)`，κ 很小；睡眠时 κ 调大（级联渗透）。
  - 乙酰胆碱信号调节读取时 A_快 的权重：不确定高时多信新写的。
- **显存与吞吐（估算，未实测）**：对话时比基座慢约 15%，多几十 MB。元训练要把梯度穿过两段各 256–512 词元的会话，批 8，显存约 5–6 GB，约 2–3 千词元/秒，一晚约 1 亿词元。

### 学习方式

**离线元训练（一到两晚）**：基座冻结，训 U、V、W、树突段、调质核和规则系数。每条训练样本是一个“小人生”：会话甲（某个合成用户说了些个人事实、用了某个新词、表现出某种风格并对回答给了反馈）→ 清空上下文 → 会话乙（提问、沿用新词、期待同样风格）。A 从零开始，跨会话保留；损失是会话乙里的回答词元，外加会话甲中途的普通下一词元损失。数据来自本地模板记忆对话、SODA、SmolTalk，用规则变换造出风格（简短 / 啰嗦、正式 / 口语、特定称呼）与反馈句。这正是“延迟提问监督”和“学完 B 再考 A”的目标（本地文献 memory-workspace 卡 7、8），只是学到的不是权重里的知识，而是**学习规则**。

**使用时**：只跑上面三行更新，无反传。每句话都改变 A_快；奖惩信号迟一轮到（用户回话后），靠资格迹对上号。会话结束把 A 存盘。

**睡眠（每晚几分钟，可无梯度）**：① 级联渗透：A_快 → A_慢；② 突触稳态缩放（Tononi 与 Cirelli 2014）：A_快 整体乘一个小于 1 的数，腾出白天的写入余量；③ 可选的有梯度版本：用当天日志对 A_慢 做几十步反传微调并过验收门（与项目现有的锚定睡眠同一套接受 / 回滚逻辑）。

**防遗忘**靠四层：基座与读出冻结（E29 显示遗忘主要来自共享读出）；树突门让不同情境写到不同单元；级联慢变量；A 的范数上限。

### 三种自我改进与记忆

| 需求 | 怎么实现 | 怎么测 |
|---|---|---|
| 知识 | 惊奇调制的误差修正写入（上式第一项），事实以“键→值”形式进 A | 教后清空上下文提问；容量曲线：教 N 条后的正确率，N 取 10 到 500 |
| 能力 | 奖惩调制项：被用户肯定的回答方式被加强，被纠正的被削弱；常聊领域的树突子网写得多 | 固定领域题在 0、1、2、4 周后的正确率；无关领域对照 |
| 适应用户 | 同一项，加上用户话语本身的自监督写入（学会预测这个用户） | 对用户下一句的预测损失随会话数下降；风格题命中率 |
| 会话内记忆 | 基座上下文 + A_快 | — |
| 跨会话记忆 | 存盘的 A_快、A_慢 | 重启后提问；隔 1、3、10 个会话 |

### 核心科学假设，为什么可能赢过普通 Transformer

- **H1**：元训练出的局部规则，在“教后清空上下文再考”的任务上，能补回“无记忆”与“事实仍在上下文里”之间一半以上的差距。
- **H2**：加入奖惩调制后，风格 / 偏好适应快于只有自监督写入的规则（同样会话数）。
- **H3**：树突门 + 级联让连续学 5 个情境后的旧情境保持率高于同样大小、无门无级联的可塑块。
- **H4（与项目历史的衔接）**：E29、E31 里“只改低秩不忘但学得少”，是因为更新方向由通用的梯度下降决定；专门为“一次就记住”而元训练的规则，在同样只动小矩阵的条件下能学得更多。

普通 Transformer 的权重在使用中是死的，学习只发生在上下文里，窗口一清就没了；在线微调能改权重，但每步要反传、会遗忘、且不知道什么值得学。这里“值得学什么”由调质信号决定，“怎么学不忘”由元训练直接优化。

### 主观成功概率：35%

理由：机制每一块都有先例（快权重、Backpropamine、活性树突），本项目的合成召回实验也说明 delta 型快记忆有效（E28、E32）。但把它们接到冻结预训练模型上、跨会话保留、并靠元训练泛化到真实用户，没有现成结果；r×r 矩阵装事实的容量有限，长串原文（电话号码之类）大概率记不准；奖惩信号从用户措辞里读，噪声很大。会说话没有风险（基座保证，可塑块零初值），风险全在“学到的规则有没有用”。

### 验证实验（按顺序）

1. **X1 单层规则可行性（3–5 小时）**：SmolLM2-135M 冻结，只在一层加可塑块。任务：合成“教一条事实或一个新词 → 插入无关对话直到超出截断的上下文 → 提问”。五臂：无可塑块；固定系数的赫布规则；元训练规则（本方案）；事实仍在上下文（上界）；在线反传低秩（强基线，同样可改参数量）。指标：答案词元损失与正确率。门槛：本方案补回“无记忆—上界”差距的 50% 以上，且不低于在线反传低秩的 70%。不过：先把写入改成纯 delta（误差修正）形式重试一次；仍不过则放弃用快权重记事实，只保留它做风格适应（低维，容易得多）。
2. **X2 容量与干扰（半天）**：教 N 条事实后的正确率曲线；有无树突门、有无级联的对照（H3）。门槛：100 条时正确率过半。不过：加大 r 或换稀疏读写。
3. **X3 奖惩调制（一晚）**：合成用户有隐藏偏好并按偏好给反馈；有无多巴胺项对照（H2）。门槛：达到同样偏好命中率所需会话数少三成。不过：去掉价值头，适应只靠自监督。
4. **X4 多层完整版元训练（一到两晚）**，再测三种改进与跨会话保持。
5. **X5 真人两周**：每天记录 A 的范数、旧能力探针、用户话预测损失。

### 最可能失败的地方，失败能学到什么

- **元训练出的规则只在合成分布上有效**：真人说话方式不同，规则不触发或乱写。学到：学习规则的泛化比知识的泛化更难，需要多少种“小人生”才够。
- **规则退化成“什么都不写”**：元训练发现不写最安全（与 Strategy Coopetition 所说的上下文学习被挤掉同类）。学到：需要在目标里强制上下文不可见，或给写入项单独的下限。
- **容量不够**：X2 曲线很早崩。学到：稠密小矩阵不适合当事实库，事实应交给稀疏的大表（指向 17-N1 的路线），可塑块只管风格与技能。
- **奖惩信号太噪**：X3 无差别。学到：对话里隐式反馈的信噪比，这是任何“从使用中学”的系统都要知道的数。
