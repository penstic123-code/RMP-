## 15　回响网络 Echo：思考回路 + 海马槽表 + 自我模型（2026-11-20 综合提案，未实施）

来源：综合第 9–14 章、文献目录（[literature/](../../literature/README.md)）与实验记录 E14–E40，按 2026-11-20 用户给的目标设计：训练较快、能对话、有一定智力、有记忆和学习能力；架构大胆，可结合反向传播与新机制，可有涌现、自我表征、自上而下预测。规模按笔记本 8 GB（可用约 7 GB）：通宵约 5000 万稠密参数，两天约 1 亿。语言英文。依据、验证顺序与风险见 [15-echo-plan.md](15-echo-plan.md)。标“推测”的没有直接证据。

### 15.1　一句话

**一个会“想几遍”的皮层（共享核心循环 + 自上而下回送），一张只在少数格子里学习的海马槽表，和一个预测自己会错多少的自我模型；自我模型的“意外”作为全局调质信号，同时决定想几遍、记什么、什么时候改、睡觉时复习什么。**

前五章方案的共识（快记忆、持久记忆、睡眠只改慢东西、按惊讶写入）全部保留；新的是三处：思考回路、成年后只改稀疏槽表（关键期）、一个信号管四件事的“意外经济”。

### 15.2　结构

数据流（每个词元）：

```
词元 → 嵌入 → 前段 P（2 层，独有）
              ↓
        ┌→ 核心 C（4 层：3 层门控 delta + 1 层滑窗注意力，权重共享）─┐
        │        ↑ 回送：上一遍 C 的输出经门控融合（自上而下）       │
        └──────── 想 K 遍（K = 1–3，由自我模型的预测难度决定）←────┘
              ↓
        海马槽表 H（稀疏查表，每词元只读 32 格）
              ↓
        后段 D（2 层，独有）→ 输出（与嵌入共享）
              ↘ 自我模型 S（小头）：预测本词元自己的损失、自己的下一状态
```

| 部件 | 做法 | 尺寸（通宵档 d=640） |
|---|---|---|
| 分词 | 英文 BPE 16384 词元，加 4 个特殊词元：用户、助手、会话边界 SEP、思考 | 嵌入 1050 万，输入输出共享 |
| 门控 delta 层 | Gated DeltaNet / KDA 配方：q/k/v 短卷积、通道级衰减门、q/k 归一化、输出 RMSNorm × sigmoid 门、β∈(0,2)、头维 128（[cards/fast-memory.md](../../literature/cards/fast-memory.md) 第 1 张）；对角预条件（PDN）作可选项 | 每层约 12d² ≈ 490 万 |
| 滑窗注意力层 | 窗口 512 词元，因果，输出门；只在核心里 1 层，每遍都过 | 同上 |
| 思考回路 | 核心 4 层权重共享，循环 K 遍；第 k 遍输入 = 前段输出 + GLU(第 k−1 遍核心输出)，GLU 零初始化 | 回送约 2d² ≈ 80 万 |
| 时间上的自上而下 | 上一词元的后段顶层状态经 GLU 门控后加进本词元前段输入（Full-bandwidth 式，后期引入） | 约 2d² |
| 海马槽表 | 乘积键记忆（Memory Layers）：65536 格，键分两半各 256 个子键，每词元取前 32 格，softmax 加权读值，乘 SiLU 门 | 值 65536 × 640 ≈ 4200 万（只读不算，计算量极小） |
| 自我模型 | 两层小 MLP，读后段顶层状态，输出 ℓ̂（预测本词元的交叉熵）与 ẑ（预测下一词元顶层状态的 64 维投影） | 约 30 万 |

参数：稠密约 5000 万（8 个独有层 3900 万 + 嵌入 1050 万），加槽表 4200 万稀疏参数。等效深度 2 + 4K + 2，K=3 时 16 层。两天档 d=768，稠密约 7500 万。显存：参数加优化器约 1.5 GB，激活按 T=2048、批 8 估计 3–4 GB（推测，按实测调批）。

训练全程沿序列并行：门控 delta 用分块内核（flash-linear-attention，装不上 Windows 版就用纯 PyTorch 分块，项目已有 delta_chunk 可对拍）；滑窗注意力用 PyTorch 自带 SDPA；思考回路是“同一词元多算几层”，不是逐词元串行；时间回送按 Full-bandwidth 的做法，第 2 遍整段并行地读第 1 遍右移一位的顶层输出。

### 15.3　记忆：四种速度，一张表

| 层级 | 是什么 | 多久改 | 谁来改 | 对应大脑 |
|---|---|---|---|---|
| 快状态 | 每个门控 delta 头的矩阵状态 | 每词元 | delta 规则（局部、带纠错的赫布写入），写入强度 β × 调质 | 前额叶工作记忆 |
| 持久头 | 每层 1 个衰减固定为 1 的 delta 头；SEP 处不清空，存盘 | 每词元写，睡眠后缩小 | 同上，只有用户轮次能写（来源门） | 海马短期情景记忆 |
| 海马槽表 | 65536 格稀疏键值表 | 使用时每 256 词元一次；睡眠时 | 只改被本段“异常频繁”读到的前 32 格的值（Sparse Memory Finetuning 的 TF-IDF 选格 × 调质），一步无动量梯度 | 海马—新皮层索引、成年可塑性 |
| 皮层稠密权重 | 前段、核心、后段、嵌入 | 只在发育期（预训练 + 对话续训） | 反向传播 | 关键期后基本定型的皮层 |

**关键期**：发育期结束后稠密权重冻结，终身学习只发生在快状态、持久头和槽表里。依据：E25、E29 显示遗忘主要来自改共享权重；Sparse Memory Finetuning 在学新事实时的遗忘远小于全量微调和 LoRA（[topics/continual-sleep.md](../../literature/topics/continual-sleep.md)）。这比此前方案“睡眠时改低秩偏移”更彻底：稠密权重成年后一个数都不改，遗忘只可能来自槽表里被改的那几十格。

**槽表的元可塑性与储备格**（取自第 12 章萤火）：每格记累计写入量 n_i，写入步长乘 1/(1+n_i/n₀)，常被写、已稳固的格变难改；从未或很少被读到的格是“储备格”，新内容优先落在其中（选格分数加一项 1/(1+读取次数)）。对应突触稳固化与齿状回新生细胞（推测有益，需消融）。

### 15.4　自我模型与“意外经济”

自我模型 S 在每个词元输出两样东西：

- ℓ̂_t：我预计自己在这个词元上会错多少（预测自己的交叉熵）。
- ẑ_t：我预计自己下一刻的顶层状态（低维投影，目标停梯度）。

训练：两项均方误差，权重小（0.01–0.1），目标都停梯度，只额外训这个小头和它读的状态。依据：Premakumar 等的自我建模辅助损失；Phua 显示去掉自我模型后元认知校准消失、对噪声更脆（[topics/cognition-selfimprove.md](../../literature/topics/cognition-selfimprove.md)、[cards/memory-workspace.md](../../literature/cards/memory-workspace.md) 第 5 张）。

由它导出一个全局标量 **调质 m_t = σ(a·(ℓ_t − ℓ̂_t) + b)**，即“比我预料的错得多”。ℓ_t 是读到真实下一个词元后的实际损失，所以 m 只在读入文本（用户的话、训练数据）时存在，自己生成时为 0。一个信号，四个用途：

1. **记什么**：快状态与持久头的写入强度 β ← β·(1 + γ·m_t)；槽表选格分数乘 m_t。预料之中的不写，意外的才写（三因子规则：突触前 × 误差 × 调质）。
2. **想几遍**：推理时用 ℓ̂（预测难度，读入前就有）决定 K：ℓ̂ 低想 1 遍，高想 3 遍。训练时 K 随机取 1–3，各遍都算损失（深监督）；“每个词元想几遍”不手工规定，由自我模型的预测涌现。
3. **何时改**：槽表的在线写入只在一段文本的平均 m 超过门槛时发生，避免把闲聊都写进长期记忆。
4. **睡前复习什么**：白天缓冲按 m 排优先级（SuRe 的惊奇优先回放）。

另外两个用途是自我表征的直接产物：ℓ̂ 高时，聊天里可以说“我不确定”（校准）；ẑ 的预测误差衡量“我的内部状态是否在按预期变化”，作为工作中的不确定度探针，可测、可展示。

### 15.5　睡眠

触发：持久头写满（写入量超过阈值）或用户命令。步骤：

1. **复习**：按 m 优先级从白天缓冲取片段，用早晨的模型带持久头重读，读出“依赖持久头才答对”的位置。
2. **转移**：在这些片段上对槽表做选格写入（同 15.3 规则，多步），让不带持久头的模型也能答对；随后持久头按比例缩小，腾出容量。这就是系统巩固：海马短期痕迹 → 长期索引。
3. **做梦作锚**：早晨模型从换行或 SEP 处自由生成文本（不从白天片段续写，E36、E37 的教训），在梦上加 KL(早晨‖当前)，只约束槽表改动不破坏旧行为。
4. **考试与档案**：反事实探针（换名、打乱选项顺序）+ 白天事实提问 + 旧语料损失；过关才提交，不过就回滚。保留历次被接受的槽表快照组成档案，按之后的睡眠是否持续过关挑选（Darwin / Huxley-Gödel 思路，[cards/sleep-2.md](../../literature/cards/sleep-2.md)）。
5. **自我模型校准**：睡眠后在旧语料上重估 ℓ̂ 的偏差，修正 b。

稠密权重在睡眠里不动，所以睡眠的最坏结果是槽表那几十到几千格变差，可整体回滚。

### 15.6　发育期训练

| 阶段 | 数据 | 做什么 | 时长（两天档） |
|---|---|---|---|
| A 预训练 | FineWeb-Edu + Cosmopedia + 少量 TinyStories | 下一词元 + 自我模型损失；单遍（K=1），无时间回送 | 约 75% |
| B 学会想 | 同上 | 打开思考回路（K 随机 1–3，各遍都算损失，后一遍的损失反传进前一遍）与时间回送；分阶段而非交错（Full-bandwidth 的结论） | 约 25% |
| C 对话与记忆 | SmolTalk、SODA、受限词汇合成对话（TinyChat / TinyDialogues 式）、记忆对话 | 只在助手轮次算损失；记忆对话含延迟提问（事实与提问间插多段无关对话、跨 SEP）与干扰组（先 A 组事实、再 B 组、再问 A，ACL 目标）；按会话顺序喂并跨批带状态 | 约半天 |

C 阶段教的是“怎么记”：持久头的读写方式、β 与来源门都在这里由反向传播学出，用的时候不再求梯度。槽表的在线写入规则不需要元训练（Sparse Memory Finetuning 原文即如此）。

### 15.7　涌现、和大脑的对应

预期会自己长出来、并要测量的东西（测法见 [15-echo-plan.md](15-echo-plan.md)）：

- 每个词元想几遍：由自我模型决定，预期集中在难词元（专名、数字、句首）上。
- 层间时间尺度分化：E17、E19、E24 已在 DSPN 上自发出现，看是否重现。
- 槽表分工：常用知识格与新学内容格分开，储备格被逐步启用。
- 校准：ℓ̂ 与实际损失的相关度，以及“我不确定”是否说在该说的时候。

| 机制 | 大脑里的对应 | 简化之处 |
|---|---|---|
| 思考回路 + 回送 | 皮层的循环处理与自上而下投射 | 只有 1–3 遍，不迭代到收敛 |
| 快状态的 delta 写入 | 突触的快速赫布可塑性，带纠错 | 矩阵状态，不是真实突触 |
| 稀疏槽表 + 选格写入 | 海马索引、稀疏编码、只改少数突触 | 查表是可微的软选择 |
| 关键期冻结 | 发育关键期关闭后的皮层稳定 | 一刀切冻结 |
| 调质 m | 多巴胺 / 去甲肾上腺素的“意外”信号 | 一个标量，没有多种调质 |
| 自我模型 | 元认知、内感受式的自我预测 | 只预测自己的损失和状态 |
| 睡眠转移 + 做梦 | 系统巩固、重放 | 离线批处理，不是真实睡眠节律 |
