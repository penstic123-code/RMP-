## 3　学习策略：三种速度

在线学习只改一小部分参数，大部分知识留在离线训练的慢权重里。这样在线适应快，也不容易冲掉旧规律。

| 速度 | 学什么 | 规则 | 误差来源 |
|---|---|---|---|
| 每拍 | 快记忆 S；中枢状态与注意力窗口 | 门控衰减后 delta 写入；窗口滚动 | 不需要误差 |
| 在线 | 对外读出（文本模式不含 E）；B、G 的在线偏移；MLP 第一层的秩 2 偏移；中枢读路径 W_q、W_o 的秩 2 偏移 | 学习率 × 反馈 × 痕迹，滞后更新 | 本地预测误差为主，读出误差的逐跳反馈为辅 |
| 离线 | 全部慢权重（K、V、Q、P、MLP、本地预测头及 B、G 的基础值；文本模式另含 E、R 和中枢权重） | 截断 BPTT 预训练；睡眠巩固 | 预训练数据与重放池 |

**在线反馈。** 模块 i 的状态反馈 δc_i 由两部分相加。一部分是本地误差：本地预测头权重转置乘本地误差，再经 MLP 在模块内反传到 c。另一部分是 λ 倍的逐层反馈：读出误差从最上层出发，上层模块对自身输入的反馈为 δu = Bᵀ[(1−a)⊙δc] + Gᵀ[a(1−a)⊙(c(t−1) − B·u)⊙δc]，第二项来自门 a 对输入的依赖（v0.14 漏了这一项，v0.15 补上，审阅意见来自 Codex）；δu 再经本模块 P 转置和 MLP 局部导数传给下层。消息在同一拍内传递，所以逐层反馈不再按跳数滞后，v0.13 的时间对齐问题随之消失。λ 起点 0.3，在开发种子上调整。一个模块有多个上层读者时，反馈按读者求和。

**对角精确痕迹。** 对 B 的元素 B_ij，痕迹 e_ij ← a_i·e_ij + (1−a_i)·u_j；对门参数 G_ij，痕迹 f_ij ← a_i·f_ij + a_i(1−a_i)(c_i(t−1) − (B·u)_i)·u_j。更新 ΔB_ij = η·δc_i·e_ij，ΔG_ij = η·δc_i·f_ij。只要 a 和 u 不经本模块状态依赖参数，这对 B、G 是模块内的精确在线梯度；整个在线更新并不是精确梯度。仍是近似的地方：经中枢写路径的反馈被忽略（第 1.2 节）；痕迹取发出预测时的值，而参数在此期间已被更新；以及下面两处：下层参数的改变会经上层 c 的时间累积影响未来的输出，这条跨层的时间影响被忽略；快记忆 S 依赖过去的 c，在线不对写入路径求导，K、V、Q 只在离线阶段训练。所有痕迹随队列弹出的记录滞后递推，导数取发出预测时的值。

**MLP 秩 2 偏移。** 在线阶段 MLP 第一层实际权重为 W₁ + A·Bᵀ，只更新 A 和 B，每模块 2×(24+32) = 112 个数。MLP 没有循环，用队列中发出预测时的激活即可算梯度，不需要痕迹。秩限制了在线漂移的幅度，睡眠巩固时偏移并入 W₁。

**实现现状（online.py 第一版，2026-11-19）。** 为先做出 demo，在线学习暂用工程简化：文本流按 64 字节分块，状态跨块延续，每块对交叉熵反传一次，只用 Adam 更新在线参数。默认只更新各层 MLP 秩 2 偏移与中枢读路径偏移（params='lora'）：共享读出层也在线更新时是遗忘的主要来源（E29）。尚未实现：对角痕迹、逐层反馈、B/G 在线偏移及其衰减、在线方差监测与暂停。重放池只收满 64 字节的段，容量不含元数据；均匀对照用随机优先级实现。睡眠巩固把偏移并入 W₁（精确、无损），再在重放池上微调全部慢权重，同时加 KL 自蒸馏锚（老师 = 并入后、微调前的模型），无锚时微调会破坏旧知识（E29、E31）；验收用 bpc（近期探针不升、旧数据增量 ≤ 0.02），不过即回滚；巩固后直接重置会话，不恢复现场状态。demo 跑通后按设计逐项替换，替换前后做对照。

**防止消息坍缩。** 不接通道的模块以邻居消息为预测目标，而消息本身由可训练的 P 产生；若 P 和本地预测头同时朝“预测邻居消息”的误差下降，最省事的解是让所有消息变成常数，误差归零而网络什么也没学到。离线阶段因此作两条规定：消息目标取 stop-gradient，邻居消息误差只更新本地预测头和本模块的 B、G、MLP，不更新任何模块的 P；P 只由对外读出误差和观测通道的本地误差训练。另加一项方差约束：每个消息维度按滑动平均估计方差，低于初始方差的 10% 时，对该维度施加 (阈值 − 方差) 的惩罚。在线阶段 P 冻结、目标取 stop-gradient，切断了最直接的捷径，但不能保证不坍缩：产生 h 的 B、G、MLP 仍在线更新，z = P·h 仍可能趋于常数。因此方差约束在线阶段同样生效：维度方差低于阈值时，先暂停该模块的在线更新并报警。

**睡眠巩固。** 每 4,096 步或会话结束时进入巩固。先复制现场状态；从重放池抽片段，从独立状态预热；以小学习率用截断 BPTT 微调慢权重，并把 MLP 偏移并入 W₁ 后清零。巩固后用后续近期片段和旧记忆片段验收，规则与第 4 节换边保护相同：近期误差不恶化，且旧记忆 NMSE 恶化不超过 0.02（开发起点）才提交，否则回滚并恢复现场状态。巩固期间的副本与 BPTT 激活计入峰值内存。

**沿用的结论。** 反馈用对称形式。v0.12 中固定随机 ±1 反馈在学习率 0.02 时误差升到固定组的 1.15 倍，再大就发散；v0.13 中不滞后的逐跳反馈和固定随机反馈在接力链上都与“隐藏模块不学”无差别。两者保留为对照。

**调参与稳定性规则。** 学习率、λ 和巩固学习率是每种方法的一部分，各组都在开发种子上单独调整，测试种子只用于最终比较；最佳值落在网格边缘时继续外扩。运行中监测误差、饱和率和单步更新范数，超过阈值时裁剪更新或暂停在线学习。结果表除平均值外报告中位数和最差种子。完整递归系统的时间信用分配仍需以小网络反传参照。先例见 [RFLO](https://elifesciences.org/articles/43299v2)、[e-prop](https://www.nature.com/articles/s41467-020-17236-y)、[SnAp](https://openreview.net/pdf?id=q3KSThy2GwB)、Zucchet 等（2023）关于对角循环网络精确在线学习的工作，以及 [局部 Hebb/STDP 模型](https://neuronaldynamics.epfl.ch/online/Ch19.S2.html)。

### 3.1　学习规则的定位：现状、与反传的区别、与大脑的对照（2026-11-19 讨论结论）

| 部分 | 现在的算法 | 是否反传 | 大脑里大致对应 |
|---|---|---|---|
| 离线训练 | 截断 BPTT（256 拍）+ AdamW | 是 | 进化与发育（把局部规则的“用法”先学好） |
| 在线学习 | 64 拍块内截断反传，只更新低秩偏移（online.py） | 是（工程简化） | 无对应 |
| 睡眠巩固 | 重放池上反传 + 自蒸馏锚 | 是 | 睡眠中海马回放、向皮层巩固（思路对应，实现不对应） |
| 快记忆、中枢写入 | delta 规则 S ← S + β(v − S·k)kᵀ，前向时就地完成 | 否 | 海马式快速可塑、一次学会 |

- 反传在生物上难成立：需要对称的反向权重、分开的前向 / 反向两个阶段、保存整段历史；大脑用局部规则（赫布、STDP）加第三因子（多巴胺等广播信号决定局部改动是否保留）。
- 赫布家族：纯赫布记忆 S ← S + v·kᵀ（经典快权重、线性注意力、Hopfield）只会叠加，同键重写时新旧混杂；delta 规则把“后”项换成误差（带纠错的赫布），能干净覆盖同键。纯赫布无任务目标且不稳定（需 Oja 类归一化），不单独用于学习慢权重。
- 预测学习：训练目标已是预测（下一字节，自监督）；作为学习规则的预测编码（每层预测下层、只用本地误差 × 本地输入更新，Whittington & Bogacz 2017 证明可近似反传梯度）设计中有（第 1 节与本节开头的本地预测头）但文本代码未实现，与 8.4 块延迟自上而下、8.7 全局工作空间合并考虑：上传预测误差，各模块以自身预测误差学习。难点是标准预测编码需迭代推断、GPU 上慢（参 μPC）。
- 目标形态：大脑式学习统一为“赫布式局部规则 + 局部误差”——快记忆用 delta 规则（已实现）；在线用资格痕迹 × 广播误差（三因子，同 e-prop，Bellec 等 2020，即本节开头设计的对角痕迹，待实现）；层间用本地预测误差（待实现）。离线反传只负责元学习这些规则的参数。
- 关键事实：慢变状态 c 是对角线性递推，对它资格痕迹可精确等于真实梯度（非近似，参 Zucchet 等 2023 关于对角线性递推的在线学习）；因此在线阶段对 c 可不存历史、不反传而无精度损失，内存固定，符合固定内存预算。MLP 与跨层部分仍需近似（逐层反馈或本地预测误差）。

### 3.2　缺口：选择性学习（什么值得学）（2026-11-19 讨论结论）

- 现状：短期记忆已会挑——快记忆与中枢每次写入有学出来的写入强度 β 与遗忘门 γ。长期学习基本不挑——在线阶段每 64 字节一视同仁走一步梯度；唯一筛选是重放池按“意外程度”留片段，而意外不等于值得学（乱码同样意外）。睡眠验收与回滚是最后一道防线，不是筛选。
- 目标：在线学习率与睡眠保留由四个信号共同决定，各自做消融：
  1. 可学的意外（学习进展）：不只看当前块损失高于滑动均值，还看同类内容再次出现时误差是否下降；下降为规律，放大学习；不降为噪声，不学，也不进重放池。对应好奇心 / 学习进展理论。
  2. 重复：单次出现的内容只留在快记忆与低秩偏移；睡眠时偏移按比例缩小后再并入（突触稳态假说），只有多次出现而累积起来的改动留下。即阶段 5 第 3 项。
  3. 明确的重要性：外部信号（用户说“记住”、纠正、好评）作为第三因子放大该段学习率并提高其在重放池中的优先级。对应多巴胺第三因子。
  4. 来源：只从外部输入（对方的话）学，不从自己生成的文本学，避免自我强化错误。对话场景下按轮次标记来源。
- 与已有设计的关系：第 1 项是阶段 5 第 2 项“意外调制学习率”的修正版（把“意外”换成“可学的意外”）；第 2 项即阶段 5 第 3 项；第 3、4 项为新增，需要对话场景才能检验。
