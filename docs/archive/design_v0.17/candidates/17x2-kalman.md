## 17-X2　卡尔曼写入（Kalman）

借鉴领域：控制论与估计理论（卡尔曼滤波、递归最小二乘）。标注：[V] = 本次打开原文核实；[未核实] = 凭记忆或二手来源；“估算”= 未实测。

### 1. 一段话总述

把“使用中学习”看成一个估计问题而不是训练问题：模型的权重是要估计的“状态”，用户说的每句话是一次“测量”。卡尔曼滤波告诉我们：新测量该把估计挪动多少，取决于我们对每个方向有多不确定——很确定的方向几乎不动，没把握的方向大步改。具体做法：用现成的小型对话模型（Qwen2.5-0.5B-Instruct）作主干，在几层 MLP 的输出矩阵 W 旁边各维护一张“不确定度表”P（哪些输入方向已被旧知识占用）。用户教一条事实时，用一条闭式公式直接改 W：一步写入、不用反复迭代，并且对旧输入的输出改动最小。写完后 P 在这个方向上收缩，新事实也变成“受保护的旧知识”。这是三套方案里最贴近“参数在使用中当场改变”的一套：改的就是主干自己的权重。

### 2. 借鉴的原理与对应关系

把一层 MLP 的输出矩阵看成线性联想记忆：输入键 k（该层中间激活）→ 输出值 v = W k。

| 控制论 | 本方案 | 类比还是真机制 |
|---|---|---|
| 状态 | 被选中的 4 层 MLP 输出矩阵 W | 真机制 |
| 测量与残差 | 新事实要求的输出 v* 与当前输出 W k* 之差 | 真机制 |
| 误差协方差 P | 键的逆协方差：初值 P₀ = (Σ k kᵀ + εI)⁻¹，k 来自背景语料 | 真机制（线性层上递归最小二乘就是卡尔曼滤波） |
| 卡尔曼增益 | g = P k* / (λ + k*ᵀ P k*) | 真机制 |
| 状态更新 | W ← W + (v* − W k*) gᵀ | 真机制：秩一更新 |
| 协方差更新 | P ← P − g k*ᵀ P | 真机制：写过的方向变“确定”，以后不易被改 |
| 过程噪声 Q | 每晚 P ← P + qI，让很久没用的方向慢慢恢复可塑 | 真机制；也是允许“改口”的来源 |
| 新息大小 k*ᵀ P k* | “这个情境我有多陌生” | 真机制，可当不确定度读出（假设 H2） |
| 扩展卡尔曼滤波 | 非事实类学习：反传一次得到该层输出的梯度 δ，取 v* = W k − η δ 再走同一公式 | 近似：把网络在当前点线性化 |
| 平滑（事后重估） | 空闲时把当天全部 (k*, v*) 联立成一次最小二乘重解 | 真机制：一次线性求解，不是训练 |

与普通梯度下降的区别用一句话说：梯度下降的改动是 −η δ kᵀ，沿新键 k 本身；卡尔曼的改动沿 P k——把 k 中与旧知识重叠的成分扣掉之后的方向。所以旧输入几乎感觉不到这次改动。本项目早期就在读出层比较过 LMS 与 RLS（E04）：RLS 精度略好但要存协方差；那时字节预算极紧，现在预算充裕，结论可以反过来用。

需要说清：这条公式与模型编辑里的 ROME / MEMIT 是同一族（MEMIT 的连续编辑解里就有“背景键协方差 + 已编辑键协方差”之和，AlphaEdit 再加零空间投影 [V]）。本方案的新意不在公式，而在三点：把它当作**常驻的在线学习规则**（不止三元组事实）；加**过程噪声**解决已知的连续编辑退化；用**新息**当不确定度信号。

### 3. 结构与规模

- 主干：Qwen2.5-0.5B-Instruct（24 层、隐层 896、MLP 中间维 4864，约 4.9 亿参数；Apache-2.0 [未核实许可细节]）。半精度约 1 GB 显存。
- 可写层：中后段 4 层 MLP 的输出矩阵（896×4864）。每层一张 P（4864×4864，单精度约 95 MB），4 层约 380 MB，放内存里用双精度算也可以（一次秩一更新约 2,400 万次乘加，毫秒级）。
- 两套滤波器并行（“多速率”）：快表 W_f（过程噪声大，会话结束清零，装临时内容）与慢表 W_s（过程噪声小，长期）；前向用 W + W_f + W_s。原始 W 另存一份，随时可回滚。
- 日记：每次写入的原话、(k*, v*)、时间，存 SQLite。用于夜间重解、审计、撤销。
- 显存：推理约 1.5 GB；求 v* 需要反传到可写层，约 2.5–3 GB（估算）。吞吐：生成 40–80 词元/秒（估算）；写一条事实 1–3 秒（主要花在求 v* 的 20 步小优化上，估算）；逐词元 EKF 步约为一次前向加一次反传。
- 离线准备：在 100 万词元的对话 + 百科混合语料上收集各层键、求 P₀，10–20 分钟（估算）。**不训练主干。**

### 4. 学习方式

- **离线**：只求 P₀。若主干闲聊质量不够，可加一次几小时的 SmolTalk LoRA 微调并入主干，之后重求 P₀。
- **使用时**（两条写入通路）：
  1. 事实写入：检测到陈述 / 纠正 → 主干自己把它改写成 3–5 个问法 → 在每个问法末词元处取键 k*ᵢ → 用约 20 步小优化求出让模型说出正确答案的目标值 v*（ROME 的做法 [未核实细节]）→ 对 4 层依次走卡尔曼更新。多个问法 = 多次测量，天然合并。
  2. 普通经验：对用户轮与被接受的助手轮，惊奇高的词元各走一步 EKF（一次反传），写进快表；会话结束时，只把当晚重解后仍有用的部分并入慢表。
  - 改口：用户更正旧事实时，同一个键上的残差 v* − W k* 自动把旧值顶掉；日记里旧条目标记作废。
- **空闲时（平滑 + 检查）**：把慢表清回昨晚状态，用当天日记里全部有效条目联立重解一次（批量最小二乘，比逐条写更准）；加过程噪声；检查三项——日记抽查题通过率、背景对话困惑度漂移、W 的范数与奇异值谱——任何一项超标就回滚到昨晚并减半当天写入强度。
- **防遗忘**：靠 P 的保护（结构性）+ 每晚回归检查 + 原始权重备份。不需要回放语料做梯度训练。

### 5. 三种自我改进与记忆：怎么实现、怎么测

| 需求 | 实现 | 测法 |
|---|---|---|
| 知识 | 事实写入通路 → 慢表 | 清空上下文后改写问法的正确率；连续写入 N 条后首批保持率；改口后旧值复现率 |
| 能力 | 空闲时读用户常聊领域的语料（Cosmopedia 检索），逐词元 EKF 写慢表 | 领域留出问答与困惑度；对照为同时长 AdamW-LoRA |
| 适应用户 | 对用户轮做 EKF（学会预测用户怎么说话）+ 对被接受的回复做 EKF | 用户轮困惑度随会话数下降；偏好遵守率 |
| 会话内记忆 | 上下文窗口 + 快表 | 同会话指代题；超出窗口后靠快表回答的题 |
| 跨会话记忆 | 慢表 + 日记 | 重启后提问；撤销某条日记后重解，应答不出 |
| 知道自己不知道 | 新息 k*ᵀ P k* 高时回答加“我不确定”或反问 | 新息对答错的 AUROC |

### 6. 核心假设，以及为什么可能赢过普通 Transformer

- **H1（一步写入）**：同等背景漂移下，卡尔曼写入一步达到的事实正确率，高于 SGD / AdamW 在同一矩阵或 LoRA 上几十步达到的水平。
- **H2（不确定度）**：新息能预测模型是否答得对（AUROC > 0.7），普通 Transformer 没有这个免费信号。
- **H3（过程噪声）**：带过程噪声与夜间重解的版本在 5,000 次连续写入后范数有界、通过率不降；固定协方差版本会退化。
- 为什么可能赢：本项目的在线学习一直卡在“学多少 / 忘多少”的权衡上（E25、E29），低秩偏移不忘但学得少，睡眠要锚定才稳（E31、E33）。那些都是一阶方法——改动方向不看旧输入的统计。卡尔曼增益把这份统计用上了，而且是闭式的，训练时间几乎为零，最符合“训练不能太慢”。

### 7. 主观成功概率

- 满足全部用户需求：**40%**。说话与智力由主干保证；风险集中在连续写入的稳定性。
- H1：55%（单条编辑的先例充分）；H3 在 0.5B 模型上撑到数千条：40%；H2：45%；逐词元 EKF 在“能力”上胜过 LoRA + 回放：25%。

### 8. 依据

- ROME（Meng 等，NeurIPS 2022，arXiv 2202.05262）：MLP 作键值联想记忆，秩一编辑 [V 摘要；公式细节凭记忆]。MEMIT（Meng 等，ICLR 2023）[未核实]。
- AlphaEdit（Fang 等，ICLR 2025 Oral，arXiv 2410.02355）：把改动投影到保留知识键的零空间；由约 10 万条背景三元组估计 K₀K₀ᵀ，奇异值分解后丢掉特征值大于 10⁻² 的方向；给出与 MEMIT 连续解的对照公式；2,000–3,000 条连续编辑 [V 正文]。
- 连续编辑会退化：Gupta 等（arXiv 2401.07453；2502.19416，范数增长导致崩溃）；ENCORE（arXiv 2502.01636，加正则后称可到 1 万条）；Norm Anchors（arXiv 2602.02543，多数方法几千条内耗尽）[均只看了搜索摘要]。这是 H3 要正面回答的问题。
- LoFi（Chang、…、Murphy，CoLLAs 2023，arXiv 2305.19535）：低秩 + 对角精度矩阵的扩展卡尔曼滤波做神经网络在线学习，每步代价与参数量线性，无需调步长，适应非平稳更快 [V 摘要]。
- LoKO（Abdi 等，arXiv 2410.11551，2024）：把 LoRA 微调当状态估计，对角协方差的卡尔曼优化器，比常用优化器收敛步数更少 [V 摘要]。
- 检索未发现把“带过程噪声的卡尔曼 / 递归最小二乘”用于对话模型连续事实写入的论文（2026-11 检索，不能证明没有）。
- 本地文献：cards/memory-workspace.md 第 2 卡（预条件 DeltaNet：对角近似的同一思想，精确逆 Gram 不能分块——本方案不在序列内用，所以可用精确式）、第 1 卡（Palimpsa：重要性状态控制可塑性）；cards/sleep-2.md 第 16 卡（对基座的 KL 预测遗忘，用作夜间检查）、第 9 卡（饱和时回放无效——本方案不靠回放）；topics/learning-rules.md（SynGAP：流式 Fisher 作梯度掩码）；topics/continual-sleep.md。
- 本项目实验：E04（RLS 对 LMS）；E25、E29、E31、E33（在线与睡眠的权衡）；E28（delta 规则快记忆在合成召回上有效——卡尔曼写入是它在慢权重上的对应物）。

### 9. 验证实验（按顺序）

1. **V1 连续 300 条事实（约 2 小时）**。对照组：A 卡尔曼（P 累积 + 过程噪声）；B 固定协方差（ROME 式，P 不更新）；C 同一矩阵上的 SGD（学习率扫 4 档）；D LoRA 秩 8 + AdamW；E 检索进上下文；F 上下文内直接给事实（上界）。指标：改写问法正确率（写完即测、全部写完后）；500 段普通对话困惑度漂移；W 的范数；每条写入耗时。门槛：A 末尾正确率 ≥ F 的 80%，漂移 ≤2%，在相同漂移下比 C、D 高 20 个百分点以上。不过怎么办：先扫层（键取哪 4 层最敏感）；仍不过 → 把写入改到一份旁路矩阵 + 路由（WISE 式），本方案退化为“旁路记忆的写入规则”，并记录“0.5B 模型的 MLP 不够线性联想”。
2. **V2 不确定度**：200 条已教 / 200 条未教的问题，测新息的 AUROC。门槛 0.7。不过 → 去掉“知道自己不知道”功能，其余不受影响。
3. **V3 长跑 5,000 次写入**：含 10% 改口；过程噪声三档 + 关闭夜间重解的消融。门槛：通过率不随条数下降超过 5 个百分点，范数增长 <10%。
4. **V4 能力**：读 2 MB 领域文本，逐词元 EKF 对 AdamW-LoRA（同时长）。门槛：领域问答不低于对照，且漂移更小。不过 → 能力改进改用夜间 LoRA，卡尔曼只管知识。
5. **V5 适应用户与综合**：30 个模拟会话，三项指标同时看。

### 10. 最可能失败的地方，以及失败能学到什么

- **连续写入退化**：文献里最扎实的负面结果。过程噪声与夜间重解是对策，但没有先例证明在 0.5B 上够用。失败则得到一条清楚的容量曲线：这类模型的主干能安全写多少条。
- **键选不准**：聊天里的事实没有干净的“主语末词元”，靠多个自生成问法取键；若泛化到没见过的问法很差，说明事实在小模型里不是按“线性键值”存的。
- **只会背、不会用**：编辑类方法在多跳与反向提问上普遍弱 [未核实]；间接问法题会暴露这一点。
- **逐词元 EKF 太贵或不稳**：一次反传 + 4 张大表更新，若每秒只能处理几十词元，能力改进只能留到空闲时。
- 即使整体失败，P₀ 这张“哪些方向被旧知识占用”的表，对其它两套方案的防遗忘也直接可用。
