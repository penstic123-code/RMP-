# 思说解耦 RMP（RMP-First 新架构设计）

> 状态：原型已落地并跑通首轮可证伪对照（见 [E124](../experiments/e110-.md)）；早期外部联想记忆线（`E111–E123`）已独立存档于 git 提交 `ca870a2`。

## 1. 为什么切换回 RMP-First

- 此前外部联想记忆线（`E111–E123`）虽然指标优异，但本质上仍是「标准 Transformer 编码器 + 小 Transformer 重排 + 冻结 Transformer 回答」，与标准范式差别不大，且把 RMP 主干（`E110`）完全绕了过去。
- 新主线把控制权彻底交回 **RMP**：
  ```
  用户输入 → 思说解耦 RMP（查记忆、组合证据、规划意图、决定答案或拒答） → [可选] 冻结 Qwen（纯语言润色嘴替，不碰原问题与记忆库） → 自然语言
  ```

## 2. 核心架构：双时钟解耦 + 有界工作记忆注意力

实现在 [rmp_think_speak.py](../../rmp_think_speak.py)，单测在 [test_rmp_think_speak.py](../../tests/test_rmp_think_speak.py)，对照评测在 [eval_rmp_think_speak.py](../../tools/eval_rmp_think_speak.py)。

1. **主干保持 100% 零 Self-Attention 的 `WavePool` RMP**：
   - 保留竞争路由、多尺度深浅波（浅波快响应管逐字吐字，深波慢整合管高层表达意图与规划）、SMF 局部抗遗忘与 $O(1)$ 恒定对话状态（不膨胀 KV-cache）。
2. **双时钟解耦（内部思考步 vs 外部说话步）**：
   - **内部思考步（Internal Tick）**：不吐字，把深波意图折回波池继续推进；同时深波向情景库发起查询（含 `NULL` 拒答槽），选中记忆后静默读入 RMP 自身循环状态并压入工作记忆槽。
   - **外部说话步（Emit Step）**：由可学习说话门 `emit_gate` 决定“继续内隐思考”还是“开口吐字”——既支持**开口前多步规划（如两跳）**，也支持**说到一半主动暂停吐字、补查第二条记忆后再说完后半句**。
3. **有界工作记忆 Cross-Attention + Copy Pointer（只在必要边界引入局部注意力）**：
   - `E124` 首轮对照实证了纯固定循环状态的边界：仅靠固定维度状态无法精确逐字节拷贝训练期从未见过的中文人名/地名；
   - 因此仅在被 RMP 主动召回的 **1~2 条工作记忆槽（固定极小窗口，$O(1)$ 开销）** 上加入轻量 Cross-Attention + Copy Pointer，主干对话历史仍完全保持零 Self-Attention。

## 3. 当前进度（截至 E124）

- **已验证打通**：
  - 双时钟控制与说话门 `emit_gate` 在几十次梯度更新内就已学会开口前停顿、两跳连想、句中主动暂停（`E124` v2 探针）与缺证拒答；
  - 全部单元测试通过（`tests/test_rmp_think_speak.py` 与 `tests/test_assoc_memory.py`）。
- **尚未打通（下一步核心）**：
  - 当前按单条 episode 循环训练导致吞吐偏低（640 episode 仅 80 次梯度更新），尚不足以让字节级 Copy Pointer 收敛跨多字节精确拷贝未见中文实体；
  - 下一步优先做两件事：
    1. **批量化训练提速 + 指针/片段拷贝监督**：把训练改成真正 GPU 批处理（提速 5–10×，跑足 1,000+ 次更新），并对工作记忆指针注意力加直接对齐监督（或改为词/子词级），打通「动态改口切换（小李 → 陈阿姨）」「两跳答对」「句中暂停双中」三项核心指标；
    2. **接回冻结 Qwen 做纯嘴替验收**：先在拔掉 Qwen 条件下把 RMP 自身答对率拉高，再验证冻结 Qwen 只看 RMP 草稿润色时 0 失真、0 编造。
