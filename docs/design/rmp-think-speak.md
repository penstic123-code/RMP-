# 思说解耦 RMP（A2：潜空间自适应思考 + 极简端到端海马读取 + SMF）

> 状态：**A2 路线实施中**（遵循苦涩的教训与信息论边界，彻底去除 E124 的手工特征与脚本监督）；E124 原型存档于 `eced04b`，早期外部联想记忆线（`E111–E123`）存档于 `ca870a2`。

## 1. 设计原则与边界

1. **避免和 Transformer 一模一样**：
   - 主干保持 **100% 零 Self-Attention** 的 `WavePool` RMP（竞争路由、多尺度深浅波、慢通道 $c$ + DeltaNet 快记忆 $S$、$O(1)$ 恒定对话状态、SMF 局部抗遗忘）。
   - 计算深度与吐字解耦：在 $O(1)$ 状态内对同一 `WavePool` 进行 $K$ 拍潜空间循环思考，动态路由到不同专家模块，无需吐出显式 CoT 撑大 KV-cache。
2. **尊重信息论硬上限（Jelassi et al. 2024，见 [architectures.md](../literature/topics/architectures.md)）**：
   - 任何固定常数状态模型都无法在超容量下做任意长度的精确逐字召回；因此超状态容量的精确原文交由极简外部海马接口按需读取，但绝不对对话历史做全量 Self-Attention。
3. **严格遵循苦涩的教训（砍掉 E124 的手工补丁）**：
   - 删掉 `k_top=9` 字节级 MaxSim、手工 `used_mask`、脚本化 `THINK/SPEAK` 轨迹监督与显式指针对齐损失；
   - 全部改由 **GPU 批量化端到端训练**（标准下一 token 交叉熵 + PonderNet 几何先验停机正则）自然涌现。

## 2. A2 核心架构（`rmp_a2.py`：`LatentThinkHippoRMP`）

1. **零 Self-Attention 路由主干 + 潜空间自适应思考（PonderNet 停机）**：
   - 输入序列经稠密编码层 `enc` 得初始残差流 $x^{(0)}$；
   - 第 $k = 0 \dots K_{\max}-1$ 拍潜空间思考复用同一 `WavePool`（每拍独立 $O(1)$ 槽位状态，支持全序列 `(B, T)` 并行训练且与逐 token 流式推理严格等价）；
   - 说话/停机门 `emit_gate` 输出各拍停机分布 $p_t^{(k)}$，完全由端到端任务损失 + $\lambda_{\text{ponder}}\,\mathrm{KL}(p_t \,\|\, \mathrm{Geom}(p_{\text{prior}}))$ 驱动，自动把更多潜空间思考拍数分配给多跳/难位置。
2. **极简端到端海马读取（可选开关 `use_hippo`，供 A1/A2 严格消融）**：
   - 外部情景库文本直接由 RMP 自身编码层 + `WavePool` 编码（零 BGE / 零外部 Transformer），附带 1 个可学习 `NULL` 拒答槽；
   - 每拍思考输出 $x_{\text{out}}^{(k)}$ 对海马库做单头门控读取，结果回注残差流 $f^{(k)} = x_{\text{out}}^{(k)} + W_o(\text{ctx}^{(k)})$ 并作为下一拍潜空间思考输入——从而在**无任何跳数脚本监督**下，自然涌现“第 0 拍查第一跳 → 融进波池 → 第 1 拍查第二跳 → 停机回答”；
   - 读出头以可学习门融合词表分布与海马指针分布，**仅由标准交叉熵端到端训练**。
3. **原生兼容在线 SMF 抗遗忘（`smf_mlp`）**：
   - 沿用 E110 验证的 `freeze_enc + plastic=False + _masked_step`，在线学习新领域/新技能时只更新相对激活频率最高的 $k_{\text{smf}}$ 个波池模块 MLP，守住旧域遗忘红线。

## 3. 可证伪对照实验设计（E125 起）

1. **A2 潜空间思考与海马端到端消融（同参数、零实体泄露、无脚本监督）**：
   - 对比 `lockstep`（$K=1$，无海马）、`A1_latent_only`（$K=3$ 潜空间思考，无海马）、`A2_hippo_k1`（$K=1$ + 极简海马）、`A2_hippo_k3`（$K=3$ 潜空间思考 + 极简海马）；
   - 评测 4 项零泄露能力：单跳动态改口切换、两跳无脚本连想、三跳/复合条件推理、缺证拒答，以及 `emit_gate` 是否自发对多跳题分配更多思考拍数。
2. **A2 + 在线 SMF 持续学习验证**：
   - 在真实多域文本（`task3`）或双任务流上验证 `LatentThinkHippoRMP` 接入 `smf_mlp` 后，新域降损同时旧域遗忘可控（对照全参微调）。
