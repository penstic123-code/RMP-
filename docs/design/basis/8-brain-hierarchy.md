## 8　脑机制对照、层级与稀疏（设计讨论结论，2026-11-19）

本章记录设计讨论得出的判断与理由；要做的事只写在 [plan.md](../../plan/README.md)。文献出处见本章末，均已核对作者、年份与核心结论。

### 8.1　已吸取与缺少的脑机制

| 脑机制 | 本设计中的对应 | 现状 |
|---|---|---|
| 互补学习系统（海马快、皮层慢） | 快记忆 S、中枢、在线偏移为快；离线慢权重为慢 | 已实现 |
| 睡眠重放与巩固 | 意外优先的重放池、睡眠巩固 | 第一版已实现（online.py） |
| 主动遗忘 | 快记忆与中枢的门控衰减 | 已实现 |
| 预测编码（学习信号部分） | 上层本地预测头预测下层下一拍消息（第 1、3 节） | 已设计，文本代码未实现 |
| 资格痕迹 / 三因子规则 | 学习率 × 反馈 × 痕迹，痕迹即资格痕迹，第三因子为预测误差 | 已设计；在线第一版暂用块内反传 |
| 结构可塑性 | 流式换边 | 只用于数值流模式 |
| 内在可塑性（稳态） | 消息方差约束（第 3 节防坍缩） | 已设计 |
| 神经调质调节学习率（多巴胺、乙酰胆碱、去甲肾上腺素） | 无 | 计划：意外调制在线学习率 |
| 突触稳态的睡眠下调 | 无 | 计划：在线偏移向 0 的权重衰减（连续版） |
| 睡眠中的生成式重演 | 无 | 计划：做梦式自蒸馏，作 KL 锚 |
| 记忆分配（兴奋性高的神经元优先承载新记忆） | 无 | 候选：稀疏写入 / 稀疏激活 |
| 预测编码（信号流部分：低层只上传预测误差） | 无 | 候选：块延迟的自上而下预测 |

原则：“更像大脑”不是目标，每个机制须经消融证明降低遗忘或提升能力才保留。

### 8.2　灾难性遗忘的风险位置

- 在线阶段（中等）：只改低秩偏移与读出，漂移有限；但读出为所有上下文共用，在线修改直接影响旧内容。
- 睡眠巩固（最大）：仅用 64 KiB、以新内容为主的重放池微调全部慢权重，是典型的遗忘情形；当前只有“验收不过即回滚”，回滚等于放弃本次巩固。对策见 plan.md 阶段 4、5 与文献调研采纳决定。

### 8.3　层级：含义、模块同构与涌现

- 皮层中“高层级”指：内在时间尺度更长；感受野更大、表征更抽象；整合更多来源（枢纽）；向低层发出预测；层级由连接方式（谁投射到谁、投射到哪一皮层）定义，而非神经元种类。
- 模块同构不是缺陷：皮层大体共用同一种微环路，分化来自位置与连接、经验学习，以及少量平滑的参数梯度（同一环路 + 兴奋性梯度即可得到时间尺度层级）。本设计已有前两者；第三者不预先写入，先检验层级能否自发长出。
- 核查（2026-11-19）：随机初始化时四层统计完全相同（门控时间常数中位数 34.9 拍、τ>100 占 34.4%、快记忆保持 64 拍），训练后出现差异才算“长出来”。测量工具：[tools/analyze_hierarchy.py](../../../tools/analyze_hierarchy.py)。 上下文替换实验（E19）表明：“减半时间逐层变长”在随机初始化网络里就存在，是层层平滑的结构效应，不能单独作为涌现证据；训练带来的真实分化是底层变快、顶层携带的长程前文信息大幅增加。层级涌现以“剩余信息量相对随机网络的增量”为主指标，并需打乱文本训练作对照（若分化消失，才说明是语言的长程结构促成了层级）。

### 8.4　连接方式的决定

- 现状：模块只接正下方一层（正下方 + 四邻居，4 维消息）；无同层、无自上而下；跨层直连只有“所有层接读出”。S 档 2×4 网格、4 层时，第 4 层经 3 跳可覆盖第 1 层曼哈顿距离 ≤3 的模块，即除对角两端外的全部。
- 层间不必稠密：感受野逐层扩大，文本模式下第 1 层各模块都读完整字节；全局混合由读出与中枢两个全连接枢纽承担，构成“局部为主 + 少数枢纽”的小世界结构。稀疏与全连接的优劣尚无本项目证据，可做同参数对照。
- 同层输入暂不做：同拍互连成环，改用上一拍则产生跨模块的非线性时间循环，失去整段并行训练；v0.14 正为此改为自下而上（E13：同层逐拍版 bpc 2.535，分层版 2.598，前者略好但只能逐拍训练）。
- 跨层直连暂不做：每层都能见原始输入会冲淡层级，与“让层级自发长出”的目标相冲突。
- 自上而下预测分两种：作为学习信号（已设计）与作为信号流（缺）。候选“块延迟的自上而下预测”把上层对下层的预测按块延迟送回，下层上传预测误差，块内仍并行；高层越能预测，上传越少，可能促成分工与层级。

- 同层通信、自上而下与可学连接的统一候选：全局工作空间，见 8.7。

### 8.5　稀疏与动态

- 现状：模块内稠密（循环已改为对角，稠密在 B、G、K/V/Q 与 MLP）；层间稀疏；文本输入、读出、中枢为全连接；文本模型无换边，“动态稀疏”目前只体现了“稀疏”。计算上以同层堆叠的批量稠密矩阵乘实现块对角结构。
- 动态换边推迟而非放弃：（1）原换边解决的是多通道中搜索有用输入源，文本单字节流且已送达第 1 层全部模块，暂无此需求；（2）训练中途改连接会打破固定形状的批量计算与 CUDA Graph，离线阶段反传可自行把无用连接学到接近零；（3）其价值主要在在线阶段——固定内存下为新规律腾容量、少碰旧连接以防遗忘——需待阶段 4 跑通。离线若要稀疏，可用固定连接数的周期性剪枝再生长（RigL 类），与批量计算兼容。

### 8.7　候选：全局工作空间（demo 之后的层级研究线第一项）

- 来源：全局（神经）工作空间理论（Baars 1988；Dehaene 等，综述 [Mashour 等 2020](https://pubmed.ncbi.nlm.nih.gov/32135090/)）——许多专门模块并行工作，只有少量内容经竞争进入容量很小的工作空间，再广播给全部模块；胜出内容会“点燃”并维持一段时间。机器学习对应：[RIMs](https://arxiv.org/abs/1909.10893)（模块经注意力竞争，每步只激活少数）与 [Goyal 等 2022 共享全局工作空间](https://arxiv.org/abs/2103.01197)（模块竞争写入少量槽位、再广播，优于模块两两通信）。v0.11 曾有“上下文广播”可选实验，只借了“少量信息可供多个系统访问”一点。
- 现状对照：中枢是唯一全局通道，最像工作空间，但缺三点——无竞争（第 2 层全部消息直接写入）、不广播到全部层（只给中枢之上的层）、无点燃式维持。
- 候选机制：工作空间设 K 个槽位（初值 K=4）；按 64 拍分块，每块末各模块对槽位打分，top-k 胜出者写入；块 k 的槽位内容在块 k+1 广播给所有层所有模块（作为额外输入），块内仍整段并行，不形成跨模块逐拍非线性循环。可选：胜出槽位跨块保留（点燃 / 维持），读时只更新被读到的模块（RIMs 式稀疏更新，在线阶段少碰旧模块以防遗忘）。
- 预期（待验证，目前只提供通道）：同层横向通信（经工作空间，带宽 4 槽、每模块收 4 维、延迟一块）；自上而下（高层写入的内容可广播回低层，但写入由全部模块竞争，不保证是高层在写；与 8.4 块延迟预测合并：下层可上传“消息 − 工作空间预测”，这是全局而非逐层的预测编码）；模块稀疏（只有胜出者能写入并在下一块更新，所有模块都收广播）；层级与分工涌现（谁常胜出、谁听谁的需另做统计工具读出，尚未实现）。判定“解决”需要效果证据（长上下文、远距召回、遗忘上优于无工作空间）与机制证据（统计显示高层主导写入、同层经工作空间交换信息、模块分工）。之后可把固定网格换成“一池同构模块 + 工作空间”，测连接统计中是否长出层级。
- 实现现状（2026-11-19，dspn_text.py `ws_*`）：基础版为块延迟广播——槽位 4 × 16 维，软竞争（每槽位对全部模块 softmax），固定保留门，每层固定矩阵接收；广播投影零初始，起步等于无工作空间；块边界按全局位置对齐，逐拍与整段一致（tests/test_workspace.py）。完整版各机制可单独开关：`ws_topk` 硬竞争（显著性前 k 的模块才能写，显著性经 sigmoid 门控得梯度）；`ws_lb` Switch 式负载均衡损失；`ws_ignite` 点燃（保留门随写入内容变，近似而非真正全或无）；`ws_read` 各模块以自身消息为查询、注意力选择性读槽位；`ws_sparse` RIMs 式稀疏更新（未胜出模块下一块 c、S 冻结）；`ws_pc` 预测编码（读到的内容预测本模块消息，向上传“消息 − σ(g)·sg(预测)”，预测头以 MSE 训练）。策略：先测完整版对基础版与无工作空间，有效再逐项去掉找关键机制。
- 风险：块延迟使工作空间对块内信息滞后最多 64 拍，字节级局部预测仍须靠模块自身；top-k 不可导，用直通估计或软 top-k；竞争易塌缩成少数模块总胜出，需负载均衡项（同 MoE）。
