## 4　记忆与保护旧知识

> 与主线 RMP 相关：睡眠巩固与保护旧知识被 RMP 复用，见 [23.10](../candidates/23-routed-pool.md)。

记忆按时间尺度分层，每层大小固定，不随上下文增长（第 2 节）。

| 记忆 | 在哪 | 时间尺度 | 会话边界（第 1.4 节） |
|---|---|---|---|
| 慢通道 c | 每个模块 | 1.5–1000 拍，门按输入调节 | 清空 |
| 快记忆 S | 每个模块 | 初始平均保持约 64 拍，按内容存取 | 清空 |
| 中枢 | 中枢 | τ 初值 300 / 1,000 / 3,000 / 30,000 拍 | 清空 |
| 在线改动 | MLP 低秩偏移，或慢通道 B、G、b_a（e-prop） | 一天（两次睡眠之间） | 保留 |
| 海马（情景库） | episodic.py，原句 | 终身 | 保留，新会话可召回 |
| 慢权重 | 全部 | 永久，只经睡眠改动 | 保留 |
| 重放池 | 原始字节 | 按优先级淘汰 | 保留 |

**工作记忆**由 c、S 和中枢承担。**跨会话的事实**由海马承担：中枢持久头从没被用上（E48、E50），v0.17 已删；聊天时海马按线索把相关原句以 `User: 事实
Bot: OK.` 的格式读回上下文（第 20 章）。**长期记忆**是慢权重；在线学到的内容先在在线改动里，经睡眠巩固才进入慢权重。

**快记忆怎样遗忘。** delta 规则只在新旧键相近时覆盖旧内容，情境切换后旧内容会留在 S 里干扰读出。因此 S 每拍先按学出来的遗忘率 γ 衰减，由模型自己决定何时清理；β 上限 2 使写入还能主动擦除同键内容（E20、E26）。会话边界清空 S。S 和中枢的内容不直接巩固进慢权重，巩固只用重放池里的原始片段；没进池的经历不会被巩固。

**中枢为什么用异质时间常数。** 单一时间常数的头要么记不久，要么被新内容慢慢冲掉；几个头分别覆盖几百到几万拍，模型可以把不同寿命的信息写到不同的头。衰减时间常数只是上限：新写入会覆盖相近的键方向，实际召回寿命可能短得多。故事内名字召回尚未成功（E36），中枢与召回的其余结果见 E18、E21–E23、E28、E32。

**重放池存哪些片段。** 64 字节一段，优先级为该段损失；池满时替换最低者，同分换最旧；睡眠按优先级成比例抽样，提交后重算优先级（第 3.4 节）。均匀蓄水池为对照。

**记忆长度。** v0.12 中单个 16 单元 tanh 模块记不住 8 步以前的输入（E01–E13）。现行做法：输入决定的门让模块按需保持或清空状态，快记忆与中枢按内容存取，持久头跨会话，训练上下文 1,024 字节并可跨批延续状态。

**保护旧知识。**

- 在线只改低秩偏移，读出和慢权重冻结：在线改读出是遗忘的主因（E29）。低秩学习率是学多少与忘多少的权衡（E31）。
- 偏移并入是精确的，并入本身不改变输出（E31）。
- 睡眠训练慢权重时，用锚或做梦蒸馏抑制遗忘，再以两个互不相交的探针验收：新内容不变差、旧数据 bpc 增量不超过容差才提交，否则整体回滚（第 3.5 节）。验收探针与报告用的测试集分开。

**暂缓机制。** 注意力式入边门控、两级模块层级（v0.11）和动态换边（见 [8.5](../basis/8-brain-hierarchy.md)）不实现。上下文广播：v0.16 的工作空间与 v0.17 的窗口级广播都已删除（E34、第 22 章），会话级上下文由中枢承担；若再试须与中枢对照，避免重复。
