## 2　参数与显存预算

按现行 L 档配置（第 1 节）统计，以运行器打印的可训练参数数为准。v0.15 的“省内存三个位置”（稀疏连边索引、候选来源打分、对角痕迹）随换边与痕迹学习一起移出现行实现，见 [design_v0.15](../../archive/design_v0.15/current/2-memory-budget.md)。

| 部分 | 约占参数 | 说明 |
|---|---|---|
| 各模块 MLP（W₁、W₂） | 3/4 | 隐层 640，主要的容量所在 |
| 门与输入投影 B、G；快记忆 K、V、Q | 1/6 | 随 d·\|u\| 与 d·m 增长 |
| 读出瓶颈、LayerNorm、嵌入 E、偏置 | 4% | E 输入输出共享 |
| 中枢 | 2.5% | 4 头 × d_k 64，含 W_o |
| 消息投影 P | 2% | |

- 合计约 470 万可训练参数；秩 2 在线偏移另有不到 2 万个，离线冻结，不计入。
- **运行时状态**（每条流）：各层 c 与 S、中枢 4 个 64×64 矩阵，共约 3.7 万个数，固定，不随上下文增长。这是“固定内存预算”在推理端的落实。
- **训练显存由激活主导，不由参数主导。** 参数与 AdamW 状态只占几十 MB；批 × T 字节的每拍中间量（各层 c、k、v、q、β、γ、MLP 隐层，分块 delta 的块内矩阵）占绝大部分（E39、E41）。所以加大批次的代价是线性涨显存，加宽模块则主要涨 MLP 激活。
- 现行训练用批 16 × T 1024（E41 起）。用户的渲染程序常驻占用部分显存，批次按剩余显存定，溢出到系统内存时极慢（E39、E41）。
- **在线与睡眠的额外开销。** 在线阶段只有低秩偏移持有优化器状态；重放池上限 64 KiB 原始字节；睡眠时另存一份权重备份和冻结的老师副本（早晨模型、锚定老师），各一个模型大小。
