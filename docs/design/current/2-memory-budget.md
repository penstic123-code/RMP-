## 2　省内存的三个位置

| 对象 | 当前做法 | 代价或边界 |
|---|---|---|
| 不存在的跨模块连接 | 保存活动来源索引与权重。容量、活动数、预留空槽分别计数；非活动模块对不持有长期权重或优化器状态。 | 局部块内仍支付真实稠密参数的成本。 |
| 寻找新连接 | 每 16 步共享抽取 16 个候选来源。按来源累计平方和，每个预测端单独累计误差平方和、候选特征乘残差。周期结束打分并清空。 | 扫全来源更快找到新规律。追踪速度优先时试 32 个候选。128 模块版另测“邻居的邻居 + 均匀远程探索”，与均匀抽样匹配候选数。 |
| 学习活动痕迹 | 默认对角精确痕迹：B、G 每个参数一个数（第 3 节）。快记忆写入路径在线不求导；MLP 无循环，不存痕迹，只用队列里发出预测时的激活。v0.13 的 SnAp-1 保留为对照。 | 痕迹与 B、G 同样大，按 d·\|u\| 增长，不再按 d² 增长。跨层的时间影响仍被忽略，由逐层反馈部分弥补。 |

- 模块宽度 d、输入维数 |u|、快记忆维数 m、MLP 隐层 n 固定口径下，每个模块持久数值约为：门与输入投影 2d|u|，痕迹 2d|u|，MLP (d+m)n + nd，快记忆 m² + 3md，消息投影 4d，本地预测头 d（接通道）或 16d（预测邻居消息）。
- d=16、|u|=5、m=8、n=32 时，接通道模块约 2,200 个数，隐藏模块约 2,450 个，其中 MLP 约占六成；v0.13 同口径约 660 个。
- FP32 下 M=10,000 时合计约 84–93 MiB。
- 内存紧张时先把 n 降到 16（每模块约 1,600 个数）。
- |u|=5 是 v0.14 的估算口径，实际按层不同：数值流第 1 层 1，文本第 1 层 4，第 2、4 层 8，有中枢时第 3 层 12。
- 每多一个输入维度，B、G 及其痕迹共多 4d = 64 个数，第 3 层每模块因此比 |u|=5 多约 450 个数。
- 文本模式另加（e_dim = 32）：嵌入 E 8,192，投影 R 32×128 = 4,096，读出约 16,600，中枢权重约 5.5 万，中枢读路径秩 2 偏移约 1,200，中枢以下各模块 B、G 的在线偏移各 2d|u|，中枢工作记忆 2,048（加注意力窗口 16,384）。
- 若 Y 个预测端同时给 q 个共享候选打分，统计仍需 O(Yq)；逐跳反馈只用已有矩阵，不新建反馈矩阵。

**可选压缩。** 大多模块学到相似的 B、G 或 MLP 时，可比较“共享基础权重 + 少量独立偏移”与独立权重。将偏移索引、重建计算及效果损失一并统计。仅在相同任务精度下实际更省内存时采用。
