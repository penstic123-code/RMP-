## 1　系统怎样运行

本节按 [dspn_text.py](../../../dspn_text.py)（DSPNLayered、Layer）与 [hub.py](../../../hub.py) 的现状写（v0.17，第 20 章落地 + [plan/fast-clean.md](../../plan/fast-clean.md)）。v0.16 的网格、工作空间、持久头、词级层、字节自上而下层、惊讶门控、卷积与输出门已删除，全文见 [design_v0.16](../../archive/design_v0.16/README.md)。

模块分层排列，共 L 层，每层 M 个模块。完整配置写在代码的 SIZES 里（`--extra` 只覆盖个别项）。L 档：4 层 × 每层 2 个模块，d = 320，MLP 隐层 640，快记忆 m = 48，消息 q = 32，嵌入 64；第 2、3 层之间插中枢（4 头，d_k 64，τ 300 / 1k / 3k / 30k），β 上限 2，预测自身 0.01。少而宽的模块来自形状扫描（E30、E32、E33）。

### 1.0　一个模块

同层模块参数堆叠成 [M, …] 张量，一层的计算是几次批量矩阵乘，不按模块循环。每个模块在每拍：

1. **慢通道 c。** 对数门 log a = logsigmoid(G·u + b_a)，c ← a⊙c + (1−a)⊙(B·u)。b_a 初值使时间常数在 1.5–1000 拍间对数均匀分布。递推是对角线性的：可沿时间并行扫描（1.6），在线阶段也可以用资格迹精确求导（3.4 的 e-prop）。
2. **快记忆 S（m×m）。** 由 c 投影出键 k（归一化）、值 v、查询 q，写入强度 β = β_max·sigmoid(·)，保留 α = 1 − sigmoid(·)，平均保持约 64 拍。S ← αS，S ← S + β(v − S·k)kᵀ，r = S·q（门控 delta 规则）。β_max = 2 允许负特征值，能主动擦除同键旧内容（E20、E26）。
3. **局部 MLP。** h = c + W₂·GELU((W₁ + A·Bᵀ)·[c, r] + b₁)，W₂ 零初始。A·Bᵀ 是秩 2 在线偏移，离线冻结（第 3 节）。
4. **消息。** z = P·h，q 维。

### 1.0.1　层间数据流

- 第 1 层：每个模块读字节嵌入 e(t)。
- 第 ℓ 层（ℓ ≥ 2）：输入 u = [第 ℓ−1 层正下方模块的 z，同层其余模块 z 的平均]。M = 2 时即另一个模块，等价于 v0.16 的“按实际邻居数平均”（E53）。
- 中枢之上那一层另接中枢输出；每层每个模块另接 4 维广播（1.3）。
- 可选：预测学习（`pred_self` 默认 0.01、`pred_down`）、局部学习（`local`），见第 3 节。

### 1.1　输入与读出

- **嵌入。** 字节查 E（256×64）得 e(t)。
- **读出接所有层。** 全部层所有模块的 h 拼起来，经 LayerNorm，再经零初始的线性瓶颈压到 64 维 y，对数几率 = E·y + b（输入输出共享 E）。底层的字节细节可以直达读出。

### 1.2　全局记忆中枢

中枢插在第 hub_after 层与下一层之间，是唯一跨模块按内容取回的通道（E18、E21–E23、E28）。

- **读入。** 第 hub_after 层全部模块的消息，加本拍字节嵌入。
- **门控 delta 头。** k、q 归一化；S ← αS，S ← S + β(v − S·k)kᵀ，o = S·q；各头保留率初值按异质时间常数设置。会话边界全部清空：跨会话记忆由海马（episodic.py）承担，持久头从没被用上（E48、E50），已删。
- **输出。** 各头读出拼起来经 W_o，切给上一层每个模块 hub_out 维。中枢不再有在线偏移。

### 1.3　窗口级广播（取代工作空间）

- 每满 bc_window（1024）字节，中枢在末拍的读出经 RMS 归一化后存进状态；下一窗口里，所有层所有模块经零初始投影各读 4 维。零初始使起步等于无广播。
- 为什么按窗口：v0.16 的工作空间和第 20 章原定的 64 拍块末广播，都形成“下层 → 中枢 → 下一块下层”的跨块环路，训练时每 1024 字节要串行跑 16 段。按窗口广播时整窗一次并行算完；跨批次延续状态训练（`--stateful`，默认开）下，上一窗口的读出就在状态里。
- 归一化的原因同 E43：跨块非线性环路不归一化会逐块放大。会话边界之后，本窗不再读旧广播。

### 1.4　会话边界字节

字节 SEP = 30 标记会话边界。读到它时：各层 c 的对数门置 −30，快记忆与中枢的 log α 置 −30（全部清空），广播作废。输入比例 (1−a) 用原门值计算，边界处只清旧状态、不放大写入（E42）。聊天的 /new 就是输入这个字节。

### 1.5　动态分块（第 20.8 节第 3 档，`chunk=N`，默认关）

H-Net 式：模型自己决定在哪里切块，代替人手切词的 BPE。

- **编码层。** 第 1 层在字节上跑。路由 p_t = (1 − cos(q_t, k_{t−1}))/2，q、k 是编码层 h 的投影；p ≥ 0.5 即本字节开始一个新块，会话边界强制开块。
- **压缩率损失。** 0.03 · N/(N−1) · ((N−1)·F·G + (1−F)(1−G))，F 是边界比例、G 是 p 的平均，把平均块长拉向 N。
- **块层。** 中间各层与中枢只在块序列上跑。块序列定长 K = ⌈2T/N⌉：边界排在前面，其余为冻结的补齐位（不写不衰减）。
- **放回字节。** 块输出按 z̄_j = P_j z_j + (1 − P_j) z̄_{j−1} 平滑，每个字节取它所在块的值，再乘直通的置信度，把梯度送回路由。
- **解码层。** 最后一层在字节上跑，读 [编码层消息, 放回的块消息]。读出仍接所有层的 h。
- 逐拍（聊天）与整段一致；每次训练报告边界比例与“边界落在空格、标点之后”的比例（自发切词指标）。

### 1.6　计算怎样跑满 GPU

- **融合内核（flash-linear-attention，triton-windows）。** CUDA 上默认使用，`DSPN_FLA=0` 关闭：慢通道用 `chunk_hgrn`，快记忆与中枢用 `chunk_gated_delta_rule`。逐字节聊天等短序列走本地实现：扫描按块长 8 的衰减矩阵（指数恒 ≤ 0，不溢出），delta 用分块 WY 参考实现。
- **bf16 自动混合精度**（默认开）：门、递推状态与损失保持 fp32。
- **CUDA Graph。** 整个训练步录成一张图，之后每步只回放。
- **可选**：`--compile` 用 torch.compile 融合每层的门、投影、MLP 三段逐元素运算；`grad_ckpt` 按层做激活检查点，用显存换更大的批。
- 测速与结果见 E54。
