## 1　系统怎样运行

本节按 [dspn_text.py](../../../dspn_text.py)（DSPNLayered、Layer）与 [hub.py](../../../hub.py) 的现状写（v0.18：第 20 章落地 + [plan/fast-clean.md](../../plan/fast-clean.md) + [第 22 章](../candidates/22-dspn-lean.md) 精简）。v0.17 的窗口级广播、预测头族、可导分块路由已删除，全文见 [design_v0.17](../../archive/design_v0.17/README.md)。v0.16 的网格、工作空间、持久头、词级层、字节自上而下层、惊讶门控、卷积与输出门已删除，全文见 [design_v0.16](../../archive/design_v0.16/README.md)。

模块分层排列，共 L 层，每层 M 个模块。完整配置写在代码的 SIZES 里（`--extra` 只覆盖个别项）。XL5 档（约 4900 万参数，v2 预训练用）：1 个编码层 + 6 个块层 + 1 个解码层，块层 d 896、编码 / 解码层 d 256，快记忆 m 64，消息 q 48，平均块长 5，第 4 层加滑窗注意力；**没有中枢**（E59、E60：删后 bpc、长间隔取回都不变差），块层各模块快记忆保持初值在 64–205 块步间铺开（`fm_tau`），块序列长 K = 1.5T/N（`k_mult`）。XL 档（约 3200 万）同结构、d 704、q 32、带中枢。L 档：4 层 × 每层 2 个模块，d = 320，MLP 隐层 640，快记忆 m = 48，消息 q = 32，嵌入 64；第 2、3 层之间插中枢（4 头，d_k 64，τ 300 / 1k / 3k / 30k），β 上限 2。少而宽的模块来自形状扫描（E30、E32、E33）。

### 1.0　一个模块

同层模块参数堆叠成 [M, …] 张量，一层的计算是几次批量矩阵乘，不按模块循环。每个模块在每拍：

0. **输入先 RMS 归一化（pre-norm）。** 8 层叠起来时，不归一化的层间输入会逐层放大、发散（E57）。
1. **慢通道 c。** 对数门 log a = logsigmoid(G·u + b_a)，c ← a⊙c + (1−a)⊙(B·u)。b_a 初值使时间常数在 1.5–1000 拍间对数均匀分布。递推是对角线性的：可沿时间并行扫描（1.6），在线阶段也可以用资格迹精确求导（3.4 的 e-prop）。
2. **快记忆 S（m×m）。** 由 c 投影出键 k（归一化）、值 v、查询 q，写入强度 β = β_max·sigmoid(·)，保留 α = 1 − sigmoid(·)，平均保持约 64 拍。S ← αS，S ← S + β(v − S·k)kᵀ，r = S·q（门控 delta 规则）。β_max = 2 允许负特征值，能主动擦除同键旧内容（E20、E26）。
3. **局部 MLP。** h = c + W₂·GELU((W₁ + A·Bᵀ)·[c, r] + b₁)，W₂ 零初始。A·Bᵀ 是秩 2 在线偏移，离线冻结（第 3 节）。
4. **消息。** z = P·h，q 维。

### 1.0.1　层间数据流

- 第 1 层：每个模块读字节嵌入 e(t)。
- 第 ℓ 层（ℓ ≥ 2）：输入 u = [第 ℓ−1 层正下方模块的 z，同层其余模块 z 的平均]。M = 2 时即另一个模块，等价于 v0.16 的“按实际邻居数平均”（E53）。
- 中枢之上那一层另接中枢输出。
- 可选：局部学习（`local`，层间消息停梯度），见第 3 节。

### 1.1　输入与读出

- **嵌入。** 字节查 E（256×64）得 e(t)。
- **读出接所有层。** 全部层所有模块的 h 拼起来，经 LayerNorm，再经零初始的线性瓶颈压到 64 维 y，对数几率 = E·y + b（输入输出共享 E）。底层的字节细节可以直达读出。

### 1.2　全局记忆中枢

中枢插在第 hub_after 层与下一层之间，是跨模块按内容取回的通道（E18、E21–E23、E28）。XL5 起不用（`hub_after=0`）：有滑窗注意力与块层快记忆时，删中枢 bpc 与长间隔取回都不变差（E59、E60），长程由块层快记忆接管。

- **读入。** 第 hub_after 层全部模块的消息，加本拍字节嵌入。
- **门控 delta 头。** k、q 归一化；S ← αS，S ← S + β(v − S·k)kᵀ，o = S·q；各头保留率初值按异质时间常数设置。会话边界全部清空：跨会话记忆由海马（episodic.py）承担，持久头从没被用上（E48、E50），已删。
- **输出。** 各头读出拼起来经 W_o，切给上一层每个模块 hub_out 维。中枢不再有在线偏移。

### 1.3　（v0.18 删除）窗口级广播

v0.17 的窗口级广播从未单独验证，v0.18 删除（[第 22 章](../candidates/22-dspn-lean.md)）。会话级上下文由中枢逐拍给中枢之上的层；原文见 [design_v0.17](../../archive/design_v0.17/current/1-runtime.md)。

### 1.4　会话边界字节

字节 SEP = 30 标记会话边界。读到它时：各层 c 的对数门置 −30，快记忆与中枢的 log α 置 −30（全部清空），并强制开新块。输入比例 (1−a) 用原门值计算，边界处只清旧状态、不放大写入（E42）。聊天的 /new 就是输入这个字节。

### 1.5　动态分块（第 20.8 节第 3 档，`chunk=N`，XL / C 档开）

模型自己决定在哪里切块，代替人手切词的 BPE。v0.18 起边界由编码层的预测惊讶决定（同 BLT 熵分块，[第 22 章](../candidates/22-dspn-lean.md)），不再可导。

- **编码层。** 第 1 层在字节上跑。局部头（一个线性层）读停梯度的编码层 h，预测下一字节，交叉熵以 0.1 进辅助损失；停梯度使它不改主干（E45 的教训）。
- **开块。** 惊讶 s_t = 局部头对实际字节的负对数似然。惊讶跃升 s_t − s_{t−1} > θ 即从 t 开新块：整段都难预测（随机串）时惊讶持续高、不再跃升，不会逐字节开块挤爆块序列。当前块满 L_max = 3N 字节、会话边界、流的开头都强制开块。
- **阈值 θ。** 模型里的 buffer，不是状态：训练时每步按 θ ← θ + 0.1·(块率 − 1/N) 原地更新（CUDA Graph 下可用），评估与推理时冻结；冷启动、清零状态都不影响它。
- **块层。** 中间各层与中枢只在块序列上跑。块序列定长 K = ⌈k_mult·T/N⌉（默认 2，XL5 取 1.5：每行块率 99% 分位 0.254，E60）：边界排在前面，其余为冻结的补齐位（不写不衰减）；超出 K 的边界并入第 K 块，训练日志记溢出行比例。
- **放回字节。** 每个字节直接取它所在块的输出；段首尚未开块的字节取上一段最后一块的输出（存在状态里）。
- **解码层。** 最后一层在字节上跑，读 [编码层消息, 放回的块消息]。读出仍接所有层的 h。
- 状态里存局部头上一拍的对数概率、上一字节的惊讶、当前块已有字节数、当前块输出，逐拍（聊天）与整段一致。训练日志记块率、边界落在空格 / 标点之后的比例（自发切词指标）及其基准率、K 溢出、θ。

### 1.5.1　滑窗注意力（第 20.8 节第 2 档，`attn_layer`，XL / C 档开）

- 放在一个块层（XL 是第 4 层，中枢之后）：读下面一层的 h，4 头 × 64 维、不加位置编码，输出每模块 64 维作为这一层的额外输入；输出投影零初始。
- 窗口 512 个位置（块序列上约 2500 字节）。最近 512 个有效位置的键值存在状态里：跨批次训练、逐拍聊天与整段一致，内存固定。会话边界之后不看之前的位置。
- 分工：注意力管窗口内原样照抄（名字），中枢管更久以前的按内容取回，海马管跨会话。

### 1.6　计算怎样跑满 GPU

- **融合内核（flash-linear-attention，triton-windows）。** CUDA 上默认使用，`DSPN_FLA=0` 关闭：慢通道用 `chunk_hgrn`，快记忆与中枢用 `chunk_gated_delta_rule`。逐字节聊天等短序列走本地实现：扫描按块长 8 的衰减矩阵（指数恒 ≤ 0，不溢出），delta 用分块 WY 参考实现。
- **bf16 自动混合精度**（默认开）：门、递推状态与损失保持 fp32。
- **CUDA Graph。** 整个训练步录成一张图，之后每步只回放。
- **可选**：`--compile` 用 torch.compile 融合每层的门、投影、MLP 三段逐元素运算；`grad_ckpt` 按层做激活检查点，用显存换更大的批。
- 测速与结果见 E54。
