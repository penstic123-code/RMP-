## 1　系统怎样运行

模块分层排列，共 L 层，每层是一张网格，第一版为 4 层、每层 32 个模块（4×8）。第 1 层中 16 个模块各接一条外部观测通道。每个模块有 16 维线性状态 c、8×8 快记忆 S 和一个局部 MLP；模块将 MLP 输出 h 投影为 4 维消息 z。模块间消息只在同一拍内由下层传给上层：第 ℓ 层模块读取第 ℓ−1 层中正下方模块及其四邻居的消息，四邻居由坐标推算，边界不环绕。时间方向的记忆只放在各模块自己的 c 和 S 里，不经消息逐拍传播。这样时间循环全是线性的，训练时可以沿整段序列做并行扫描；v0.13 及更早的同层逐拍消息版本保留为对照，它的模块间循环经过 MLP，只能逐拍计算。第一版允许每个预测端接收至多两条活动远程入边。读出先导实验中的“三个槽”是独立实验配置。

1. 在时刻 t 观察 x(t)，先用它核对上一时刻对 x(t) 的预测。记录误差，然后用发出预测时保存的特征更新读出。第一步仅初始化。
2. 模块更新，自下而上逐层计算。输入 u：第 1 层为 [本通道当前输入]，更高层为 [下层正下方模块本拍的消息，下层四邻居本拍消息之和除以 4]。门 a = sigmoid(G·u + b_a)，每个单元一个保持率；状态 c ← a⊙c + (1−a)⊙(B·u)，不过 tanh。快记忆由 c 投影出键 k、值 v、查询 q，k 归一化后先按 S ← (1−γ)S 衰减，再写入 S ← S + β(v − S·k)kᵀ，最后读出 r = S·q；写入强度 β 和遗忘率 γ 都由 c 经 sigmoid 给出，γ 初始偏置使平均保持约 64 步。输出 h = MLP([c, r])，24→32→16，GELU；消息 z = P·h。初始化时 b_a 使时间常数 1/(1−a) 在 1–1000 步间对数均匀分布，其余矩阵随机初始化并保存种子。0<a<1 保证模块内循环稳定，模块间没有回环，不再需要 W 的谱范数检查；仍监测各层激活的饱和率。
3. 预测。每个模块有本地预测头：接观测通道的模块预测本通道 x(t+1)，其余模块预测下层输入模块下一拍的消息 z。对外读出接在最上层。在线阶段 P 冻结，消息目标不易被学习拉向常数，但不能完全排除（第 3 节）。预测端另有对外读出，基础读出采用 NLMS：以误差乘输入特征，按特征平方范数加常数归一化。远程边只进入对外读出。普通 LMS 是同等地位的低内存对照。
4. 误差到达后，按第 3 节更新在线参数。痕迹不按当前时刻更新，而是随待核对队列弹出的那条记录滞后更新，使痕迹与误差对应同一次预测。
5. 先结清旧预测的学习，再更换连边；新边权重和学习状态从零开始。反馈延迟 D 步时，队列每步保存 u、a 和 c，供滞后痕迹递推，约 M·D·(|u|+2d) 个数，计入内存。

正式接口只有观测流 step(x)。过去的读出先导实验在预测后由生成器给出目标；它们分别检验了改权重与换边的机制，尚未覆盖完整单流系统。

### 1.1　文本模式的输入与输出（v0.15）

文本模式下 x(t) 是一个字节（0–255）。

- **输入嵌入。** 字节查嵌入表 E（256×e_dim）得 e(t)，默认 e_dim = 32，16 作消融。第 1 层全部 32 个模块都接输入，模块 i 的输入 u = R_i·e(t)，R_i 为 4×e_dim，所以 |u| = 4。4 维足以区分 256 个字节，32 个模块的投影又各不相同，但投影后是否好学没有保证，要由实验确认。E 和 R 是慢权重，只在离线阶段训练，在线阶段冻结；离线训练时把 E 每行的范数约束在 1 以内，使在线读出的步长不随 E 的尺度漂移。
- **第 1 层的本地预测。** 接输入的模块预测自己下一拍的输入 R_i·e(t+1)。与消息坍缩同理，E 和 R 可训练，这个目标也能被拉成常数，所以照第 3 节规定处理：目标取 stop-gradient，本地误差不更新 E 和 R；E 和 R 只由对外读出的交叉熵训练。
- **对外读出。** 最上层 32 个模块的 h 拼成 512 维特征 f，y = W_r·f（W_r 为 e_dim×512），对数几率 = E·y + b，b 为 256 维偏置，经 softmax 得下一字节的分布。输出与输入共享 E，e_dim = 32 时读出约 16,600 个数。共享 E 带来 softmax 秩瓶颈：随上下文变化的对数几率只能落在 E 张成的 e_dim 维子空间里。这正是默认 e_dim 取 32 而不取 16 的原因。另跑一组不共享、直接 512→256 的读出（约 13 万个数）作诊断，用来判断性能是否卡在输出层。
- **在线读出学习。** 误差信号取 g = Eᵀ(onehot(x(t+1)) − p)，e_dim 维。按 NLMS 的形式更新：ΔW_r = η·g·fᵀ / (1 + ‖f‖²)，b 按 onehot − p 更新，E 冻结。f、p 取发出预测时队列里保存的值。这是交叉熵的归一化梯度，平方误差下 NLMS 的稳定性结论不能直接沿用，η 在开发种子上单独调。逐层反馈从 W_rᵀ·g 出发，与数值模式相同。
- **换边与远程边。** 文本模式的读出直接接最上层全部 32 个模块，特征只有 512 维，不做稀疏换边。换边机制只用于第 6 节第 4–7 项的多通道数值流。

### 1.2　全局记忆中枢（v0.15）

中枢是第 2、3 层之间的一层，不属于网格，也没有本地预测头。

- **读入。** 第 2 层全部 32 个模块本拍的消息 m(t)（128 维），加上本拍字节嵌入 e(t)（旁路，e_dim 维），拼成 n(t)，e_dim = 32 时 160 维。旁路的原因：第 2 层的消息是把 16 维 h 压成 4 维得到的，原样复制所需的字节身份可能在到达中枢前就丢了，中枢事后无法恢复。旁路约多 3,000 个投影参数。数值流模式没有 e(t)，n(t) = m(t)。
- **门控 delta 记忆头（默认 2 个）。** 每个头 d_k = d_v = 32。k = normalize(W_k·n)，q = normalize(W_q·n)，v = W_v·n，写入强度 β = sigmoid(w_β·n + b_β)，保持率 α = sigmoid(w_α·n + b_α)。更新 S ← α·S·(I − β·k·kᵀ) + β·v·kᵀ，读出 o = S·q。b_α 的初值使无写入时的衰减时间常数约 1,000 步，长于模块内 S 的约 64 步。这只是衰减尺度：新写入会覆盖相近的键方向，实际召回寿命可能短得多；两个 32 维头能可靠存住多少对键值，由第 6 节第 3a 项测出，不做预设。模块内快记忆的 β、γ 也统一写成带偏置的 sigmoid。形式同 Gated DeltaNet。
- **滑动窗口注意力头（可选，1 个）。** d = 32，因果掩码，时刻 t 只看 t−255 到 t，位置用 RoPE 编码相对距离，序列开头不足 256 拍时只看已有部分。目标是窗口内的原样复制，例如重复前文出现过的名字，能否做到要由实验确认。注意窗口按字节计，256 字节约合 85 个汉字。KV 缓存固定为 256×64 个数，满足固定内存的要求。窗口外的内容只能靠 delta 头保存。
- **并行训练。** 离线训练时权重在一段序列内固定，模块的 c、中枢的 S 都是给定输入后的线性递推，可以分块并行；窗口注意力按标准的因果掩码并行计算。在线阶段每拍都会改权重，只能逐拍计算。“并行扫描”只指离线训练。
- **输出。** 各头读出拼成 o，64 维或 96 维，经 W_o 投影到 128 维，切成 32 段各 4 维，第 j 段送给第 3 层第 j 个模块。第 3 层模块的输入变为 [正下方消息，四邻居平均，中枢切片]，|u| = 12。
- **为什么放在第 2、3 层之间。** 中枢读到的是经过两层加工的特征，不是原始字节；写进中枢的内容还要经过第 3、4 层处理才进入读出。放在别处作为消融（第 6 节）。
- **学习：写路径与读路径分开。** 写路径（W_k、W_v、w_β、w_α）经 S 跨时间循环，只在离线阶段训练。读路径没有循环：o = S·q，当拍把 S 视为常数时 ∂o/∂q = S，梯度精确，不需要痕迹，处理方式与 MLP 相同。在线阶段给 W_q 和 W_o 各加秩 2 偏移并在线更新（两个头的 W_q 偏移共 2×2×(160+32) = 768 个数，W_o 偏移 2×(96+128) = 448 个数），睡眠巩固时并入基础权重。中枢状态每拍更新，属于“每拍”这一速度。
- **反馈穿过中枢。** 第 3 层模块输入中“中枢切片”那部分的反馈，经 W_oᵀ 得 δo，经 Sᵀ 和 normalize 的雅可比得 δq，用于更新 W_q 偏移，再经 W_qᵀ 传给 n(t) 中第 2 层消息那部分，与正下方、四邻居路径的反馈相加。下层因此收到“与中枢读出保持兼容”的信号。经写路径的影响仍被忽略，与模块内快记忆 S 是同一种近似。
- **防止错位。** 风险：第 1、2 层在线变化后，中枢里已经写入的键与新查询可能逐渐错位。三层措施：（1）上面的读路径学习和穿过中枢的反馈；（2）中枢以下各层的 B、G 存为“基础值 + 在线偏移”，偏移每拍按 (1−ρ) 衰减，把漂移限制在基础值附近，ρ 在开发种子上调，ρ = 0 作对照，偏移计入内存（每模块 2d|u|）；（3）在线运行中定期用固定的召回探针（第 3a 项的任务）测召回准确率，下降超过开发阶段定的容差时提前进入睡眠巩固，巩固用截断 BPTT 联合训练，写路径也一起重新对齐。最简单的对照：中枢以下各层在线完全冻结，只有中枢读路径、中枢以上各层和读出在线学习。若它的在线适应不劣于完整方案，就采用它，因为机制更少。
- **工作记忆。** 中枢状态 2×32×32 = 2,048 个数，加窗口注意力 KV 缓存 16,384 个数，都计入运行内存。会话结束时清零，不巩固；长期内容只经重放池和睡眠巩固进入慢权重（第 4 节）。

**实现现状（hub.py，2026-11-19）。** 窗口大小是构造参数 window（0 表示不用注意力头）；KV 缓存只存最近 window−1 拍，当前拍现算。注意力头为单头、头维 32，q/k/v 用单独的线性层（带偏置），所以读路径在线偏移只加在 delta 头的 W_q 和总的 W_o 上，注意力头的 q 没有偏移。delta 头复用 dspn_text.py 的 delta_chunk，与上面的更新式等价。

**文本档规模（估算）。** 小档：4 层 × 32 模块，加中枢、嵌入和读出，约 33–35 万个参数，用于冒烟测试。中档：6 层 × 64 模块（每层 8×8），中枢放在第 3、4 层之间，约 94–97 万个参数，用于和同参数的小 GRU、小 Transformer 比较（TinyStories 级别的数据）。前一个数只含两个 delta 头，后一个数另含窗口注意力；均按第 2 节的显式矩阵计，本地预测头按 16d，不含偏置、秩 2 偏移、痕迹、快记忆状态和 KV 缓存。比较时须写明是否计入本地预测头和秩 2 参数，痕迹、S 和 KV 另报为运行内存。实际数以运行器统计的数组为准。

### 1.3　计算怎样跑满 GPU（v0.15）

模块多而小，按模块逐个计算时 GPU 大部分时间耗在调用开销上。“能并行训练”不等于“训练快”，实现按以下规定。

- **同层模块堆叠。** 同一层的模块形状相同，参数存成 [M_ℓ, …] 的批量张量。一层的计算是几次批量矩阵乘（einsum），不按模块循环，等效于一个 M_ℓ·d 宽的块对角层。邻居读取用固定索引 gather。各层 |u| 不同时按层分别建张量。
- **离线训练。** 张量形状为 [序列数, 时间, 模块, 维度]，在显存允许的范围内取尽量大的“序列数 × 时间”。对角线性循环用分块扫描：块内（起点 64 拍）用 log a 的累加和并行计算各拍的衰减系数，块间顺序传递状态。模块内 8×8 快记忆和中枢 delta 头用 DeltaNet 的分块算法（Yang 等，2024）。第一版用纯 PyTorch 实现，先与逐拍参考实现做数值核对（第 6 节第 1 项），再按 profiler 结果决定是否换 Triton 内核（Windows 下需 triton-windows；flash-linear-attention 已有门控 delta 规则内核）。
- **在线实验。** 多个种子或数据流作为批维一起跑，第 6 节的 100 个测试种子一次跑完。
- **单流部署。** 每拍只有几十万次乘加，放 CPU 运行，避免 GPU 每次调用的固定开销。第 6 节第 7 项分别报告 CPU 和 GPU 的步延迟。
- **吞吐门槛。** 第 3b 项同时报告离线训练吞吐（字节/秒），与同参数的 cuDNN GRU、小 Transformer 比较。开发起点：低于 GRU 吞吐的 1/3 时，先优化实现，再扩大规模。
