## 3　学习策略：三种速度

> 与主线 RMP 相关：在线学习与睡眠被 RMP 复用，见 [23.10](../candidates/23-routed-pool.md)。

在线学习只改一小部分参数，大部分知识留在离线训练的慢权重里。这样在线适应快，也不容易冲掉旧规律。本节按 [dspn_text.py](../../../dspn_text.py)（train）与 [online.py](../../../online.py) 的现状写。

| 速度 | 学什么 | 规则 | 误差来源 |
|---|---|---|---|
| 每拍 | 快记忆 S、中枢各头 | 门控 delta 写入 | 不需要误差 |
| 在线 | 秩 2 偏移（各层 MLP 第一层）或 e-prop（慢通道 B、G、b_a），二选一（B4） | 偏移：块内截断反传，AdamW；e-prop：资格迹 × 当拍误差 | 对话或文本流的下一字节交叉熵 |
| 睡眠 | 先精确并入偏移，再训全部慢权重 | 重放池上反传 + KL 锚或做梦蒸馏，验收不过即回滚 | 重放池 |
| 离线 | 全部慢权重 | 截断 BPTT + AdamW | 预训练与微调数据 |

### 3.1　学习规则的定位：与反传的区别、与大脑的对照

| 部分 | 现在的算法 | 是否反传 | 大脑里大致对应 |
|---|---|---|---|
| 离线训练 | 截断 BPTT（T = 1024，可跨批延续状态）+ AdamW | 是 | 进化与发育（把局部规则的“用法”先学好） |
| 在线学习 | 二选一：低秩偏移块内反传；或慢通道 c 的 e-prop（资格迹 × 当拍误差，跨块延续，不反传时间） | 前者是；e-prop 只在一拍之内 | e-prop：三因子规则（资格痕迹 × 神经调质） |
| 睡眠巩固 | 精确并入 + 重放池上反传 + 锚 / 做梦蒸馏 | 是 | 睡眠中海马回放、向皮层巩固（思路对应，实现不对应） |
| 快记忆、中枢写入 | delta 规则，前向时就地完成 | 否 | 海马式快速可塑、一次学会 |
| 预测外部字节（分块时） | 编码层局部头预测下一字节，读停梯度的 h；它的惊讶决定块边界（1.5） | 只训局部头 | 预测编码的单次近似 |

- 反传在生物上难成立：需要对称的反向权重、分开的前向 / 反向阶段、保存整段历史。大脑用局部规则（赫布、STDP）加第三因子（多巴胺等广播信号决定局部改动是否保留）。
- delta 规则是带纠错的赫布：纯赫布 S ← S + v·kᵀ 只会叠加，同键重写时新旧混杂；delta 把“后”项换成误差，能干净覆盖同键。纯赫布无任务目标且不稳定，不单独用于学习慢权重。
- 目标形态：快记忆用 delta 规则（已实现）；层间用本地学习（`local` 开关；v0.17 的“预测下一拍消息”头族已删，E51 的小收益由第 22 章把关决定是否恢复）；在线用资格痕迹 × 误差（三因子，e-prop，已实现于慢通道 c，见 3.4）。离线反传只负责元学习这些规则的参数。
- 关键事实：慢通道 c 是对角线性递推，对它资格痕迹可精确等于真实梯度（Zucchet 等 2023），在线阶段对 c 可不存历史、不反传而无精度损失，内存固定。MLP 与跨层部分仍需近似。
- **防止消息坍缩。** 以消息为预测目标时，最省事的解是所有消息变成常数（E45 曾为此加归一化补丁）。v0.18 改为预测外部字节（交叉熵），没有坍缩问题。

### 3.1.1　每个位置只放一个（2026-11-20 定的规矩）

学习方式按时间尺度分层，各管一件事；同一个位置出现两个就是重复，按实验留一个。新加学习方式先对照这张表。

| 位置 | 现在的唯一主人 | 竞争者 / 处理 |
|---|---|---|
| 主干训练目标 | 下一字节交叉熵（反传） | — |
| 辅助主干损失（最多一个，权重 ≤ 0.01） | 暂空 | 线性自上而下预测（22.8，F 组）与局部头不停梯度（E 组）竞争，F 不差留 F；多个辅助损失会抢梯度（E45 的 0.1 全变差，E51 两个 0.01 不叠加） |
| 切块信号 | 编码层局部头的惊讶（局部头停梯度，只训自己） | — |
| 新奇信号（在线学习门、海马写入） | 主模型损失（C6，平滑门） | 22.8 的字节级自上而下惊讶只能替换它，不能成为第三个信号 |
| 会话内快写入 | 快记忆 S、中枢的 delta 规则 | 删中枢对照（22.4 D 组）待长间隔 MQAR |
| 白天写进权重 | 低秩偏移 / e-prop | 重复，B4 按 E31 协议删输的 |
| 原句存档 | 海马 | — |
| 巩固 | 睡眠（蒸馏 + 旧语料锚定） | — |
| 功劳分配方式 | 全局反传 | `local`（层间停梯度）是同一位置的另一个选项，二选一，默认关 |
| 块率 | θ 追 1/N（不是学权重） | — |

### 3.2　缺口：选择性学习（什么值得学）

- 现状：短期记忆已会挑——快记忆与中枢每次写入有学出来的写入强度与遗忘门；惊讶门控（第 1.5 节，可选）让下层的预测误差调节上层写入强度。长期学习基本不挑：在线每 64 字节一视同仁走一步梯度；唯一筛选是重放池按损失留片段，而损失高不等于值得学（乱码同样意外）。睡眠验收与回滚是最后一道防线，不是筛选。
- 目标：在线学习率与睡眠保留由四个信号共同决定，各自做消融：
  1. 可学的意外（学习进展）：同类内容再次出现时误差是否下降；下降为规律，放大学习；不降为噪声，不学也不进池。
  2. 重复：单次出现的内容只留在快记忆与低秩偏移；睡眠时偏移按比例缩小后再并入（突触稳态假说），只有多次出现而累积的改动留下。
  3. 明确的重要性：外部信号（用户说“记住”、纠正、好评）作为第三因子放大该段学习率并提高其在池中的优先级。
  4. 来源：只从外部输入学，不从自己生成的文本学。聊天工具已按此实现（第 3.6 节）。

### 3.3　离线训练

- **优化器。** AdamW，权重衰减 0.01，但偏置、门偏置（b_a、b_γ、b_β、中枢 b_α 等）和一维参数不衰减（`param_groups`）。门偏置初值是很大的 logit，衰减会把时间常数持续拉短，长时间尺度单元逐渐失效（E35 注明此前所有训练都受影响）。
- 预热 200 步后余弦衰减，梯度范数裁剪到 1。整个训练步录成 CUDA Graph（第 1.6 节），学习率用张量原地改。每次评估存检查点，损失非有限即停，不白跑也不覆盖上一份检查点。
- **辅助损失。** 分块时编码层局部头的交叉熵经 `model.aux` 加进总损失。
- **`--stateful`：跨批次延续状态。** 每行是数据里一条连续的流，批与批首尾相接，状态带入下一批但截断梯度（截断 BPTT）。不开时每批从零状态起，模型永远练不到“记住 T 字节以前的事”，长于 T 的依赖就无从学起。v0.17 起默认开。
- **`--bot_loss`：只在模型轮次算损失。** 对话数据里，只有目标字节位于 "Bot:" 开头的行时才计损失；用户的话只作上下文。
- **`--init`：从检查点继续**，用于对话微调。对话数据由 [tools/make_chat_data.py](../../../tools/make_chat_data.py) 生成：每轮一行 "User: …" / "Bot: …"，对话之间是会话边界字节；四分之一是模板“记忆对话”（用户先说几件自己的事，最后提问），其中一半跨会话提问，中间插入的无关对话常超过 1,024 字节，配合 `--stateful` 让持久头有东西可学。名字由随机音节拼成，逼模型从上下文复制而不是背常见名。

### 3.4　在线学习（OnlineLearner）

- **在线参数二选一**（fast-clean B4 比较后只留一个）。读出、嵌入在线冻结：在线改读出是遗忘的主要来源（E29）。
  - `params='lora'`：只改各层 MLP 的低秩偏移。
  - `params='eprop'`：改各层慢通道的 B、G、b_a。c 是对角递推，每个参数配一条资格迹 e ← a⊙e + ∂c_t/∂θ（当拍），跨块延续；学习信号 δ = ∂L/∂c 只取当拍（c 设为叶子，不经上层的 c 回传）；更新 = Σ δ⊙e。对这条递推，资格迹给出的就是精确梯度（Zucchet 等 2023；tests/test_eprop.py 验证与整段反传一致），不存历史。
- **新奇门（第三因子）。** `read(text, gate)` 把 gate 乘在学习率上；gate = 0 只推进状态不学。句级新奇的算法见第 20.4 节，接入聊天工具是 fast-clean B3。
- 文本流按 64 字节分块，状态跨块延续但截断梯度；每块先记预测损失，再反传一次、走一步 AdamW。
- **重放混入**（`replay`）：每步另从池里抽 4 段（从零状态起）算交叉熵，按权重混进损失，抵消只看新内容造成的遗忘。可选 `wd`：偏移向 0 衰减。
- **重放池。** 只收满 64 字节的段，优先级是该段入池时的损失；池满时新段高于最低优先级才替换，同分换最旧。均匀对照用随机优先级实现，等价于均匀蓄水池。睡眠提交后用当前模型重算全部优先级：已学会的段让位，学不会的噪声不会凭入池时的高损失永久占位。
- 低秩偏移路线仍是块内反传；e-prop 路线已经是局部三因子规则（推导最早见 [design_v0.15 第 3 节](../../archive/design_v0.15/current/3-learning.md)）。两者的对照按 E31 协议做。

### 3.5　睡眠巩固（sleep）

1. 备份全部权重与在线参数，用两个互不相交的探针测 bpc：旧数据探针、新内容探针（未进池、未训练过）。
2. **精确并入**：W₁ ← W₁ + A·Bᵀ（中枢 W_q、W_o 同样），B 清零、A 重新随机。只并入不训练时输出完全不变（E31）。
3. 池非空时，在重放池上按优先级抽样，从零状态训全部慢权重若干步（偏移刚清零，留给第二天）。损失 = 交叉熵，可加：
   - **锚** `anchor`：KL(老师‖学生)，老师是并入后、训练前的模型，在重放片段上算。无锚时重放会破坏旧知识（E29、E31）；但老师已带白天的遗忘，锚越强越是保住遗忘后的状态（E33）。
   - **做梦** `dream`：早晨模型（白天学习前、上次提交后的模型）从换行出发自由生成若干段“梦”，在梦上加 KL(早晨模型‖学生)，保住旧分布。梦若从池中片段续写，会教模型忘掉新词（E36）；从换行生成后仍略削弱新词（E37）。
4. **验收**：新内容探针不变差，且旧数据探针 bpc 增量不超过容差（默认 0.02），才提交；否则整体回滚（含在线偏移）。提交后早晨模型更新为当前模型并刷新池优先级。之后重置优化器与会话状态。
- 现行聊天用锚定睡眠（锚 1、小学习率），这是目前唯一稳定提交的方式（E36、E37）。睡眠调参记录见 E31、E33。

### 3.6　聊天工具

[tools/chat.py](../../../tools/chat.py) 是边聊边学的命令行 demo：

- 用户每说一句，以 "User: …" 读入并在线学习；"Bot:" 前缀和模型自己生成的回答只推进状态、不学习（只从外部输入学，避免自我强化错误；第 3.2 节第 4 项）。回答采样到换行为止。
- `/new`：输入会话边界字节与换行，清短时状态，保留中枢持久头与权重（与训练一致）。
- `/reset`：全部状态清零，只剩权重。
- `/sleep`：锚定睡眠；旧数据探针取对话验证集开头，新内容探针取本次运行用户最近说的话。
- `/save`：把当前权重另存为 `_learned.pt`；`/quit` 退出。
- `--script`：每行一句输入或命令，跑完把记录存进 runs/。
