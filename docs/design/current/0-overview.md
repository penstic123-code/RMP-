## 0　一页看全：现行训练的模型（XL5，v0.18）

2026-11-20。正在训练的 v2 预训练模型的全部设计、训练与学习方式，按“从输入到输出、从训练到使用”的顺序。细节与理由在第 1–4 节，实验依据只写编号。代码：[dspn_text.py](../../../dspn_text.py)（SIZES 里的 `XL5`）。

### 0.1　一句话

字节级语言模型：窄的编码层逐字节读，按“预测惊讶突然升高”自己切块，宽的 6 个块层只在块上算（每层慢通道 + 快记忆 + MLP，一层加滑窗注意力），窄的解码层回到字节上预测下一字节。没有词表、没有中枢；推理时内存固定，不随上下文变长。

### 0.2　规模与配置

| 项 | 值 |
|---|---|
| 参数 | 约 4887 万 |
| 层 | 8 层：1 编码层（字节）+ 6 块层 + 1 解码层（字节） |
| 每层 | 2 个模块，参数堆叠成一次批量矩阵乘 |
| 宽度 | 块层 d 896、MLP 隐层 1792；编码 / 解码层 d 256、隐层 512 |
| 快记忆 | 每模块 64×64 矩阵 |
| 层间消息 | 每模块 q = 48 维 |
| 嵌入 / 读出瓶颈 | 64 维，输入输出共享嵌入 |
| 分块 | 平均块长 N = 5，最大块长 15，块序列长 K = 1.5T/N |
| 滑窗注意力 | 第 4 层（块层），4 头 × 64 维，窗口 512 个块位置（约 2500 字节） |
| 中枢 | 无（E59、E60） |

### 0.3　前向：一个字节怎样走完

1. **嵌入。** 字节查 256×64 的表 E。
2. **编码层（字节级）。** 两个模块各读嵌入，跑一遍“模块”（0.4），输出 h⁰ 和消息 z⁰。
3. **切块（0.5）。** 局部头读停梯度的 h⁰ 预测下一字节；惊讶跃升过阈值、块满 15 字节、会话边界或流开头，就从这个字节开新块。
4. **收成块序列。** 只取各块起点位置，排成定长 K 的序列；没用满的位置是冻结的补齐位（不写记忆、不衰减）。超出 K 的边界并进最后一块（训练日志记溢出）。
5. **6 个块层（块级）。** 第 1 个块层读编码层在块起点的消息；之后每层读下面一层的消息：[正下方模块的 z，同层另一模块的 z]。第 4 层另读滑窗注意力的输出（注意力读第 3 层的 h）。
6. **放回字节。** 每个字节取它所在块的块层输出（段首尚未开块的字节取上一段最后一块，存在状态里）。
7. **解码层（字节级）。** 读 [编码层消息，放回的块消息]，跑一遍“模块”。
8. **读出。** 全部 8 层的 h（块层是放回字节后的值）拼起来 → LayerNorm → 线性压到 64 维 → 乘 Eᵀ 加偏置 → 256 个字节的对数几率。

### 0.4　一个模块（每层 2 个，每拍）

0. **输入 RMS 归一化**（pre-norm；8 层不归一化会逐层放大发散，E57）。
1. **慢通道 c**（对角线性递推，同 Mamba / HGRN 一类）：log a = logsigmoid(G·u + b_a)，c ← a⊙c + (1−a)⊙(B·u)。b_a 初值让时间常数在 1.5–1000 拍间对数铺开。整段用 fla 的 `chunk_hgrn` 并行扫描。
2. **快记忆 S（64×64，门控 delta 规则）**：由 c 投影出键 k、查询 q（都 L2 归一化）、值 v，写入强度 β = 2·sigmoid(·)（允许负特征值，能擦掉同键旧内容，E20、E26），保留 α。S ← αS；S ← S + β(v − S·k)kᵀ；读 r = S·q。这等价于每拍对“键 → 值”的重构误差做一步梯度下降、带衰减的快权重（TTT-Linear）。块层各模块的保持时长初值在 64–205 块步之间铺开，长程记忆由它接管（原中枢的工作）。整段用 fla 的 `chunk_gated_delta_rule`。
3. **MLP**：h = c + W₂·GELU((W₁ + A·Bᵀ)·[c, r] + b₁)，W₂ 零初始。A·Bᵀ 是秩 2 在线偏移，预训练时冻结为 0。
4. **消息**：z = P·h（48 维），送给上一层。

### 0.5　切块：惊讶跃升

- **局部头**：一个线性层，读停梯度的 h⁰，预测下一字节，交叉熵以 0.1 加进总损失。停梯度：它只训自己，不改主干（E45 的教训）。
- **惊讶** s_t = 局部头对实际字节的负对数似然。
- **开块**：s_t − s_{t−1} > θ（惊讶突然升高，BLT 的近似单调条件）。整段都难预测时（随机串）惊讶一直高、不再跃升，不会逐字节开块挤爆块序列。另有三种强制开块：块满 15 字节、会话边界、流开头。
- **θ**：模型里的一个数（buffer），不是状态。训练时每步 θ ← θ + 0.1·(块率 − 1/5)，限制在 0–10；评估与推理时冻结。它只决定切多少刀，切在哪里由数据决定。
- **为什么不可导也行**：边界不需要梯度；编码层仍经消息、读出、解码层拿到主损失的梯度。切词能力是“预测器自己学出来的”：惊讶峰与词首对齐，训练开始约 1000 步时边界落在空格或标点后的比例就是基准率的约 2.8 倍。

### 0.6　滑窗注意力

- 放在第 4 层（块层），读第 3 层的 h，4 头 × 64 维，不加位置编码，输出投影零初始。
- 窗口 512 个块位置（约 2500 字节）；最近 512 个有效位置的键值存在状态里，跨批次训练、逐拍聊天与整段一致，内存固定。会话边界之后不看之前。
- 分工：注意力管窗口内原样照抄（名字），块层快记忆管更久以前的按内容取回（长间隔 MQAR 超出窗口也能取回，E60），海马管跨会话。

### 0.7　会话边界与状态

- 字节 30（SEP）标记会话边界（训练数据里文档之间也用它）：各层 c、S 清空，强制开新块，注意力不看边界之前。
- 每条流的状态：各层 (c, S)；分块状态（局部头上一拍的对数概率、上一字节的惊讶、当前块已有字节数、当前块输出）；注意力键值缓存。固定大小，不随上下文增长。

### 0.8　预训练怎么训

| 项 | 设置 |
|---|---|
| 数据 | data/mix，约 48 亿字节英文：TinyStories 45%、Cosmopedia 37%、SODA 对话 12%（转成 `User:` / `Bot:`）、Simple Wikipedia 6%；文档间用 SEP 分隔（E57） |
| 损失 | 下一字节交叉熵（主）+ 0.1 × 局部头交叉熵（只训局部头） |
| 批 | 8 条流 × 1024 字节；每条流是数据里连续的一段，状态跨批次延续（截断 BPTT）；每步约 2% 的行状态清零，免得只会“热”状态（E45） |
| 优化 | AdamW，权重衰减 0.01（偏置、门偏置、一维参数不衰减），梯度裁剪 1.0 |
| 学习率 | 4e-4，WSD：预热 2000 步 → 恒定 → 最后 20% 线性降到 0 |
| 步数 | 100 万步（约 82 亿字节，数据过约 1.7 遍），约 38–40 小时 |
| 计算 | bf16 混合精度（门、状态、损失 fp32）；fla 融合内核；整个训练步录成 CUDA Graph；torch.compile 融合门、投影、MLP |
| 评估 | 每 500 步：流式验证 bpc（8 条流读 4 段，第 1 段只预热）；块率、切词比例、K 溢出、θ |
| 保护 | 损失非有限或流式验证比最好差 0.5 以上就停，不覆盖检查点；另存最好的检查点 `runs/dspn-XL5_v2_best.pt`（E61） |

命令：`python dspn_text.py train dspn --size XL5 --data mix --iters 1000000 --batch 8 --T 1024 --lr 4e-4 --compile --tag _v2`

### 0.9　学习方式：四种速度，每个位置一个主人

| 速度 | 学什么 | 怎么学 | 在这次预训练里 |
|---|---|---|---|
| 每拍 | 快记忆 S | 门控 delta 写入，前向时就地完成 | 开（怎么写由预训练学出来） |
| 离线（预训练、微调） | 全部慢权重 | 反传 + AdamW | 开 |
| 在线（聊天时） | 秩 2 偏移或慢通道的 e-prop（二选一，B4 待定） | 偏移：块内截断反传；e-prop：资格迹 × 当拍误差，学习率乘新奇门 | 关 |
| 睡眠 | 全部慢权重 | 并入在线偏移，重放 + 旧语料锚定 / 做梦蒸馏，验收不过就回滚 | 关 |

- 不改权重的记忆：海马（[episodic.py](../../../episodic.py)），新奇的句子原样存，按线索召回，以 `User: … / Bot: OK.` 的格式读回上下文。
- 新奇信号（C6，未实现）：主模型损失做平滑门 sigmoid((L − 其 EMA)/τ)，管在线学习率与海马写入。
- 每个位置只放一个，见 [3.1.1](3-learning.md)：辅助主干损失目前空着（线性自上而下预测 `td_w` 与局部头不停梯度都试过，不比默认好，E59、E60）；切块信号归局部头惊讶，新奇信号归主模型损失。

### 0.10　和上一版比删了什么（v0.17 → v0.18 → XL5）

窗口级广播、预测头族（pred_self 等）、可导的分块路由四件套（余弦路由、压缩率损失、平滑、直通）、冷启动评估、中枢。依据：E58–E60（第 22 章）。

### 0.11　已知的弱点

- 读出压到 64 维、层间只传 48 维消息、没有贯穿各层的残差流：再往上扩大时要先改（第 22 章之后的扩大路线）。
- 超参数没调过（学习率、宽深比按经验定），这次训练先崩过一次（E61）。
- 删中枢只在约 260 万参数上验证过（E59、E60）。
- 聊天工具、在线学习、睡眠还没迁到这个底座；对话要另做微调。
