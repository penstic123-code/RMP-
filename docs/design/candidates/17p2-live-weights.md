## 17-P2　活权重（现成 0.6B 模型，每轮对话后立即改参数，记忆以参数为主）

### 一段话总述

用开源的 Qwen3-0.6B 做基座，**每一轮对话结束后立刻做几步梯度下降**，改一个低秩适配器（LoRA）：用户刚说的事实、刚纠正的错误、刚表现出的说话方式，在用户读回复、打下一句话的那几秒里就写进参数。记忆的归宿是参数；外置文本只是“还没学会之前的拐杖”——每条事实带一个状态，闭卷考过了就不再往提示里放。空闲时做一次巩固（合并、回放、验收、存档）。这一套最贴近用户“参数在使用中改变”的愿望，代价是比 P1 更容易出遗忘和学不牢的问题，基座也小一档。

### 结构与规模

| 部件 | 内容 | 规模 |
|---|---|---|
| 基座 | Qwen3-0.6B（Apache-2.0，28 层，非嵌入参数约 4.4 亿），bf16 全精度，冻结 | 约 1.2 GB 显存 |
| 快适配器 | LoRA 秩 8，挂全部注意力与 MLP 投影；每轮对话后更新 | 约 500 万参数（估算） |
| 慢适配器 | 快适配器的滑动平均；**回复用户时用它** | 同上 |
| 待学清单 | 每条事实：原句、自造的问答若干、状态（新 / 复习中 / 已学会）、下次复习时间 | 文本 |
| 回放池 | 惊奇最高的旧对话片段 + 基座自生成的通用对话 2,000 段（一次性生成） | 约 10 MB 文本 |
| 档案 | 每次巩固被接受的适配器 | 每份约 20 MB |

为什么选 0.6B 而不是 1.7B：每轮都要反传，一步必须在 1 秒内完成；0.6B 全精度训练（序列 256、批 8）估算每步 0.3–0.6 秒、显存约 3 GB，渲染程序同时开着也放得下（E39 的教训）。代价是智力比 P1 低一档；V1 通过后可换 1.7B 再测步时。

没有预训练。生成约 40–80 词元/秒（估算）。

### 学习方式

**离线（一次性，约 1 小时）**：让冻结基座自己生成 2,000 段通用对话，存下每个位置的输出分布（只存前 20 个词元的概率），作为永久的“别忘本”回放集。

**使用时（每轮都改参数）**。用户发来一句话后：
1. **回复**：基座 + 慢适配器生成；提示里带上待学清单中状态不是“已学会”的相关事实（按关键词与句向量匹配，最多 5 条）。
2. **造题**（回复之后，后台）：如果这句话含事实或纠正，让模型把它改写成 4–6 个问答（“我的猫叫什么？”“Zorp 是谁？”正反两个方向都要），加入待学清单。
3. **学几步**（后台，2–4 步，约 1–2 秒）：每步的批 = 一半新内容（本轮对话原文、清单里到期的问答）+ 一半回放。损失 = 新内容交叉熵 + λ·KL(基座存下的分布 ‖ 当前模型)。只更新快适配器。
4. **刹车**：每步后在 8 段固定的通用文本上量一次“与基座的 KL”。超过阈值（取历史中位数的 3 倍）就撤销这一步并把学习率减半。这是每一步都有的小验收。
5. **慢适配器跟进**：慢 ← 0.9·慢 + 0.1·快（半衰期约 7 步，即两三轮对话；公开方法里的 0.995 是给上万步用的，这里步数少，必须重定）。

所用的学习信号有三种，都不需要用户额外操作：下一词元预测（用户的话本身就是“标准答案”，学的是用户怎么说话、聊什么）；自造问答（学事实）；用户的纠正与否定（纠正句当高权重样本，被否定的回复不进训练）。

**待学清单的状态机**（间隔重复的简化版）：新事实每轮都练；空闲时闭卷考一次（关掉提示里的这条事实直接问），考过 → “复习中”，间隔按 1、3、7、21 天拉长；连续三次考过 → “已学会”，不再放进提示；任何一次考错 → 回到“新”。这样“参数里到底记住了多少”是随时可读的数字。

**空闲 / 睡眠时（巩固）**，空闲 10 分钟或每晚：
- 把清单里所有非“已学会”的条目和回放池再训 200–400 步（比在线阶段低的学习率）；
- 验收：闭卷事实题升、200 道通用题降不超过 2 个百分点、与基座的 KL 在预算内；
- 接受 → 把慢适配器存档，快适配器对齐到慢适配器；不过 → 回到上一个档案（清单还在，所以事实不丢，只是回到“靠拐杖”状态）。
- 每 30 天：用清单全集 + 回放从零重训一份适配器（约 1 小时），替换累积了一个月小步更新的旧适配器，清掉漂移。

**防遗忘**：基座冻结；只动低秩；每步一半是回放并带 KL；每步有刹车；回复用慢适配器，单次坏更新只影响十分之一；巩固有验收和档案。本项目的直接依据：只改低秩时旧知识不掉、但学得少（E29）；加回放后可把学习率提上去（E31）；全参数在线更新和无回放巩固都会毁掉旧知识（E25、E29）；用“已带着遗忘的模型”当老师的锚越强越糟（E33），所以这里的老师永远是**原始基座**；回放片段不能从含新内容的文本开头续写，否则等于教模型忘掉新词（E36），所以回放集在第一天一次性生成、与用户内容无关。

### 三种自我改进与记忆：怎么实现、怎么测

| 需求 | 实现 | 测法 |
|---|---|---|
| 会话内记忆 | 上下文窗口；同时该轮内容已开始进参数 | 同会话隔 20 轮提问 |
| 跨会话记忆 | 参数为主；未学会的条目由清单注入提示 | 新会话提问；分别报告“带拐杖”与“闭卷”两个数；隔 1 / 7 / 30 天 |
| 知识 | 自造问答 + 每轮几步 + 间隔复习 | “已学会”占比随时间的曲线；反事实换名对照；改口题 |
| 能力 | 常聊领域的对话原文持续进训练；纠正进高权重 | 用户常做任务的留出题，每周对比冻结基座 |
| 适应用户 | 用户的话作下一词元目标；偏好类指令（“短一点”）进待学清单 | 模型对用户**下一句话**的困惑度应逐周下降（对照：对陌生人文本的困惑度不变）；关掉提示后的偏好遵守率 |

“用户下一句话的困惑度”是这一套独有的、免费的指标：每轮在更新前先算一次，天然是未见过的数据。

### 为什么它可能成功

主观成功概率 **约 45%**（六条需求全部达到可演示水平，且“已学会”占比能稳定过半）。若把标准放宽为“带拐杖可用”，约 70%。理由：
- 智力与说话由基座提供，不占预算；
- 在线低秩 + 回放 + 睡眠这条链，本项目已在自己的小模型上跑通过一次完整的“学会—巩固—提交”（E31），机制上不是从零摸索；基座换成容量大得多、预训练充分的模型，低秩空间也大得多；
- 拐杖机制保证即使参数学得慢，功能上也不缺记忆；
- 每一步都可撤销，最坏情况是回到基座。

比 P1 低 30 个百分点的原因：每轮只有几步、样本只有一句话，学习率要在“学得动”和“不带偏”之间走很窄的一条线（E31、E33 已见这一权衡）；0.6B 比 1.7B 弱；长期成千上万次小更新的累积效应没有公开数据可参考。

### 验证实验（按顺序）

**V1　一句话几步能学会吗（2–3 小时）**
- 做法：20 条虚构事实，逐条走“造题 → 学 4 步”，全部教完后闭卷提问；同时测 200 道通用题。
- 对照：不更新（地板）；只训原句 4 步；造题 4 步无回放；造题 + 回放 + KL + 刹车（完整）；完整但 16 步（看步数上限）。
- 指标：闭卷答对率、通用题变化、每步用时与显存。
- 门槛：完整组闭卷 ≥ 40%，通用题下降 ≤ 2 个百分点，每步 ≤ 1 秒。
- 不过怎么办：闭卷低而 16 步组够 → 把在线步数加到 8 并接受 3 秒延迟；16 步也不够 → 在线只学风格与对话原文，事实改为空闲巩固时学（退化成 P1 的节奏，但保留每轮更新）；通用题掉 → 加大 λ、降学习率。

**V2　教 50 条之后前面的还在吗（半天）**：按顺序教 50 条，每教 10 条测一次全部已教事实。对照：有无间隔复习。门槛：最早 10 条的闭卷率不低于刚教完时的 70%。不过 → 复习比例加倍；加秩到 16。

**V3　巩固与档案（一晚）**：模拟 3 天使用（每天 20 条事实 + 真实对话），每天巩固一次。门槛：三次巩固至少两次被接受；“已学会”占比逐日上升。不过 → 巩固改用从零重训适配器的做法。

**V4　适应用户（两周真实使用）**：看“用户下一句话的困惑度”与偏好遵守率。门槛：困惑度比第一天低且陌生人文本不变；关提示后偏好遵守率 > 60%。

### 最可能失败的地方

1. **几步学不牢**：一句话 + 4 步，闭卷多半答不上，事实长期停在“新”状态。这时系统仍可用（拐杖在），但“参数为主”的卖点落空。V1 第一天就能看出来。
2. **慢性漂移**：每一步都过了刹车，但几千步后回复风格变怪、变啰嗦或开始复读用户的口头禅（下一词元目标学的是“像用户说话”，不是“对用户说话好”）。对策：只把用户的话作为低权重目标；每月从零重训；验收始终对比原始基座。
3. **自造问答质量差**：0.6B 改写时可能改错事实，等于自己教自己错的。对策：造出的问答必须含原句里的关键词，否则丢弃；保留原句本身进训练。
4. **改口**：用户更新了事实，参数里旧值还在，新旧打架。对策：旧条目状态置回“新”并把“以前是 X，现在是 Y”作为训练句；这是参数记忆天生的弱点，比 P1 的笔记本难处理。
5. **后台训练与生成抢显卡**：用户打字快时上一轮的步还没跑完。对策：新消息到达即中断未完成的步，留到下一个空隙。
