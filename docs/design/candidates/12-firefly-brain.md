# 12　萤火网络（Firefly）：类脑提案

状态：提案，未实现、未跑过任何实验。所有吞吐、显存、参数量都是估算，以 V0 实测为准。
写作时只读了文献主题文件、实验记录和 11 号文档（潮汐网络 Tide，本文的对照组），没有读其他设计文档和代码。

## 1　一段话总述

萤火网络把“学语言”拆给三种不同的学习方式，而不是全交给反向传播。**发育期**：用反向传播训练一个很小的循环编码器（占参数约 15%），训完永久冻结——相当于基因和早期发育给的先天回路，“关键期”一过就不再变。**一生中醒着的时候**：一大片“皮层柱”稀疏层读编码器的输出，每个词元只有不到 1% 的细胞亮（所以叫萤火）；它只用局部规则学习——每个突触只看自己的输入、自己的输出和送到本层的预测误差，没有跨层、跨时间的梯度。每个读出突触有快、慢两个分量：**快分量**看一遍就记住（惊奇越大写得越狠），**慢分量**小步积累。**睡眠时**：重放白天的文本并夹杂自己“做梦”生成的旧风格文本，把快分量里的内容转进慢分量，然后把快分量减半腾出容量，顺便修剪和新长连接。预期语言分数（每字节比特数）输给 Tide 和 Transformer；要赢的是：看一遍就会并且隔很久还记得、边用边学不忘旧的、学习代价和推理一样便宜且极稀疏、睡后变好。

## 2　结构与数据流

### 2.1　总览

```
词元 x_t（BPE，4096 个）
  → ① 先天编码器（嵌入 E_in + 小 GRU，冻结）        → g_t（256 维）
  → ② 时间细胞（不学习）：最近 8 个词元的嵌入 + 4 条慢衰减痕迹 → 与 g_t 拼成上下文 c_t（1792 维）
  → ③ 皮层柱层：96 个柱，每柱 128 个细胞，每柱只许 1 个细胞亮 → 稀疏码 h_t（12288 维里 96 个非零）
  → ④ 快慢读出：ŷ_t = (U + F) h_t（128 维，“预测的下一个词元长什么样”）
  → 概率 p = softmax(E_out ŷ_t)
  ⑤ 调质信号 m_t：上一步预测有多意外，控制快分量写多少
  ⑥ 白天文本池 + 睡眠
```

没有注意力层，没有多层堆叠，学习时不保存计算图。

### 2.2　① 先天编码器（唯一用反向传播的部件）

- 是什么：嵌入表 E_in（4096×128）加一个隐层 256 的 GRU。输出 g_t 概括“前文大意”。
- 为什么需要：局部规则学不好“把很久以前的信息带到现在”。已有工作里，只用固定衰减痕迹当上下文的赫布式语言模型，困惑度比 GPT-2 差一个量级，作者把原因归到痕迹把词的身份抹糊了（EMA Is Not All You Need，2026）；本项目的痕迹实验也是短时延有效、长时延无效（E08–E10）。所以“时间上的信用分配”这一小块交给反向传播，其余不交。
- 为什么冻结：稀疏层要求输入分布稳定，否则细胞大批死亡、持续学习失败（Bricken 等 2023 明说的局限）。冻结还保证这部分永不遗忘。
- 这是可以被实验删掉的部件：V1 有“完全不用反向传播”的对照（去掉 GRU，嵌入改由局部规则学）。两者差不多就删。

### 2.3　② 时间细胞（固定，不学习）

- 延迟线：最近 8 个词元的嵌入原样排开（8×128 维），保住“刚才是哪几个词、什么顺序”。
- 痕迹：`tr_k ← (1 − 1/τ_k)·tr_k + E_in[x_t]`，τ = 8、32、128、512（4×128 维），保住“这段话大概在讲什么、出现过谁”。
- 对应海马—内嗅皮层的时间细胞和皮层各区不同的内在时间尺度（本项目里层级时间尺度自己长出来过：E17、E19）。三段各自归一化后拼成 c_t。

### 2.4　③ 皮层柱稀疏层

解决的问题：把相似但不同的上下文分到几乎不重叠的细胞上（模式分离）。这样改一处记忆只动到极少数突触，别处的记忆物理上不受影响。

```
第 g 柱只看 c_t 的 192 个分量（它的“感受野” rf_g，睡眠时可换）
a_{g,i} = w_{g,i} · c_t[rf_g] − θ_{g,i}          # i = 1..128
胜者 i* = 柱内 a 最大的细胞；h_{g,i*} = a 最大值 − a 第二大值；其余细胞为 0
```

- 柱内只留一个胜者 = 侧抑制。减去第二名是 Bricken 等的做法（保留“赢了多少”的信息）。
- θ 是每个细胞自己的阈值：赢得太多就升高，太少就降低（见 3 节 L4），防止少数细胞包揽、多数细胞死掉。
- 每柱另留 16 个**储备细胞**，童年不参与竞争，成年后逐夜放出（3 节 L5）。
- 活跃比例固定为 96 / 12288 ≈ 0.8%。

### 2.5　④ 快慢读出

```
ŷ = (U + F) h            U：慢分量（参数）；F：快分量（状态，同形状，128×12288）
p = softmax(E_out ŷ + b)
ε = E_out[x_{t+1}] − Σ_w p_w · E_out[w]        # “真来的词”减“预测的词”，128 维的预测误差
```

- U 存一生积累的语言规律；F 存“最近看到、还没来得及巩固”的东西，会话结束不清空，关机存盘。
- 同一个突触两种速度，是 Hinton 与 Plaut（1987）和 Ba 等（2016）的快权重思想；这里快分量的键是稀疏的 h，不是稠密向量。稀疏键互相几乎不重叠，所以同样大小的状态里能存的互不干扰的条目比稠密键多（Sparse Delta Memory 2026 的结论方向；本设计中待 V2 验证）。
- 它等价于什么：F 让“以前在相似上下文后面出现过的词”概率升高，是神经缓存（Grave 等 2017，不用训练就明显降低困惑度）和测试时动态评估（Krause 等 2018）的固定内存、局部规则版本。

### 2.6　分词

用和 Tide 同一个 4096 词元的 BPE（会话分隔符、`User:`、`Bot:` 各占一个词元）。理由：局部规则需要干净的“一个东西”当键和目标，字节级的名字召回在本项目从未成功（E18、E23、E36）；与对照组共用分词器才好比。指标统一折算成每字节比特数（bpb）。

### 2.7　尺寸与预算

| 部件 | 算式 | 数量 | 谁来学 |
|---|---|---|---|
| E_in | 4096×128 | 52 万 | 反向传播（发育期） |
| GRU | 3×256×(128+256+1) | 30 万 | 反向传播（发育期） |
| 柱层 W | 96 柱×128 细胞×192 输入 | 236 万 | 局部规则 |
| 阈值 θ | 12288 | 1 万 | 稳态规则 |
| 慢读出 U | 128×12288 | 157 万 | 局部规则 |
| E_out、b | 4096×128 | 52 万 | 局部规则 |
| **参数合计** | | **约 528 万**（Tide 约 550 万） | 反向传播只管 15% |
| 快分量 F（状态） | 128×12288，每条流一份 | 157 万个数（6.3 MB） | 局部规则 |

- 状态比 Tide 大（Tide 的快记忆约 0.5 MB）。两者都与读了多少文本无关，但比较记忆时必须同时报“每 MB 状态记住多少条”。
- 训练方式：128 条文本流并排，一拍一拍往前走，每拍前向一次、就地改权重一次，不存计算图。显存估算：F 共 0.8 GB，其余不到 0.3 GB，峰值 < 1.5 GB（门槛 ≤ 2.8 GB，E39 的教训）。
- 吞吐估算：每拍十几个小运算，按每秒 300–1000 拍，即每秒 4–13 万词元；取下限，8 小时约 11 亿词元，约 TinyStories 两遍。瓶颈是小运算次数（E39），所以这是 V0 第一个要实测的数。不够快的退路：慢规则每 16 拍合并更新一次（快分量仍逐拍）。
- 优化器：不带动量的普通梯度步。带动量的优化器会继续推已经不活跃的细胞，在稀疏网络里明显变差（Bricken 等 2023 的消融）。

## 3　学习

### 3.1　分工表

| 编号 | 学习方式 | 改什么 | 什么时候、多快 | 用什么信号 | 对应大脑 |
|---|---|---|---|---|---|
| L1 | 反向传播（沿时间截断） | E_in、GRU | 只在发育期（约 45 分钟），之后永久冻结 | 全局误差：下一词元交叉熵，经临时读出头回传 | 进化与早期发育给的先天回路；关键期关闭 |
| L2 | 局部误差规则（慢） | U、E_out、柱层 W | 童年每拍；成年主要在睡眠 | 局部误差 ε（本层预测与真实下一词元之差），只回传一跳 | 皮层慢学习；误差到达锥体细胞顶树突 |
| L3 | 调质门控的快写入（三因子） | 快分量 F | 醒着每拍，一次写到位 | 突触前 h × 局部误差 ε × 调质 m_t（惊奇） | 海马快速绑定、早期 LTP；蓝斑去甲肾上腺素 / 乙酰胆碱报告意外 |
| L4 | 竞争 + 稳态 | 阈值 θ（以及谁当胜者） | 每拍，很慢 | 无监督：细胞自己的放电率 | 侧抑制、内在兴奋性稳态 |
| L5 | 元可塑性 + 储备细胞 | 每个细胞的可塑度 π；放出新细胞 | π 每拍累计；新细胞每夜放一批 | 无监督：细胞累计获胜次数 | 突触随使用变稳固；齿状回成年新生细胞（年轻细胞更易兴奋、更可塑） |
| L6 | 睡眠重放与巩固 | F → U 转移；F 减半；感受野剪枝与新长 | 每“夜”一次，可回滚 | 重放文本上的局部误差 ε（关掉 F 后算） | 海马—皮层系统巩固、突触标记与捕获、睡眠中突触整体下调、结构可塑性 |

### 3.2　规则公式

```
L2  ΔU[:, j]   = η · π_j · ε · h_j                       # 只有亮着的 96 个细胞的列会变
    ΔE_out[w]  = η_E · (1[w = x_{t+1}] − p_w) · ŷ
    Δw_{g,i*}  = η · π_{i*} · (U[:, i*] · ε) · c_t[rf_g]   # 只改胜者；误差沿读出权重回传一跳
L3  m_t = sigmoid((s_t − s̄) / σ_s)，s_t = −log p(x_{t+1})，s̄、σ_s 是惊奇的滑动均值和标准差
    ΔF[:, j]   = γ · m_t · ε · h_j / (hᵀh)                 # γ 约 0.3–1，比 η 大两个量级以上
L4  θ_j ← θ_j + ρ · (1[j 获胜] − 1/128)
L5  π_j = 1 / sqrt(1 + n_j / n0)，n_j = 细胞 j 累计获胜次数
```

说明：
- L2 和 L3 是**同一条规则的两种步长**：都是“突触前活动 × 送到本层的误差”。F 一步写到位，U 小步走。因为误差里已经扣掉了 U+F 的现有预测，F 只补 U 还不会的部分；U 学会以后误差变小，F 自动少写。
- 坦白：L2 对 U 和 E_out 是单层的精确梯度；对 W 用到了“沿 U 回传一跳”，数学上就是深度为 1 的反向传播。本文说的“局部”指：没有跨时间的梯度、没有跨部件的梯度、不存计算图、每次只改亮着的细胞。大脑里反馈通路不必与前向权重对称，可以用局部规则把反馈权重学成近似对称（Kolen–Pollack，Akrout 等 2019 报告在 ImageNet 上接近反向传播）；本设计先直接用 Uᵀ（E07：读出权重反馈优于随机反馈），反馈权重单独学留作后续。
- 文献提醒：赫布式规则学前馈权重未必胜过固定随机投影（EMA Is Not All You Need 2026 试了四种都没赢；果蝇模型用固定随机投影就是很强的持续学习器，Shen 等 2021）。所以 V1 有“W 固定随机”对照，赢了就把 W 的学习删掉。

### 3.3　一生的三个阶段

1. **发育期（约 45 分钟）**：只训 E_in + GRU + 一个临时读出头，标准下一词元损失。结束后丢掉临时头，冻结。
2. **童年（通宵的其余时间）**：TinyStories 为主、后段混入对话，流式读。L2–L5 全开，F 也开着（模型要在“有快分量”的条件下长大）。储备细胞不参与。
3. **成年（部署）**：醒着时 L3 全开；L2 仍在，但成熟细胞的 π 已很小，实际变化集中在年轻细胞；白天文本进池（池满时优先留惊奇高的段落，SuRe 的做法）。每夜睡一次。

### 3.4　睡眠（L6）

1. 存快照（“早晨模型”要用的是睡前模型，所以先存）。
2. 做梦：用**关掉 F 的睡前模型**从换行符开始自由生成一批文本，作为旧知识的替身（自生成重放几乎能消除遗忘，Forgetting in LMs 2026；梦不能从新内容开头续写，E36、E37 的教训）。
3. 重放：池里的白天文本与梦按 1:3 交替，**关掉 F** 做前向，用 L2 更新 U 和年轻细胞的 W。关掉 F 后，白天靠 F 才答对的地方误差变大，U 就把它学过去。
4. F ← 0.5·F（腾出快容量；已巩固的内容不再需要快分量）。
5. 结构可塑性：每柱丢掉权重总量最小的 5% 输入分量，换成随机新分量（权重从 0 起）；放出 2 个储备细胞。
6. 考试：旧语料留出集不变差、白天内容的留出探针在 F 清零条件下不比睡前差，才保留，否则回滚（E31、E33、E36 的经验；探针与报告用句分开）。

### 3.5　怎样不互相干扰

- 反向传播部件和局部部件在时间上完全错开：先发育、后冻结，稀疏层面对的是不再漂移的输入。
- 快和慢共用一个误差，天然“谁会了谁少学”，不会抢着记同一件事。
- 柱层 W 一变，稀疏码就变，F 里按旧码存的东西会失效。所以成年后 W 的改动只在睡眠第 3、5 步进行，那时 F 的内容已转给 U。
- 调质 m_t 只管 F 的写入强度，不碰慢规则。
- 不带动量，所以不活跃细胞真的一动不动。

## 4　主要卖点（可能赢的地方）

| 卖点 | 靠什么 | 为什么对照组做不到或做不好 | 怎么测 |
|---|---|---|---|
| A　看一遍就会，隔很久、跨会话还记得 | L3 快写入 + 稀疏键 + F 不清空 | Transformer 的新知识只在 1024 词元窗口里，出窗即失；想留住只能微调（全局反向传播、容易冲掉旧的：E25、E29）。Tide 的快记忆是稠密键、每头 128 维，自估容量约一千条，且键只对预训练教过的模式有效 | 每条事实只读 1 遍，隔 1 千 / 4 千 / 1.6 万 / 6.4 万词元无关文本并跨会话分隔、存盘重启后提问；报答对率，以及事实数 10 / 100 / 1000 时的答对率曲线和“每 MB 状态记住的条数” |
| B　边用边学不忘旧的（白天不重放） | 0.8% 稀疏活动 + 元可塑性 + 储备细胞 + 冻结的编码器 | Transformer 和 Tide 的主干每一步都改全部或大片稠密权重；Tide 靠单独的槽表每 256 词元反传一次、只改几十行，学得慢 | 依次读 TinyStories → 对话 → 生造词教学文本各一遍；报“新内容 bpb 下降量”对“旧内容 bpb 上升量”的折线，与 Transformer 全量在线微调（3 个学习率）、Tide 槽表、低秩偏移（E31 做法）比 |
| C　学习是局部的、稀疏的、和推理一样便宜 | L2–L5 全是局部规则，不存计算图 | 两个对照组学习都要整段反向传播，内存随序列长度涨 | 每词元活跃细胞比例；每词元被改动的参数比例；“学一个词元”与“只读一个词元”的时间比和峰值显存比；整个网络里由反向传播训练的参数占比 |
| D　睡一觉之后更好 | L6 | Transformer 没有这一步；Tide 的睡眠是全参数反向传播重放 | 连续 5 个昼夜：睡后把 F 清零，白天事实的答对率还剩多少；旧语料 bpb；第 5 天的单次学习能力是否和第 1 天一样（容量是否腾出来了） |

主推 A、B、C；D 是加分项。**预期会输的**：通宵后的语言 bpb 和生成故事的连贯性，原因见第 8 节。

## 5　和大脑的对应（类比，并说明哪里是简化）

| 部件 | 对应 | 简化之处 |
|---|---|---|
| 先天编码器 + 关键期 | 进化和发育给出的先天结构（Zador 2019 的观点）；感觉皮层关键期后可塑性骤降 | 用反向传播代替进化，只是功能上的替身 |
| 时间细胞 | 海马 / 内嗅皮层时间细胞；按对数间隔排布的时间常数（Howard 与 Shankar 的理论） | 只取 4 个时间常数加 8 格延迟线 |
| 皮层柱稀疏层 | 齿状回的模式分离；柱内侧抑制；小脑颗粒细胞 / 果蝇蘑菇体的稀疏扩张 | 每柱硬性只留 1 个胜者；没有脉冲和时间编码 |
| 快慢突触 | 早期 LTP（快、易衰减）与晚期 LTP（慢、稳固）；突触标记与捕获；海马快、皮层慢的互补学习系统 | 两种分量放在同一个突触上，而大脑里快慢更多分在不同脑区；多级级联（Benna 与 Fusi 2016）只取两级 |
| 调质 m_t | 蓝斑去甲肾上腺素、基底前脑乙酰胆碱对“意外”的广播，调节可塑性 | 只有一个标量；没有多巴胺式的奖赏信号 |
| 元可塑性、储备细胞 | 用得多的突触变稳固；齿状回成年新生神经元年轻时更易兴奋、更可塑 | 细胞数固定，储备细胞放完就没有了 |
| 睡眠 | 慢波睡眠中海马重放、系统巩固；突触稳态假说的整体下调；结构可塑性 | 重放的是存下来的原文而不是海马自己重建的；做梦只是采样 |
| 误差一跳反馈 | 顶树突接收自上而下的误差类信号（预测编码的一种解读） | 直接借用了前向权重的转置 |

不像大脑的地方：有全局的 softmax 和精确的误差计算；一拍一个词元的同步时钟；没有脉冲、没有树突非线性、只有一层皮层。

## 7　验证计划

按顺序做，前一个不过先按“不过怎么办”处理。语言指标用验证集 bpb。对照组始终包括同参数 Transformer 和 Tide。**Tide 目前也未实现**：V1 需要它的小档检查点，所以要先完成 11 号文档的 V0–V1（或同一天内一起做）；在 Tide 可用之前，用同参数 GRU 暂代并注明。所有门槛里的 bpb 差值是暂定值，V1 之后按实测噪声重定。

**V0　对拍与测速（约 30 分钟，不训练）**
- 手写的 L2 更新与自动求导算出的单层梯度一致；每拍活跃比例 = 0.8%；读 1 千与 10 万词元后状态字节数相同；128 条流时每秒拍数与峰值显存。
- 门槛：全部一致；全尺寸 ≥ 每秒 3 万词元；显存 ≤ 2.8 GB。不过：改成每 16 拍合并慢更新；仍不过就缩到 64 柱。

**V1　最小判决实验（约 3 小时）：能学语言吗？看一遍能记住吗？**
- 小档约 130 万参数（嵌入 96 维，GRU 128，48 柱×128 细胞）。每组 20 分钟墙钟，TinyStories，同种子：① 萤火完整版（其中发育 5 分钟）；② 完全不用反向传播（去掉 GRU，嵌入由局部规则学）；③ 关掉 F；④ 柱层 W 固定随机；⑤ 只有先天编码器 + 它的临时读出头；⑥ 同参数 Transformer；⑦ Tide 小档。
- 四项测试（每项几分钟）：(a) bpb；(b) 单次学习：20 条虚构事实各读 1 遍，隔 2 千词元无关故事后提问，报答案词元的首位命中率。对照：Transformer 靠上下文（窗口 1024，事实已出窗）；Transformer 与 Tide 对每条事实做一步梯度微调（学习率扫 3 档）；Tide 保留快记忆；(c) 遗忘：在线读 20 万字节对话后 TinyStories 的 bpb 变化；(d) 活跃比例、每词元改动的参数比例。
- 门槛：(a) ① 比 ⑤ 好 ≥ 0.03（稀疏层确实有贡献），且不比 ⑥ 差 0.25 以上，生成的 20 条样本语法基本通顺。(b) ① 命中率 ≥ 50%，③ ≤ 10%（证明是快分量的功劳），且不低于各对照在“旧数据 bpb 上升 ≤ 0.03”约束下的最好成绩。(c) ① 的旧数据上升 ≤ 0.03。(d) 活跃 ≤ 1%。
- 不过怎么办：② 与 ① 相差 < 0.05 → 删掉反向传播部件，全网局部学习；④ 不比 ① 差 → W 改为固定随机，删掉 L2 里 W 那一行。(a) 不过 → 先加大编码器到参数的 30%、延迟线加到 16；仍不过则“局部规则学语言”这一半判失败，快慢读出作为记忆部件移植到 Tide 上继续测 A、B。(b) 不过 → 扫 γ、把写入键限制到只看延迟线的柱；仍不过则卖点 A 不成立，提案整体不成立。

**V2　单次学习的容量与跨会话（约 2 小时）**
- 第 4 节 A 的完整测法。对照：Tide（快记忆不清空）、Transformer（窗口 1024）、萤火清空 F（应掉到瞎猜）。另加“换一种问法提问”的子集（见风险 2）。
- 门槛：100 条事实、隔 1.6 万词元时答对率 ≥ 60% 且高于 Tide；清空对照接近瞎猜。不过：加柱数；若 Tide 更好，如实记录，A 改为“持平”。

**V3　不重放的持续学习（约 2 小时）**
- 第 4 节 B 的测法。消融：去掉元可塑性（π 恒为 1）；去掉储备细胞。
- 门槛：旧内容 bpb 总上升 ≤ 0.03，同时新内容下降量 ≥ Transformer 全量微调的一半；在折线图上不被 Tide 槽表和低秩偏移同时压过。两个消融都不变差就删掉 L5。

**V4　睡眠（约 2 小时）**
- 5 个昼夜，每天 20 条新事实。对照：不睡；只重放不做梦；完整睡眠；去掉结构可塑性。
- 门槛：睡后清零 F，白天事实的答对率 ≥ 睡前（带 F）的 60%；旧语料 bpb 变化 ≤ 0.02；第 5 天单次学习答对率不比第 1 天低 5 个百分点以上；5 次考试全部通过。连续看 5 次而不是 1 次（cognition-selfimprove.md，Huxley-Gödel Machine）。不过：哪一步没用删哪一步；若不睡同样好，删掉 L6 只保留 F 的缓慢衰减。

**V5　通宵（一夜）**
- 全尺寸萤火：发育 45 分钟 + 童年约 7 小时，TinyStories 加对话。对照：Tide 与 Transformer 各自的通宵结果（11 号文档 V5）。
- 门槛：bpb 不比 Transformer 差 0.20 以上；对话不替用户续写；V2–V4 的门槛在全尺寸上仍成立；学习 / 推理时间比 ≤ 2。

**V6　一周量级循环**：每天读新对话、每夜睡。看储备细胞放完之后可塑性是否下降、F 是否被填满变噪声。只在 V1–V5 通过后做。

## 8　风险

1. **语言明显更差（最可能）。** 能跨长距离带信息的只有一个冻结的小 GRU；皮层只有一层局部学习。已核实的先例里，局部学习的语言模型与反向传播差 2–8 倍困惑度。本设计的预期是“句子通顺、故事不太连贯”。V1(a) 两小时内给出答案。
2. **换个问法就想不起来。** 快分量按“上下文的稀疏码”存取，提问时的上下文必须和学习时的足够像。原句复现、同模板提问应当有效；转述式提问可能无效（Transformer 靠反向传播学出来的键能处理转述）。V2 专门有这个子集。若失败，卖点 A 要缩窄为“原样线索下的单次记忆”。
3. **细胞大批死亡或少数细胞包揽。** 硬性单胜者 + 阈值稳态可能不够；原文靠“先全开再逐步变稀”才稳住，且要求上游冻结。备选：童年前期每柱先留 8 个胜者，逐步降到 1。
4. **睡眠转移太慢或伤到旧知识。** 成熟细胞的 π 很小，把 F 的内容转进 U 可能要重放很多遍；小模型做的梦质量差，当旧知识替身可能不够（本项目做梦式睡眠多次回滚：E36、E37）。备选：池里常驻一小份真实旧语料。
5. **逐拍循环太慢。** Windows 上没有编译加速，128 条流每拍十几个小运算（E14、E39 的教训）。有合并更新的退路，但会让“学习便宜”这个卖点打折。
6. **“局部”的成色。** 15% 参数来自反向传播，W 的规则是一跳反传。如果 V1 的 ② 远差于 ①，就得承认语言能力主要来自那个 GRU，稀疏层只是一个会持续学习的读出。这仍是有用的结论，但新意小于标题。
7. **状态预算不对等。** F 比 Tide 的快记忆大十几倍，A 的优势可能只是“状态更大”。所以必须报每 MB 的条数，并给 Tide 一个把快记忆加大到同字节数的对照。
8. **机制偏多。** L4、L5、结构可塑性、做梦各有一个消融，没有收益就删；核心只有三样：冻结的先天编码器、稀疏柱层、快慢读出。
9. **依据强度有限。** 神经科学对应多数未核实原文；所谓“全文”核实是经摘要工具读取；项目自己的实验几乎都是小档、单种子。

**失败了还能学到什么**：(1) 在这个规模上，“局部学习”到底比反向传播差多少 bpb——目前没有公开数字；(2) 稀疏键的快权重与稠密键的纠错式快记忆，每字节谁记得多——结论可以直接移植到 Tide；(3) “关键期后冻结 + 稀疏读出”能否单独提供不遗忘的持续学习；(4) 睡眠转移在局部规则下是否可行。四条里任何一条有明确答案，都能决定下一版往哪边走。
