## 23　路由模块池：规则生成的稀疏连接 + 涌现层级与分工（测试用候选）

2026-11-20。用户讨论“逻辑稀疏、计算稠密、连接由规则生成”后定的目标：这个结构**是测试用的**，回答四个问题——能否涌现层级与分工、能否抗遗忘并在线学习、能否放大后像 Transformer 那样随规模变强、是否好训练。状态：未实施、未实验；排期与过关条件见 [plan/research-lines.md](../../plan/research-lines.md)“路由模块池线”。

与已有章节的关系：
- 底座是现行 DSPN 模块（[current/1-runtime.md](../current/1-runtime.md) 1.0：慢通道 c、快记忆 S、局部 MLP、消息 z），不另造块。
- 借 TraceCols（[第 21 章](21-tracecols.md)）的原型路由、竞争学习、稳态偏置、“醒时只动权重，睡时才动结构”。区别：这里每拍选 k 个模块（不是一个专家），模块自带状态，层级由时间尺度定向的路由产生，而不是固定两级。
- 现行代码的块内计算已经是“模块内稠密、模块间固定少量连接”（同层 [M, …] 张量批量乘），所以本章不为提效而做块稀疏；要回答的是“模块很多、每拍只用少数”这种结构的能力。

### 23.1　为什么不会自动涌现

- 分工要有竞争：只有被选中的模块学习、负载均衡（侧抑制）、模块天生有差异。
- 层级要有不对称：模块完全对等时最多出现分工，不会出现层级。这里用时间尺度给出方向。
- MoE 的经验：没有额外压力时专家多按表层特征分工（标点、常见词），所以分工要直接测，不能从 bpc 推断。

### 23.2　结构

**模块池。** 块层的固定 M = 2 个大模块换成 N 个小模块（N = 16–128），每个模块就是现行模块，参数堆成 [N, …]。每个模块 i 另有：
- 地址 a_i（q 维，单位向量）；
- 时间尺度档 τ_i：慢通道门偏置按 i 在 1.5–1000 拍间对数均匀初始化（现行做法，只是按模块而非按单元分档），档位记为 ℓ_i = log τ_i。
- 稳态偏置 b_i（标量，不求导）。

**路由（每拍、块层的块分辨率）。**
- 查询 r = W_r · RMSNorm(u)，u 是本拍输入（下层消息 + 上一跳被选模块消息的加权和）。
- 选择分数 s_i = cos(r, a_i) + b_i，取前 k 个（k = 2–4）。混合权重**不含偏置**：w_i = softmax(cos(r, a_i) / T_r)，只在 k 个内归一化（同 DeepSeek 无辅助损失均衡：偏置只管选谁）。W_r 经 w_i 得梯度。
- 被选模块完整走一拍（1.0 的第 0–4 步）。**未选模块保持状态不变**（c、S 都不衰减），相当于静默的神经元保留记忆；在扫描里等价于该拍门 a = 1、写入 β = 0，并行扫描不受影响。
- 输出 o = Σ w_i · z_i，送下一跳或读出。

**层级的两个版本（先 R1 后 R2）。**
- **R1 分层池**：保留现行的层叠，每个块层换成一个池。回答分工、遗忘、规模、训练四问；层级仍是固定层。
- **R2 秩排序 + 跨级读（替代“迁移到第几层”）**：每个模块一个连续的秩 r_i，醒时冻结，每隔 P 步与睡眠中更新（按“各秩位置的查询与该模块地址的匹配度”移动）。秩小的先算；模块按地址规则从**任何**秩更小的模块读输入（跨级直连，读谁仍是规则当场算出的连接）。为并行，把秩相近的模块分成 G 波同算：G 只是并行粒度，不是语义层，模块随秩变化在波间移动。先后顺序由学出的秩决定，不由人定。可选时间尺度先验 λ（秩与 τ 档一致度加分），λ = 0 作对照。依据：MTRNN 只靠时间常数差就自组织出功能层级。
- 原“扁平池 + 多跳”不可并行训练：同一模块在不同拍被不同跳选中，其状态序列夹着不同跳的输入，模块间沿时间互相依赖，只能逐拍串行（RIMs 训练慢的原因）。
- **R3 按块延迟的自上而下反馈（开关，与 R2 正交）**：序列切成长 W 拍的块（如 64）。块内先后固定、自下而上、时间并行；块间所有模块读上一块末尾全部模块的消息（含秩更高的）。信息双向：块内向上，跨块向下。代价是按块串行（T = 1024、W = 64 时 16 步，同 Block-Recurrent 做法）。逐拍反馈会变成非线性耦合递推、只能逐拍串行，所以必须按块延迟。证据：E60 的线性自上而下预测作学习信号无收益；这里作输入通路，未测。
- **并行训练真正的约束**：一拍之内模块先后对每拍相同、拍内无环、非线性反馈必须带延迟。层不是约束。
- **哪些还是人定的**：编码层与解码层、波数 G（并行粒度，可给宽）、反馈延迟 W。涌现的是：先后顺序（秩）、谁读谁（地址）、每波几个模块（每波至少 k 个）、实际走多深（跳过选项）。
- 不采用：一拍内整图跑两遍（迭代细化，HRM/TRM 类）。拍内双向但算力翻倍，文献总结第 2 条：自回归字符任务上无可靠增益。
- **跳过选项**：每层多一个“不选任何模块”的选项，直接传残差，深度可变、计算图固定（Mixture-of-Depths 做法）。
- **R0 对照（只路由 MLP）**：模块的慢通道与快记忆仍稠密、每拍都算，只把局部 MLP 换成 N 选 k 的专家（MoE-Mamba / BlackMamba 的做法）。用来分清收益来自“路由 MLP”还是“路由带状态的模块”。

**读出与数据流。** 一拍之内计算图单向无环，环只经时间闭合：字节 → 编码层（稠密）→ 惊讶定边界切块 → 第 1 层池（选 k 个，残差加权混合得 o₁）→ … → 第 L 层 → 解码层 → 读出（所有层输出拼接，同现行）。上层信息靠状态在下一拍被用到，拍内不迭代到收敛。

### 23.3　学习规则（谁在什么时候改什么）

| 量 | 规则 | 什么时候改 |
|---|---|---|
| 模块权重 | 反向传播；只有被选模块有梯度（MoE 天然性质） | 预训练；在线时只动被选模块的秩 2 偏移或 e-prop（[current/3-learning.md](../current/3-learning.md)） |
| 查询投影 W_r | 反向传播 | 预训练；**在线时冻结**（MoE 持续学习文献：冻结旧专家仍会遗忘，原因是路由器共享参数漂移） |
| 地址 a_i | 竞争学习：被选模块的地址向查询移一小步 a_i ← norm(a_i + η_a·w_i·r)，不求导 | 预训练中；**醒时冻结，只在睡眠中更新**（同 21.1 原则 4，免得在线漂移把旧输入改路由） |
| 稳态偏置 b_i | 无辅助损失的负载均衡：b_i ← b_i + η_b·(目标负载 − 实际负载)；外加疲劳项（近期使用率越高门槛越高） | 预训练中、睡眠中；醒时冻结 |
| 未用模块分配（可选 O2） | 新奇信号高时给近期负载最低的几个模块加临时偏置，让新内容落到“空闲”模块（类似新生神经元分配） | 在线学习时 |

抗遗忘的来源（待验证，不是保证）：
- 旧内容由旧路由选中的模块负责，新内容若路由到别处，旧模块的权重与状态都不动。
- 地址与 W_r 醒时冻结，旧输入的路由不因在线学习改变。
- O2 有先例：Lifelong-MoE 在分布变化时加新专家、冻结旧专家与旧门控，旧知识保留、算力基本不变。
- 风险：路由塌缩到少数模块时，新旧内容挤在一起，退化成现行的稠密结构。

### 23.4　四个问题与测法

**Q1 能否涌现（分工、层级）。** 都与同配置随机初始化对照（同 [tools/emergence.py](../../../tools/emergence.py) 做法），新增四项：
- 模块选择性：被选模块与字节类别、词内位置、句首 / 对话轮次的归一化互信息；负载均衡度（负载分布的熵 / log N）。
- **当前字节之外的选择性**：在固定当前字节类别的条件下，被选模块与上下文类型（引号内 / 叙述、对话轮次、词内位置）的条件互信息。OpenMoE 等发现小模型专家主要按 token 分工，只测字节类别会让 Q1 轻易过关而没有意义。
- 时间尺度与抽象度对应：各模块被选时的“上下文替换剩余信息量”（E19 指标）与 τ_i 的 Spearman 相关。
- 层级（R2、R3）：学到的秩与模块 τ 的 Spearman 相关，对不更新秩的 R1；跨级读的比例；各波跳过比例；R3 开关对 bpc 与长间隔取回的影响。
- 剪除特异性：逐个关掉高负载模块，看损失是否集中在某一类字节或某一类任务（集中 = 真分工；全面变差 = 没分工）。

**Q2 抗遗忘与在线学习。**
- 沿用 E31 协议（读新故事、学生造词，测新词 bpc 下降与旧数据 bpc 上升，再睡眠）。
- 加一项顺序任务：A 风格文本 → B 风格文本（如故事 → 对话），测 A 上 bpc 回升量；与同步数的现行稠密结构比。
- 同时记路由重叠：A、B 两段的被选模块集合的 Jaccard 重叠，看遗忘是否随重叠升高。

**Q3 放大后能否像 Transformer 一样随规模变强。**
- 固定每拍激活参数与算力，只增大 N（例如 N = 8 / 32 / 128，k 固定），看 bpc 是否持续下降——这是 MoE 式放大是否成立。预期收益递减（Clark 2022：专家数收益与规模双线性），所以只要求单调，不要求线性；用“有效参数量”比较。
- 粒度：同总参数下比“更多更小的模块”（Krajewski 2024：细粒度专家在几乎所有预算下更好）。N 到上千时路由换 product key（PEER，约 √N 的检索代价，不存连接索引）。
- 再固定 N/k 比例放大激活规模（S → C 档量级），画 bpc–算力曲线，比斜率：与现行稠密 DSPN 同算力曲线比（只和自己的上一版比）。
- 用户问的是“像 Transformer 一样”：Transformer 曲线只作参照线，可选（现行代码已删 tf 基线，需要时从 legacy 取，见 23.6）。

**Q4 是否好训练。**
- 稳定性：前 3000 步不发散、无死模块（负载 < 目标 1/10 的模块比例）、路由不塌缩（负载熵不降到 0.5 以下）。
- 吞吐：原型阶段用掩码稠密计算（正确性优先，不省算力）；过了 Q1、Q2 再写按模块排序 + 分组矩阵乘（MegaBlocks 式）的版本，报字节 / 秒与显存。
- 调参量：新增超参（N、k、T_r、η_a、η_b、λ）中有几个需要扫才能训好；越少越好。

### 23.4.1　模块里面、数量与大小

- 模块内部就是现行模块（慢通道 c、快记忆 S、局部 MLP、消息 z）：沿时间循环（c、S 跨拍保留），拍内单向（u → c → S → MLP → z），每拍只有被选的 k 个更新。
- 两条约束定配置：每拍激活算力不变，k·d² ≈ 现行稠密层 2·d₀²；显存定 N 的上限（Adam 约 16 字节 / 参数，可用约 7 GB，总参数约 2 亿以内）。
- C 档量级（d₀ = 384）的扫描点：粗粒度 d = 256、k = 4、N = 8 / 16 / 32（6 层池约 0.4 / 0.8 / 1.5 亿参数）；细粒度 d = 128、k = 16、N = 128（约 1.5 亿）。m ≈ d/4、MLP 隐层 2d，沿用现行比例。
- 学习按三种速度：快——模块权重（预训练反传；在线秩 2 偏移或 e-prop，新奇信号定学多少）；中——W_r（预训练反传，醒时冻结）；慢——地址、均衡偏置、所属层（训练间隔与睡眠中，见 23.3）。

### 23.5　实现要点

- 新选项 `pool=N`、`pool_k=k`、`pool_rank=P`（0 = R1，秩不更新）、`pool_waves=G`、`pool_fb=W`（0 = 无 R3 反馈）、`pool_lambda=λ`，默认关；只动块层，编码层、解码层、滑窗注意力不变。
- 原型阶段：所有模块都算，乘选择掩码；未选模块的门 a 置 1、β 置 0，使扫描与快记忆内核（delta_chunk）照用。
- 地址与稳态偏置是 buffer，不进优化器；睡眠代码（[online.py](../../../online.py)）加“更新地址与偏置”一步。
- 测试：未选模块状态逐位不变；k = N 且 λ = 0 时与“全选的稠密池”数值一致；地址在醒时模式下不变。

### 23.6　风险与已知证据

- 路由塌缩、死模块：MoE 老问题，由稳态偏置 + 疲劳处理；Q4 直接测。
- 小规模下 top-k 调度开销吃掉省下的算力：原型不追求省算力，Q3 先看能力曲线。
- **最近的先例是 RIMs**（N 个循环模块、top-k 更新、其余状态不变），其后续发现“路由慢、模块快”迁移更好，与 23.3 一致。本章的新意只在：学到的秩决定先后、按地址跨级读、可选块延迟的自上而下反馈、地址醒冻睡更、MoE 式稳态均衡、配合快记忆与睡眠巩固。文献见 [literature/topics/routing-modules.md](../../literature/topics/routing-modules.md)。
- 带状态模块的路由比无状态专家（MoE-Mamba、BlackMamba）风险大：未选模块的状态会“过期”。R0 对照用来量这一点。
- 相关旧证据：E01 换边有效（只改权重 0.774 → 允许换边 0.125）；v0.17 的余弦分块路由在 v0.18 删去（第 22 章，与本章路由对象不同：那是切块，这里是选模块）；中枢（按内容取回）在 XL5 上删去不变差（E59、E60）。
- 自上而下预测在 E60 无收益，所以 R2 的层级不依赖它，只靠时间尺度定向。
- Transformer 参照线与“只和自己的上一版比”的约定冲突：默认不跑，用户要时再从 legacy 取同参数 tf。

### 23.7　训练速度

- **前提**：路由只看本拍下层输出，不看本层模块自己上一拍的状态。于是整段序列的路由先一次算完，每个模块再各自沿时间并行扫描，训练仍是时间并行的。
- **未选模块状态不变，使压缩计算精确**：把每个模块被选中的拍挑出来排成变长序列，用 fla 变长内核（cu_seqlens）扫完再放回，与逐拍计算逐位相同；投影与 MLP 用“按模块排序 + 分组矩阵乘”（MegaBlocks）。代价约为全算的 k/N。
- 原型阶段用掩码稠密（全算），只求正确；P1–P4 过关后再写压缩版，报字节 / 秒与显存。
- 块层本来就在切块分辨率（约每 N 字节一拍）上算，这点不变；秩更新只在训练间隔与睡眠中做，不进训练步；R3 打开时改为按块串行。

### 23.8　规则生成的连接：测什么、怎么测

本章的“连接”不存索引：第 ℓ 层的输出与第 ℓ+1 层模块 j 是否连通，由规则当场算出（j 的地址与查询的相似度进入前 k）。存下的只有每个模块一个地址。要测三件事：规则学出来是否比不学好、找邻居代价是否可控、改地址能否代替显式换边。

**五种规则**（同算力、同参数）：
- A 学到的地址（本方案）：余弦取前 k，地址竞争学习。
- B 平衡哈希（对照，不学）：按块内容哈希固定分配。Hash Layers 显示语言模型上它与学出的路由持平或更好，所以是强对照。
- C 线性门（常规 MoE）：W_g·u 取前 k，存 N×q 门矩阵。
- D 空间位置：模块排在二维片上，偏好近处模块，加连线长度代价（seRNN：这样会长成模块化小世界、功能相近的单元聚在一起）。
- E product key：A 在 N 上千时的检索版本（约 √N）。

**五项测试：**
- T1 能力：各规则的 bpc 与 23.4 Q1 指标。A 要比 B 的 bpc 低至少 0.01，或“当前字节之外”的选择性明显更高；否则学规则无用，改用哈希。
- T2 找邻居代价：路由单独计时，N = 8 … 4096，余弦全比 vs product key。选定的 N 下路由不超过一拍总时间的 10%。
- T3 结构可塑性：E01 映射整体切换任务，比冻结、只改权重、改地址（规则自动换连接）、存索引显式换边。改地址的最终误差要更接近显式换边（E01：0.125），而不是只改权重（0.774）。
- T4 稳定与可塑：睡眠更新地址前后旧探针的路由一致率至少 80%；新旧内容所选模块的 Jaccard 重叠不超过 0.5。
- T5 内存：各规则存连接的字节数，只报告。
- D 另测拓扑图：片上距离与选择性画像差异的相关（正相关 = 功能相近的模块自己聚到一起）。
