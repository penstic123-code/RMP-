## 19　定容活柱 Fixed-Budget LiveColumns：固定内存预算下持续预测 + 活柱（2026-11-20，未实施）

来源：第 18 章 [活柱网络](18-live-columns.md) 与 DSPN 立项前提（固定内存预算下持续预测、在线学习、保留旧规律）的合并，2026-11-20 用户确认写成候选。第 18 章用注意力主干，KV cache 随上下文增长，违背固定内存前提；本章换成递归主干，并因此修改柱的放置与责任估计。第 18 章的四因子规则、元训练、睡眠、假设 H1–H5 不变的部分不重复，只写差异。所有规模与吞吐为估算，未实测。

### 19.1　一句话

**冻结的递归主干（RWKV-7）提供语言能力与会话内的 delta 状态；上层通道混合旁挂一组定额的可塑柱，按块内预测误差逐层路由、按四因子规则无梯度写入；整套系统的推理内存是一个与对话长度和使用天数无关的常数，柱数到上限后长新柱必须先合并或淘汰。**

|---|---|---|---|

主干全程冻结。阶段一用 0.1B 做规则调试、0.4B 做主实验，1.5B 视显存。

### 19.3　柱的放置：只挂通道混合，单一状态路径

第 18 章的柱各自重算上 1/3 层并在输出层混合。递归主干下这会造成：① 状态分叉——每根柱要维护一份上层递归状态；② 状态过期——未被选中的柱不运行，其状态停在旧时刻，再被选中时与上下文不一致；③ 代价乘以 k。

本章改为：

```
x_ℓ → 时间混合（主干，冻结，唯一一份矩阵状态）→ y_ℓ
y_ℓ → 通道混合（主干 FFN，冻结）+ Σ_i ρ_i · Colᵢ(y_ℓ)   （只在上 8 层）
Colᵢ(y) = Bᵢ Aᵢ_lowrank(y) + Uᵢ[g(c) ⊙ ((Wᵢ + Aᵢ_快 + Aᵢ_慢)·Vᵢᵀy)]
```

- 递归状态始终只有一份，由混合后的隐状态驱动，不存在过期。
- 每词元只算 top-3 + 1 根探索柱，计算约为裸主干的 1.1–1.2 倍（第 18 章为 2 倍）。
- 代价：投票从“完整预测器在输出层投票”变为逐层专家混合，千脑式的独立预测性减弱。消融：在时间混合的输出投影上也加低秩增量，检查只改通道混合是否表达力不足。

### 19.4　责任 = 可塑性的误差

每根活跃柱在块内本就要算写入误差 δᵢ = P_tgt·e_{t+1} − ŷᵢ（下一词元嵌入经固定投影 P_tgt 的 r 维目标与柱输出的读出之差）。直接用它路由：

```
先验      πᵢ = softmax_i(cᵀ protoᵢ / τ_p)
误差统计  ε̄ᵢ ← (1−α)·ε̄ᵢ + α·‖δᵢ‖²            （只对活跃柱更新）
责任      ρᵢ ∝ πᵢ · exp(−ε̄ᵢ / T)，在活跃柱上归一化
```

同一个误差信号驱动写入（四因子规则中的 δ）与路由（ρ），不需要为每根柱额外跑前向。未被选中的柱 ε̄ 不更新，夜间全体重估（第 18 章 18.7 第 1 步）对其纠偏。

四因子写入规则沿用第 18 章 18.4：`A_快 ← (1−d)·A_快 + ρ·[η₁·NE·(δ·preᵀ) + η₂·DA·E]`，`A_慢 ← A_慢 + κ·(A_快 − A_慢)`。

### 19.6　预算驱动的结构可塑性

- **长柱条件**不变（所有活跃柱的 ε̄ 持续高于各自历史水平）。**柱数达到 N_max 时**，长新柱前必须先腾位：
  1. 优先合并：预测分布最接近的一对柱蒸馏为一根（夜间执行；白天只标记待合并，新内容暂写入责任最高的柱）；
  2. 其次淘汰：按“保留价值 = 近期累计责任 × 旧能力探针上的贡献”最低者淘汰，淘汰前把其 A_慢 蒸馏进最近的邻居柱。
- 这使“固定容量下保留什么”成为可测问题：每根柱的出生、合并、淘汰事件与遗忘曲线一起记录。对应成年神经发生与凋亡的平衡（简化）。

### 19.7　定容精确存储（补丁，可选）

纯递归主干原样召回弱于注意力（Zoology），A 是稠密小矩阵，也记不准长串（电话号码、地址）。加一张固定槽数的键值表：键 = 主干中层表示，值 = 原文片段（≤64 词元）；写入条件为惊奇 NE 高或用户明示“记住”；满了按 `价值 = 命中次数 × 时间衰减` 淘汰。读出：检索 top-2 拼到当前输入前（不进 KV，因主干无 KV，只是多读几十个词元刷新状态）。仍满足固定内存。V3 检验它相对 A 的增量；若 A 已够，删去。

### 19.8　持续预测

- 系统对任何输入流都预测下一词元：用户的话、读入的文档、自己的输出（自己的输出不产生 NE、DA）。NE、δ、ρ 每个词元都有，学习信号不依赖会话结构；用户柱学习“预测这个用户”是纯自监督。
- 可永不重置地流式运行。SEP 只清主干递归状态（会话内上下文），A、柱、精确存储保留。
- 与 DSPN 三种速度的对应：主干递归状态（每词元，会话内）→ A_快（每词元，跨会话）→ A_慢与柱慢部件（级联与睡眠）→ 冻结主干（关键期后不改）。

### 19.9　职能划分与潜在重叠

| 机制 | 职能 | 时间尺度 |
|---|---|---|
| 主干递归状态 | 会话内上下文 | 词元—会话 |
| A_快 | 跨会话的新内容、用户事实 | 会话—数日 |
| A_慢、柱慢部件 | 巩固后的知识、领域能力、用户风格 | 数日—长期 |
| 精确存储 | 需逐字的事实 | 直到被淘汰 |
| 柱的增删 | 容量分配 | 数日—长期 |

主干状态与 A_快 都是 delta 型快权重，可能重叠。V1 必须包含“只有主干状态（无 A）”一臂，A 没有增量就收缩为只做跨会话保存。

### 19.11　风险

1. **预测误差分不开语言领域**（继承自第 18 章，最大赌注）。δ 是 r 维局部误差，信息可能比输出层损失更少，V2 专门对照。
2. **只改通道混合的表达力不足**：时间相关的行为（例如记住谁在说话）可能需要改时间混合，见 19.3 的消融。
3. **元训练效率**：沿两段会话展开递归主干的反传，Windows 上 Triton 内核未验证；退到 0.1B 与纯 PyTorch 分块会限制规模。
4. **主干状态与 A 的重叠**：A 可能只在跨会话时有用，会话内无增量（V1 会显示）。
5. **定额淘汰误删**：保留价值估计不准时会淘汰仍有用的柱；淘汰前蒸馏进邻居是对策，V4 测效果。
6. **语言能力上限**：0.4B 递归主干的对话与常识弱于同级注意力模型，智力由主干决定。

### 19.12　路线

阶段一以 RWKV-7 G1 为主干验证 H1–H5 与定额机制；阶段二把主干换成自研模型（DSPN 一系放大到几千万参数），柱群层与主干无关，接口为“上层 FFN 输入 y_ℓ 与输出残差”，其余部件不改。依据同第 18 章 18.11，另加：RWKV-7 论文（[topics/fast-memory.md](../../literature/topics/fast-memory.md)，已核实）；Zoology 关于递归模型召回的结论（[topics/architectures.md](../../literature/topics/architectures.md)）；RWKV-7 G1 模型页（2026-11-20 检索：0.4B 为 L24 D1024、1.5B 为 L24 D2048，Apache-2.0）。
