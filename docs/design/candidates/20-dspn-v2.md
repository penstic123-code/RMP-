## 20　DSPN v2：精简 + 各部件接通（已选定，实施中）

2026-11-20。v0.16 的问题见 plan/v2.md 的讨论：存信息的机制有 7 套，其中持久头与情景记忆重复、工作空间与中枢重复、网格代码已名存实亡；各部件互不相通（情景记忆不进睡眠，预测误差只当辅助损失，在线学习对什么都一视同仁）。v2 只砍不加，再补三条连接。代码落地后本章内容移进 current/（先存档 v0.16）。

### 20.1　设计原则

1. **一个部件一件事，时间尺度不重叠**（20.3 的表）。
2. **一个“新奇”信号**决定什么值得记：同时管情景记忆写不写、在线可塑性开不开。对应大脑里新奇引起的神经调质（多巴胺 / 去甲肾上腺素）同时作用于海马编码与皮层可塑性。
3. **一种上下文格式**承载记忆：`User: 事实\nBot: OK.` 既是训练数据里的重现行，也是聊天时情景记忆的读回，也是睡眠蒸馏时老师看到的上下文。三处格式一致，模型学的、用的、巩固的是同一件事。
4. **海马教皮层**：情景记忆里的事实在睡眠中经上下文蒸馏进入慢权重（互补学习系统），不再永远只靠外挂查。

### 20.2　结构

```
字节 → 嵌入 e(t)
  第1层  模块 ×M        模块 = 慢通道 c + 快记忆 S + MLP（带秩2在线偏移）
  第2层  模块 ×M        输入 = [正下方模块的消息, 下层其余模块消息的平均]
   ── 中枢：门控 delta 头 ×4，τ 300 / 1k / 3k / 30k，会话边界全部清空
        ├─ 逐拍输出 → 第3、4层（同 v0.16）
        └─ 每 64 拍块末输出 RMS 归一化 → 下一块广播给所有层（取代工作空间）
  第3层、第4层
  读出：所有层 h 拼接 → LayerNorm → 64 维 → 共享嵌入 → 字节分布
模型外：海马（episodic.py）、睡眠（online.py）
```

| 部件 | v0.16 | v2 | 理由 |
|---|---|---|---|
| 网格 rows/cols/adj | 1×2 网格 + 邻居 | 每层 M 个模块，读下层“正下方 + 其余平均” | M=2 时与现行完全等价（含 nb_count 的收益，E53），删掉邻接矩阵代码 |
| 中枢持久头 | τ 10⁶，会话不清空 | 删 | 从未被用上（E48、E50）；跨会话由海马承担。选择性写入实验成功后再加回 |
| 工作空间 | 4 槽软竞争写入 + 广播 | 并入中枢：中枢块末输出直接广播 | 两条全局通道重复；E34 工作空间无益无害。保留“全局广播”这一脑机制，源头改为唯一的全局记忆。仍块延迟 + RMS 归一化（E43） |
| 广播的形式（2026-11-20 修订） | — | 改为窗口级：下层整窗读中枢上一窗口末的读出，整窗并行 | 64 拍块末广播会保留“下层 → 中枢 → 下一块下层”的串行环路，每窗 16 段串行是现在最大的训练开销；没用就删（plan/fast-clean.md A2） |
| 预测学习 | self / nb / down 可插拔 | 保留可插拔，默认 self 0.01 | 用户要求规则可混合可替换；E51 self 有益 |
| local | 开关 | 保留开关，默认关 | 局部学习是目标之一；E45 现配置差 0.17 |
| 惊奇门控写入（网络内） | 开关 | 删 | E49 持平；新奇信号改在 20.4 用于长期学习 |

### 20.3　记忆分工（时间尺度一部件一段）

| 记忆 | 时间尺度 | 写入规则 | 学什么 | 会话边界 |
|---|---|---|---|---|
| 慢通道 c | 1.5–1000 拍 | 门控对角递推 | 词内、句内的上下文 | 清空 |
| 快记忆 S（每模块） | 约 64 拍 | 门控 delta | 刚出现的片段，供原样复制 | 清空 |
| 中枢（全局） | 300–30k 拍 | 门控 delta，按内容跨模块取回 | 一次会话内的事实、话题 | 清空 |
| 广播（中枢块末输出） | 64 拍一块 | 无参数存储，只是中枢读出 | 把会话级上下文送到所有层 | 随中枢清空 |
| 在线偏移 | 一天 | 新奇门控的梯度步（20.4） | 今天反复出现的说法、用户的用词 | 保留，睡眠并入后清零 |
| 海马（情景库） | 终身 | 新奇门控写入原句（20.4） | 用户说过的、意外的事 | 保留；新会话才可召回 |
| 慢权重 | 永久 | 睡眠：上下文蒸馏 + 锚定（20.5） | 语言、常识、巩固后的事实 | 保留 |

快记忆与中枢都用 delta 规则，但分工不同：S 在模块内、窗口短、管复制；中枢跨模块、窗口长、管取回。

### 20.4　新奇信号与它管的两件事

- **定义。** 用户一句话读入时，模型对这句话字节的平均交叉熵（bpc）记为 n。保留最近 64 句的 n，取中位数 med。新奇 = n > med（同 EM-LLM 用 token NLL 作惊奇；不用网络内预测误差，E49 显示它作写入门持平）。
- **海马写入。** 陈述句且新奇才写入；问句不写（同 v0.16）。寒暄（“Hi again!”）之类低 n 的句子自然不进库，库更干净，相似事实之间的混淆减少。
- **在线可塑性。** 新奇的句子才走在线梯度步（学习率不变），不新奇的只推进状态。在线学习从“每句都学”变成“只学意外的”，减少在线偏移的无用漂移（E41 记录的睡后退化疑因之一）。
- 冷启动：前 8 句没有中位数时全部视为新奇。

### 20.5　睡眠：海马教皮层

顺序：并入在线偏移（精确）→ 训练慢权重 → 验收 / 回滚 → 偏移清零。训练信号三项：

1. **当天蒸馏**（同 v0.16）：老师带状态读完当天全部字节，学生从零状态只看窗口。
2. **事实蒸馏**（新）：对当天每个窗口，用海马按窗口文本召回相关事实（含以前会话的）。老师 = 读回这些事实（20.1 第 3 条格式）再读窗口；学生 = 只读窗口。学生学会“不查也像知道这些事一样回答”，事实由此进权重。召回为空的窗口只做第 1 项。
3. **旧语料锚定**（同 v0.16）：旧对话随机窗口上 KL(并入前模型‖学生)。

验收沿用新旧两探针；另加一项事实探针：海马中本次参与蒸馏的事实，关掉召回问一遍，记录答对数（只记录不设门槛，用来看巩固是否在发生）。

### 20.6　训练与数据的配合

- 预训练：E53 采纳项（pred_self 0.01、WSD），`--stateful`，fla 内核视基准结果。
- 对话微调：chat3 数据（含重现行，格式同 20.1 第 3 条），`--stateful --bot_loss`。
- 去掉持久头后，跨会话样例的作用变为训练“读回的事实怎样用”，不再指望状态跨几千字节保持。

### 20.8　主干可替换，涌现靠指标守住（2026-11-20 用户：1–3 档都可以，但不能失去涌现）

主干只需满足一个接口：`forward(x, state) → (logits, state)`，整段与逐拍同式，读到 SEP 清空会话状态。海马、睡眠、新奇信号、在线学习、跨批次延续状态与对话格式都不依赖主干。允许的主干：

| 档 | 主干 | 用途 |
|---|---|---|
| 1 | 门控 delta（Gated DeltaNet）或 RWKV-7 块，fla 内核，字节级 | 与 DSPN v2 主干同墙钟对比 |
| 2 | 档 1 + 每 3–4 层一个滑窗注意力 | 只为原样复制（名字抄错是 demo 最大短板） |
| 3 | 缩短序列：**优先用动态分块代替 BPE** | 训练快 |

**涌现原则**：不靠结构写死，也不因换主干丢掉。BPE 是人手切词，会丢掉“自己切出词”的涌现，所以第 3 档先用 H-Net 式动态分块（相邻表示余弦差判边界，压缩率损失约束平均块长 4–6 字节；第 13 章 13.2），BPE 只作速度对照。另外两种涌现与主干无关：稀疏正激活带来的单元分工（v2.1-a），注意力头里自发形成的复制 / 归纳头（第 2 档）。

**涌现指标**（tools/analyze_hierarchy.py 扩展；换主干、加机制时必须报告，任何一项明显退化不采纳）：

| 指标 | 量什么 | 基准 |
|---|---|---|
| 时间尺度层级 | 各层门的中位时间常数，顶层 / 底层之比 | E46：137 / 30 ≈ 4.6，随机初始化 ≈ 1 |
| 自发切词 | 动态分块的边界与空格、标点的重合率（从未告诉它词在哪） | 随机边界的重合率 |
| 单元分工 | 激活稀疏度、单元对字节类别 / 词内位置的选择性、共激活图模块度（BDH 的量法） | 同配置随机初始化 |
| 复制能力的相变 | 训练过程中重复随机串的复制准确率，看是否突然跃升 | 训练早期检查点 |
| 中枢分工 | 各头实际召回距离分布是否按 τ 分开 | 初值 τ 谱 |
