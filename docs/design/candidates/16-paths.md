## 16　四条路线：从“最稳”到“最野”（2026-11-20 提案，未实施）

来源：按用户 2026-11-20 的五条要求重新设计——训练不能太慢、有智力、会英文对话、能持续改进自己（知识 / 能力 / 适应用户三种都要）、有会话内与跨会话记忆。目标是“最有可能做成”，不是“最新奇”。读过文献目录（[literature/](../../literature/README.md)）、实验 E14–E40（[experiments/](../../experiments/README.md)）与第 9–15 章；不受前面任何一章约束。标“推测”的没有直接证据；“本次核实”指 2026-11-20 打开过原文摘要或项目页。

### 16.1　先说结论

- 四套方案共用同一个“生活层”（聊天程序、笔记本、白天缓冲、睡眠流水线、考试、成长曲线评测），只换“脑子”。生活层与脑子无关，写一次四套都能用，细节见 [16a-graft.md](16a-graft.md) 16a.3–16a.5。
- 采纳用户对第 15 章的修改意见：**醒着不改稠密权重；睡眠时在“复习旧数据 + 锚定早晨模型 + 按重要性限制步长 + 考试既不退步又有进步”四个条件下慢慢改**。第 15 章“成年后一个数都不改”只能长知识，长不了能力，这里推翻。
- 推荐顺序：先做 A（几天内能聊、能记、能睡），同时让 B 的预训练在夜里跑；B 是自己训练的基线；C、D 是在同一套评测下对 B 的升级，赢了才换。

### 16.2　四套方案

| 代号 | 名字 | 一句话 | 文件 |
|---|---|---|---|
| A | 嫁接 Graft | 现成小模型（3.6 亿参数、已会说话）不重训，外接笔记本记忆，睡眠时训一个小插件并逐步并入 | [16a-graft.md](16a-graft.md) |
| B | 朴素 Plain | 自己从零训一个标准小 Transformer（0.5–1 亿），记忆靠笔记本，睡眠时直接慢改稠密权重 | [16b-plain.md](16b-plain.md) |
| C | 回响改 Echo-S | 自训混合主干（门控 delta + 滑窗注意力），记忆长在网络里（持久头 + 稀疏槽表），睡眠慢改稠密权重 | [16c-echo-s.md](16c-echo-s.md) |
| D | 回响全 Echo-X | 在 C 上加思考回路、自我模型的“意外”调质、自己挑薄弱处练习、睡眠超参自我进化 | [16d-echo-x.md](16d-echo-x.md) |

### 16.3　对比表

“做成”的定义：在这台笔记本上做出 demo，五条要求都有可测的正结果——三种自我改进各有一条向上的成长曲线，同时旧能力不退。成功概率是主观估计。

| 项目 | A 嫁接 | B 朴素 | C 回响改 | D 回响全 |
|---|---|---|---|---|
| 核心思路 | 借现成的脑子，只做“生活层” | 标准结构 + 高效训练配方，创新只放在睡眠 | 把记忆做进网络：快状态、持久头、槽表 | 再加会“多想几遍”和“知道自己不知道” |
| 训练速度 | 不用预训练；每次睡眠 5–15 分钟（推测） | 通宵档 0.5 亿 / 约 10 亿词元；两天档 1 亿 | 同参数约为 B 的 0.5–0.7 倍吞吐（推测，取决于内核） | 约为 B 的 0.3–0.5 倍（多遍） |
| 智力上限 | 四套里最高：基座读过 4 万亿词元，本机永远训不出 | 能讲通顺英文、懂简单常识；推理弱、会编造 | 与 B 同级；长记忆与召回可能更好 | 与 B 同级，推理题可能略好（证据弱） |
| 对话 | 基座自带对话与指令能力 | 靠对话续训（SmolTalk、TinyChat 等） | 同 B | 同 B |
| 知识（记事实、新词、个人信息） | 白天记笔记本；睡眠把事实改写成问答训进插件 | 白天记笔记本；睡眠训进稠密权重 | 白天写持久头与槽表；睡眠转入槽表 | 同 C，意外大的才写 |
| 能力（常聊领域、常做任务） | 睡眠按白天话题从本地语料库挑文档读，训插件 | 同左，直接训稠密权重（带重要性限步） | 同 B | 同 B，另按“自己预计会错”的话题优先练 |
| 适应用户 | 偏好写进笔记本的“档案行”；睡眠训用户认可 / 纠正过的回答 | 同 A | 同 A，档案进持久头 | 同 C |
| 会话内记忆 | 上下文窗口（约 8k 词元，未核实） | 上下文 2048–4096 词元 | 快状态 + 滑窗 512，长度不封顶 | 同 C |
| 跨会话记忆 | 笔记本检索（文本，精确） | 笔记本检索 | 持久头 + 槽表；笔记本作对照与保底 | 同 C |
| 实现难度 | 低：约 1 周，无新内核 | 中：高效训练器 + 数据管线，约 2 周 | 高：新主干、分块内核、跨批带状态、槽表 | 很高：C 之上再叠 4 个机制 |
| 成功概率 | 约 75% | 约 50% | 约 30% | 约 10–15%（全部机制都值得保留） |
| 概率理由 | 语言与对话已有；风险只剩睡眠的长期漂移和基座“太满”学不进 | 结构零风险；风险在本机算力下的智力与吞吐达标 | E28、E32 支持 delta 记忆，但自然文本召回 E18、E23 失败过；槽表原文规模大两个数量级 | 思考回路在语言上无可靠收益的文献多；E34、E35、E40 说明加机制常持平或变差 |
| 算力与数据 | 下载基座约 0.7 GB；不需云 | 下载 FineWeb-Edu、Cosmopedia、SmolTalk 等约 6–10 GB；本机 1–2 夜。可选云预训练（百美元级） | 同 B，训练时间约 1.5–2 倍 | 同 B，训练时间约 2–3 倍 |
| 是否“自己的架构” | 不是，脑子是别人的 | 结构不是，睡眠与成长机制是 | 是 | 是 |

### 16.4　推荐

**先做 A，同时起 B；C、D 以 B 为对照按门槛晋级。**

1. **A 最先**：五条要求里“会说话”“有智力”在本机算力下最难，A 把它们直接买来，一周内就能验证真正没人替你做的部分——三种自我改进的睡眠流水线与考试。A 的智力也是另外三套的上限参照：如果连 3.6 亿参数的现成模型都聊不好，0.5 亿自训模型更不会好。
2. **B 同步**：B 的预训练只占夜里的显卡，白天做 A。B 的高效训练器、分词、数据管线是 C、D 的前置；B 训完后把 A 的生活层原样接上，就得到“全部自己训练”的版本。
3. **C 是架构创新的主战场**，但只在 1000 万参数的同墙钟对照里赢过 B 才放大（门槛见 16c.6）。输了也有用：C 的持久头、槽表可以单独嫁接进 B。
4. **D 的四个机制逐个加**，每个都和“同算力加宽”比，赢一个留一个。
5. A 做成后，用户已有可用的东西；之后每一步都是“更像自己的架构”，而不是“终于能用”。

### 16.5　与前面各章和实验的关系

- 第 15 章 Echo：C 是它去掉思考回路与自我模型、并把“冻结”改成“睡眠慢改”的版本；D 是把这两样加回来，并按用户意见改睡眠。
- 第 13 章：规模与两阶段数据沿用；字节级与动态分块不用（E38、E40）。
- 睡眠的做法全部来自本项目已有结果：只并入无损、锚定睡眠能提交（E31）；锚的老师必须是早晨模型（E33）；梦不能从白天片段续写、自由做梦仍会削弱新词（E36、E37）；遗忘主要来自共享读出层（E25、E29）。
- 不做全局工作空间（E34、E35）、不做词级层级（E38）。

### 16.7　最大的风险（跨方案）

1. **睡眠的考试题就是天花板**：考试集小而固定，模型会学到“只在考题上不退步”。对策：考试集轮换、每周一次大考（完整留出集），大考退步就回到档案里更早的版本。
2. **能力成长的幅度可能很小**：一晚读几十万词元，对任何模型都只是微调。能测出来的多半是“该领域文本更好预测、该领域选择题略升”，不是肉眼可见的变聪明。要靠几十夜累积，且必须和“读随机文档”对照。
3. **自训模型的智力受算力限制**：0.5–1 亿参数、十亿词元，与 A 的基座差三个数量级的数据。B、C、D 的卖点是“自己的、会成长的”，不是比 A 聪明。
4. **适应用户的信号稀疏**：真实用户很少点评。先用模拟用户脚本验证机制，再靠真实使用积累。
