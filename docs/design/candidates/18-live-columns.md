## 18　活柱网络 LiveColumns：会长出新柱的神经调质可塑柱群（2026-11-20，N2 + N4 合成，未实施）

来源：用户选定 [17-N2 神经调质三因子可塑性](17n2-neuromod-plastic.md) 与 [17-N4 千脑投票柱](17n4-voting-columns.md) 合并。依据、验证顺序与风险见 [18-live-columns-plan.md](18-live-columns-plan.md)。所有吞吐、显存都是估算，没有实测。

### 18.1　一句话

**冻结的现成小模型上面并排长着许多“皮层柱”；每根柱里有一块会自己变的突触，聊天时按大脑的三因子规则直接改写（不用反向传播），改写规则本身是离线学出来的；哪根柱该说话、该学习，由它预测得准不准决定；都预测不好就长新柱，睡觉时合并、修剪、巩固。**

### 18.2　为什么合起来比各自强

| | N2 单独 | N4 单独 | 合起来 |
|---|---|---|---|
| 使用中怎么学 | 局部规则，无反传，快 | 每轮反传，一条事实要 10–20 步、多约一秒延迟 | 局部规则，无反传 |
| 容量 | 一块固定大小的小矩阵，学多了互相干扰 | 柱可以长，容量随需要增加 | 柱可以长 |
| 学到哪里 | 树突门按情境选单元 | 按预测误差分配“责任” | 责任决定写进哪根柱，树突门细分柱内单元 |
| 防遗忘 | 树突门、级联、范数上限 | 责任低的柱几乎不动 | 两者叠加 |

### 18.3　结构

```
用户的话 → 冻结主干的下 2/3 层（每个词元只算一次）→ 语境表示 c
                │
                ├→ 路由：c 与每根柱的原型比 → 先验；再乘“最近谁预测得准” → 责任 ρ
                │
                ├→ 取责任最高的 3 根柱 + 随机 1 根（探索），各自跑主干上 1/3 层
                │     每根柱 = 慢部件（低秩增量，秩 8）+ 可塑块（A_快、A_慢，r×r）
                │
                └→ 按责任加权混合各柱的预测 → 回答
调质核（读主干与对话）→ 惊奇 NE、不确定 ACh、奖惩 DA 三个标量
```

| 部件 | 做法 | 规模 |
|---|---|---|
| 主干 | Qwen2.5-0.5B-Instruct（备选 SmolLM2-360M-Instruct），全程冻结，保证会说话、有常识 | 约 5 亿，半精度约 1 GB |
| 柱的慢部件 | 主干上 1/3 层（约 8 层）MLP 旁的低秩增量，秩 8；只在离线与睡眠里用反传改 | 每根约 60–80 万 |
| 柱的可塑块 | 同样 8 层，每层 `h ← h + U·[g(c) ⊙ ((W + A_快 + A_慢)·Vᵀh)]`，r=128；U、V、W 是慢参数，**A_快、A_慢 在聊天时变** | 每根约 26 万个会变的数 |
| 树突门 g(c) | 柱内每个单元有几个“树突段”，与语境匹配，只放行前 20% 的单元（活性树突） | 可忽略 |
| 原型与损失统计 | 每根柱一个原型向量（“我擅长什么语境”）和一个近期预测损失的滑动平均 | 可忽略 |
| 调质核 | 惊奇 = 本段损失相对其滑动平均的偏差（不用学）；不确定 = 小头预测自己下一句的损失（自我模型）；价值头 = 读用户下一句，输出奖惩 | 约 200 万 |
| 柱数 | 出厂 8 根（离线训好的通用柱），上限 32 根；另有一族“用户柱” | 32 根合计约 3000 万 |

柱分两族：**回答柱**负责生成；**用户柱**只在用户的话上竞争、学着预测这个用户会怎么说，它们的内部表示经小投影加进语境 c，让回答受“这个用户通常想要什么”影响（心智理论的最小形式）。

计算量：每个词元约为裸主干的 2 倍（4 根柱各算上 1/3 层）。聊天时的学习只是几次 r×r 矩阵加法，几乎不加延迟。存盘：全部柱约 100 MB。

### 18.4　四个因子的学习规则（聊天时，每个词元、每层）

大脑的三因子规则说：突触先记下“前后神经元一起活跃过”（资格迹），稍后调质信号来了才真正改。这里再加一个“空间因子”——责任，决定改哪根柱：

```
资格迹    E ← λ·E + post·preᵀ                       （因子 1：谁和谁一起活跃过）
误差      δ = 目标 − 预测                            （目标 = 下一词元嵌入经固定投影，块内局部可得）
快突触    A_快 ← (1−d)·A_快 + ρ·[ η₁·NE·(δ·preᵀ) + η₂·DA·E ]
                                ↑责任              ↑意外时按误差纠正   ↑奖惩来时强化或削弱刚才的痕迹
慢突触    A_慢 ← A_慢 + κ·(A_快 − A_慢)              （级联：快的慢慢渗进慢的）
读取      不确定 ACh 高时，多信 A_快（新写的）；低时多信 A_慢
```

- **因子 1 资格迹**：赫布学习，局部。
- **因子 2 调质**：NE（意外就多学）、DA（用户下一句是肯定还是纠正，迟一轮到，靠资格迹对上号）、ACh（读的时候信新还是信旧）。
- **因子 3 责任 ρ**：预测得准的柱才学，预测不准的柱不动——新东西不会写进不相关的柱，这是防遗忘的主机制。
- 系数 λ、d、η₁、η₂、κ 和调质核都不是人定的，是**元训练**出来的（18.6）。

### 18.5　结构可塑性：长柱、修剪、合并

- **长新柱**（模仿齿状回成年新生神经元）：连续若干轮所有活跃柱的损失都明显高于各自历史水平，说明遇到了没见过的东西。复制当前责任最高的柱的慢部件、可塑块清零、原型设为当前语境，作为新柱加入。
- **个人事实**：惊奇度高或用户明说“记住”时，对个人柱连续施加几次规则更新（用主干自己生成的 3–5 个问法作输入），无反传，毫秒级。
- **防锁死**：白天每步有 1 个随机探索名额；夜里所有柱都重新评估（18.7）。这针对 E35 的教训：没被选中的模块状态不变、永远赢不回来。

### 18.6　离线元训练（一到两晚，主干冻结）

训练柱的慢部件、原型、树突段、调质核和规则系数。每条样本是一个“小人生”：

1. 会话甲：某个合成用户在某个领域里聊天，说出个人事实、用一个新词、表现出某种风格，并对回答给出肯定或纠正；
2. 清空上下文（A 保留）；
3. 会话乙：可能换领域，再回来；对甲里的内容提问、沿用新词、期待同样风格。

损失 = 会话乙里的回答词元（延迟提问监督）+ 会话甲中途的普通下一词元损失 + 很小的负载均衡项（防一根柱通吃）。梯度穿过整段两会话，所以学到的不是某条知识，而是**怎样一次就记住、记在哪根柱、什么时候该学**的规则。不给领域标签，分工只能由责任规则自己长出来。数据：SmolTalk 各子集、Cosmopedia 不同学科、SODA、本地模板记忆对话，按规则造出风格与反馈句。元训练时柱数固定为 8，不长柱；长柱只在使用时启用，由验证实验单独检验。

### 18.7　睡眠（每晚 10–20 分钟）

1. **全体重估**：当天日志让所有柱都跑一遍，更新损失统计与原型，人人都有机会重新被选中。
2. **级联渗透**：κ 调大，A_快 的内容渗进 A_慢。
3. **柱内巩固**（可选，有反传）：在每根柱自己责任高的日志片段上，用反传把 A_慢 的效果蒸馏进该柱的慢部件，同时对柱的早晨副本在自由生成的梦上做 KL 锚定（梦从换行处开始，不从白天片段续写，E36、E37）。之后 A_慢 缩小，腾出余量。
4. **稳态缩放**：所有 A_快 乘一个略小于 1 的数（突触稳态假说）。
5. **合并与修剪**：两根柱在日志上的预测分布很接近就蒸馏成一根；长期责任为零的柱删除。
6. **逐柱验收**：旧能力探针、新内容探针、换名反事实对照；按柱分别接受或回滚，一根柱出问题不必整晚作废；被接受的状态存档。

### 18.8　三种自我改进与记忆

| 需求 | 怎么实现 | 怎么测 |
|---|---|---|
| 知识 | 惊奇调制的误差纠正写入个人柱；睡眠时级联、巩固 | 教 N 条（10–500）后清空上下文提问；换问法；隔 1、3、10 个会话 |
| 能力 | 常聊领域长出专属柱，责任集中、写得多；被肯定的回答方式经 DA 加强 | 领域固定题的周曲线；其他领域题不下降 |
| 适应用户 | 用户柱族学着预测这个用户；DA 加强被认可的风格 | 对用户下一句的预测损失随会话下降；风格题命中率；去掉用户柱的对照 |
| 会话内记忆 | 主干上下文 + A_快 | 多轮指代题 |
| 跨会话记忆 | 存盘的全部柱 | 重启后提问 |
| 知道自己不知道 | 不确定头（自我模型）预测自己的损失 | 校准曲线；高不确定时回答“我不确定”的准确率 |

### 18.9　和大脑的对应

| 机制 | 大脑 | 简化之处 |
|---|---|---|
| 并列的柱、投票 | 千脑理论的皮层柱 | 语言里没有空间参考系，参考系换成原型向量 |
| 责任 = 预测误差决定谁学 | 小脑与运动皮层的 MOSAIC 模块选择 | 用最近若干词元的损失近似 |
| 资格迹 × 调质 | 三因子突触可塑性、多巴胺 / 去甲肾上腺素 / 乙酰胆碱 | 每种调质是一个标量 |
| 树突门 | 活性树突，按情境开关神经元 | 只挡读写幅度，不冻结状态 |
| 长新柱 | 齿状回成年神经发生 | 复制已有柱再分化 |
| 级联快慢突触 | Benna–Fusi 级联突触模型 | 只有两级 |
| 睡眠缩放、合并、巩固 | 突触稳态假说、系统巩固 | 离线批处理 |
| 用户柱 | 心智理论 | 只预测对方下一句 |
