## 18（续）　活柱网络：依据、假设、验证与风险

正文见 [18-live-columns.md](18-live-columns.md)。实验只写编号，数字在 [experiments/](../../experiments/README.md)。

### 18.10　核心假设

| 编号 | 假设 | 来自 |
|---|---|---|
| H1 | 元训练出的局部规则，在“教后清空上下文再考”上能补回“无记忆”与“事实仍在上下文”之间一半以上的差距，且不低于同参数量在线反传低秩的七成 | N2 |
| H2 | 不给标签时，按预测误差分配的责任能把领域分开，多领域依次学习的遗忘不超过“同总秩一整块低秩增量”的一半 | N4 |
| H3 | 合起来更好：同样会变的参数量下，“可塑柱群”的容量曲线（教 N 条后的正确率）和多领域遗忘都优于“单块可塑”与“柱群 + 反传” | 本章 |
| H4 | 遇到全新领域时长新柱，比挤进现有柱旧领域损失更小、新领域收益不低于九成 | N4 |
| H5 | 加奖惩调质 DA 后，达到同样偏好命中率所需的会话数少三成 | N2 |

### 18.11　依据

- 三因子规则与资格迹：Gerstner 等 2018（凭记忆）；本项目 E08、E09、E11 在小任务上验证过带滞后的痕迹能利用延迟反馈。
- 可学的可塑性：Miconi 等 2018、2019 Backpropamine（2019 摘要已核实）；SRWM 与元学习持续学习（[topics/cognition-selfimprove.md](../../literature/topics/cognition-selfimprove.md)、[cards/memory-workspace.md](../../literature/cards/memory-workspace.md) 第 8 张）。
- 写入目标对齐下一词元：In-Place TTT（[cards/memory-workspace.md](../../literature/cards/memory-workspace.md) 第 3 张）。
- 延迟提问监督：[cards/memory-workspace.md](../../literature/cards/memory-workspace.md) 第 7 张；E18、E23 显示不显式监督就学不会用记忆。
- 活性树突：Iyer 等 2022（摘要已核实）。
- 责任门控的模块选择：Wolpert 与 Kawato 1998、Haruno 等 2001（凭记忆）；千脑：Thousand Brains Project 2025（本地文献已核实）。
- 只更新被用到的部分可大幅减少遗忘：Sparse Memory Finetuning（[cards/sleep.md](../../literature/cards/sleep.md) 第 6 张）。
- 局部规则只放在快权重里：纯局部规则训练慢权重与反传差距大（[topics/learning-rules.md](../../literature/topics/learning-rules.md)）。本方案的慢参数（柱的慢部件、U、V、W、调质核）仍用反传，局部规则只改 A。
- 遗忘来自共享权重：E25、E29；锚定睡眠可提交：E31；做梦细节：E36、E37。
- 与本项目失败的关系：E30、E32（极小规模下模块多而小更差）和 E34、E35（工作空间无益、稀疏更新锁死）是在固定预算里**切分**主干；这里主干完整冻结，柱是**额外**容量，比较对象是同样增量参数的一整块。锁死用随机探索名额加夜间全体重估对付。
- 突触稳态：Tononi 与 Cirelli 2014；级联突触：Benna 与 Fusi 2016（凭记忆）。

### 18.12　验证顺序

前两步分别检验 N2、N4 各自最核心的假设，互不依赖，可以先做便宜的那个；两步都过才合并。

| 步 | 内容 | 对照 | 门槛 | 不过怎么办 |
|---|---|---|---|---|
| V1 规则（3–5 小时） | SmolLM2-135M 冻结，单层、单柱可塑块。合成“教一条事实或新词 → 插无关对话直到超出上下文 → 提问” | 无可塑块；固定系数赫布规则；事实仍在上下文（上界）；在线反传低秩 | H1 | 写入改纯 delta 形式重试一次；仍不过：可塑块只管风格适应，事实交给外部键值表 |
| V2 分工（4–5 小时） | Qwen2.5-0.5B 冻结，柱用反传学习（先不接可塑块）。四个领域（儿童故事、日常对话、科学讲解、代码问答）依次各约 200 万词元，不给标签 | 一整块秩 32；四柱人工按领域指定（上界）；四柱只用原型先验 | H2；柱—领域纯度高 | 只用原型过而责任不过：改纯原型路由；都不过：放弃免标签分工，柱改为按会话或按用户指定 |
| V3 合并（半天） | V1 的规则装进 V2 的柱：可塑柱群 vs 单块可塑（同样会变的参数量）vs 柱群 + 反传 | 三臂互比 | H3：容量曲线与遗忘都最好；每轮延迟低于柱群 + 反传 | 哪项不赢就保留赢的那半（单独的 N2 或 N4） |
| V4 长柱（半天） | V3 之后加第五个全新领域 | 不许长柱 | H4 | 调新柱阈值；仍不行就固定柱数 |
| V5 奖惩（一晚） | 20 个合成用户各有隐藏偏好并按偏好给反馈，各 10 个会话 | 无 DA 项；无用户柱 | H5；用户柱降低用户话预测损失 | 去掉价值头，适应只靠用户柱的自监督 |
| V6 完整元训练与睡眠（两晚） | 多层、8 根出厂柱的完整元训练；14 个模拟日夜，观察柱数是否稳定、合并是否无损、逐柱验收是否频繁回滚 | 不睡；只做缩放不做巩固 | 第 14 天旧能力探针不降、新内容保持过半 | 按回滚最多的步骤回查 |
| V7 真人两周 | 每天记录柱数、责任分布、A 的范数、旧能力探针、用户话预测损失 | — | 三种改进的曲线都向上 | — |

测量（与任务指标分开）：责任分布的熵与随时间变化；柱—领域纯度；长柱与修剪事件；各调质信号与用户反馈的相关；不确定头的校准曲线。

### 18.13　风险（按可能性排序）

1. **预测误差分不开语言领域**（V2）：各柱损失同涨同落，责任接近均匀，系统退化成一块大适配器。这是最大的赌注；失败本身是一条有价值的负面数据：千脑式投票能否用于语言。
2. **元训练的规则只在合成对话上有效，或退化成“什么都不写”**（V1、V6）：对策是会话乙里事实绝不出现在上下文，并给写入项设下限。
3. **小矩阵装不下精确事实**（电话号码这类长串）：退路是精确事实交给外部键值表（17-N1 的海马），柱只管能力、风格和用户模型。
4. **强者通吃**：一根柱越学越准、责任越来越大。负载均衡、探索名额、夜间重估三重对策；若仍通吃，记录条件（与 E35 同源）。
5. **奖惩信号太噪**：用户措辞里的隐式反馈信噪比低。V5 先用合成用户量出能否起作用。
6. **工程量**：两个机制叠加，元训练要穿过两段会话、4 根活跃柱，显存估计 5–6 GB，批要小。每个部件都要有“逐词元与整段一致”的测试。
7. **智力上限**：常识与推理由 0.5B 主干决定，不会因为柱和可塑性而变成大模型；本方案能比的是同一主干下记得多、忘得少、越用越懂这个用户。

失败也有收获：学出来的学习规则能否泛化；语言领域能否靠预测误差无监督分工；稠密可塑小矩阵能装多少事实；对话里隐式反馈有多少信号。
