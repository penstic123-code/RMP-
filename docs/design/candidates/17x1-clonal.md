## 17-X1　克隆选择记忆（Clonal）

借鉴领域：免疫系统（克隆选择、亲和力成熟、阴性选择、免疫记忆）。标注：[V] = 本次打开原文核实；[未核实] = 凭记忆或二手来源；“估算”= 未实测。

### 1. 一段话总述

用一个现成的小型对话模型（Qwen2.5-0.5B-Instruct，备选 SmolLM2-360M-Instruct）当“先天免疫”：它已经会说话、有常识，主干权重永远不动。在它上面养一群很小的“克隆”——每个克隆 = 一把识别钥匙（受体）+ 一小块低秩权重。用户教了新东西、或模型答错被纠正（“抗原”）时，当场造出几份候选克隆，各训几步，按“在没见过的改写问法上答得多好”选出最好的一份留下；留下前必须通过“阴性选择”：它不能对普通对话起反应。平时只有钥匙对得上的克隆才参与计算，其余完全不出声，所以旧能力在数学上不变。常被用到的克隆寿命变长、合并成更大的“领域克隆”；没用的被淘汰。参数在使用中当场改变，但改的是新长出来的局部参数，不是共享主干。

### 2. 借鉴的原理与对应关系

| 免疫学 | 本方案 | 类比还是真机制 |
|---|---|---|
| 先天免疫 / 自体 | 冻结的预训练主干 + 它自己生成的 512 段普通对话（“自体集”） | 真机制：自体集是验收用的固定数据 |
| 抗原 | 惊奇高的片段：用户陈述的事实、新词、纠正 | 真机制：以逐词元 NLL 超过滑动基线为触发 |
| 受体与结合 | 钥匙 r 与中间层隐状态 h 的余弦相似度过阈值 θ 才开门 | 真机制：门关时该克隆输出严格为 0（同 GRACE 的半径内才生效） |
| V(D)J 重组、体细胞高频突变 | 一次造 N 份候选：挂哪几层、秩、学习率、初值各不相同；胜者再加噪声变异一轮 | 半类比：就是小规模的群体超参与初值搜索 |
| 亲和力成熟（生发中心选择） | 按“留出的改写问法上的 NLL 降幅”选胜者 | 真机制：选择标准是泛化而不是训练损失 |
| 胸腺阴性选择 | 候选在自体集上的开门率须 <1%，开门处 KL(主干‖主干+克隆) 须 <δ，否则缩半径或销毁 | 真机制：把“不遗忘”变成造克隆时的硬验收 |
| 浆细胞 / 记忆细胞 | 新克隆先是短寿命；跨会话再次被命中且有用才转为长寿命 | 真机制：固定容量下的淘汰规则 |
| 二次应答更快更强 | 抗原再次出现且钥匙命中时，只在原克隆上追加几步、学习率更高 | 真机制，可测（见假设 H3） |

### 3. 结构与规模

- 主干：Qwen2.5-0.5B-Instruct，24 层、隐层 896、MLP 中间维 4864，约 4.9 亿参数，Apache-2.0 [未核实许可细节]。半精度约 1 GB 显存。
- 克隆：钥匙 r（896 维，取自第 ℓ_k 层在“问题末词元”处的隐状态）+ 半径 θ + 在 3 个中后层 MLP 上的秩 2 低秩对（每层约 1.15 万参数）≈ 3.6 万参数/个。容量上限 2,000 个 ≈ 7,200 万参数、半精度约 145 MB。
- 前向：每个词元算一次 h·R（2,000×896 的矩阵乘，可忽略），取相似度最高且过阈值的至多 4 个克隆，把它们的低秩输出加到对应 MLP 上。没有克隆开门时与原主干逐位相同。
- 另有一个“耐受克隆”（用户风格）：钥匙固定在助手回复起始处，常开，但只在空闲时更新，并受自体集 KL 预算约束。
- 每个克隆旁边存原始文字（教它的那句话 + 自动生成的问答），用于重训、合并、列出与删除。
- 显存：推理约 1.5 GB；造克隆时只反传到最低挂载层，N=8 份候选并成一个批，约 3 GB（估算）。吞吐：生成 40–80 词元/秒（估算）；一次初次应答 2–5 秒（估算），在用户读回复时后台完成。
- 离线准备不需要训练主干：生成自体集、标定 θ 与 δ，合计 1 小时内。

### 4. 学习方式

- **离线**：无主干训练。只做一次标定：在自体集和 200 条合成事实上扫挂载层与 θ。
- **使用时（当场改参数）**：
  1. 触发：用户轮的 NLL 高于基线，或出现纠正 / “记住”类说法。
  2. 自学材料：主干在上下文里看着这句话，自己写 4–6 条问答与改写（Cartridges 的 self-study 做法：直接对原文做下一词预测不如先生成对话再蒸馏 [V]）。留 2 条不参与训练，作亲和力测试。
  3. 钥匙未命中 → 初次应答：造 N=8 份候选，各训 6–10 步；按留出问答选胜者；过阴性选择才入库。
  4. 钥匙命中 → 二次应答：在原克隆上续训；若内容与旧文字冲突（猫改名了），旧文字作废、克隆重训。
- **空闲时（“生发中心”）**：
  - 合并：钥匙相近的克隆聚成一个更宽半径、秩 4 的领域克隆，用各成员存的问答重训；合并后须通过全部成员的留出问答，否则不合并。
  - 领域加强：按用户常聊话题，从本地语料（Cosmopedia、FineWeb-Edu）检索相近段落，训练该领域克隆。这是“能力”改进的数据来源。
  - 淘汰：统计每个克隆“开门时相对关门的 NLL 改善”，长期无用者删除。
- **防遗忘**：三道保证——门关时输出不变（结构保证）；阴性选择（造时验收）；每晚在自体集上回归测试，漂移超标的克隆缩半径。不依赖回放和锚定来保主干。

### 5. 三种自我改进与记忆：怎么实现、怎么测

| 需求 | 实现 | 测法 |
|---|---|---|
| 知识 | 事实 / 新词 → 记忆克隆 | 清空上下文后，用改写问法与间接问法提问的正确率；学完 N 条后最早那批的保持率 |
| 能力 | 常用话题的领域克隆 + 空闲时检索语料加强 | 该领域留出问答正确率与困惑度随使用天数的曲线；冷门领域作对照应不变 |
| 适应用户 | 耐受克隆学用户接受的回复风格 | 模拟用户带固定偏好（短答、称呼、口吻），测偏好遵守率 |
| 会话内记忆 | 主干上下文窗口（2k–4k 词元） | 同会话多轮指代题 |
| 跨会话记忆 | 克隆 + 其旁的原始文字 | 重启进程后提问；“列出你记得我的什么”；删除某条后应答不出（精确遗忘） |

### 6. 核心假设，以及为什么可能赢过普通 Transformer

- **H1（局部化）**：钥匙门控 + 阴性选择能让“一次讲述”的事实在改写问法上达到上下文内作答的 85% 以上，同时普通对话困惑度漂移 <1%，并在连续 1,000 条后仍成立。
- **H2（选择）**：同等算力下，“造 8 份、按留出问法选 1 份”比“只训 1 份、多训几步”在间接问法上更准。
- **H3（二次应答）**：同一领域第 k 次学新内容所需步数随 k 下降。
- 对比对象是“普通 Transformer + 在线微调”：本项目已见共享参数在线更新会严重遗忘（E25），只改低秩偏移时不忘但学得少（E29），睡眠要靠锚定才稳（E31、E33），做梦式巩固会削弱新内容（E36、E37）。本方案不在“学多少 / 忘多少”之间调旋钮，而是把新知识放在只对相关输入开门的新参数里，学习率可以放得很大。相对“冻结模型 + 检索进上下文”，它不占上下文、能合并成领域能力、能学风格——但在纯事实回忆上未必赢（见第 10 节）。

### 7. 主观成功概率

- 满足全部用户需求（会说话、有记忆、三种改进可测到）：**55%**。说话与智力由主干保证；知识与防遗忘有 GRACE、WISE 的先例。
- H1 成立：50%；H2 成立：30%（群体搜索可能只是浪费算力）；H3：40%。
- 整体明显优于“检索 + 每晚一个 LoRA”这一朴素基线：35%。

### 8. 依据

- 克隆选择算法 CLONALG（de Castro、Von Zuben，2002）与阴性选择算法（Forrest 等，1994）：人工免疫系统的两个经典算法 [未核实，凭记忆]。
- GRACE（Hartvigsen 等，NeurIPS 2023，arXiv 2211.11031）：离散键值码本、不改原权重、可做数千次连续编辑 [V 摘要；半径与层的细节未核实]。
- WISE（Wang 等，NeurIPS 2024，arXiv 2405.14768）：主记忆 + 旁路记忆 + 路由；直接改主参数与纯检索各有缺陷（可靠、泛化、局部三者难兼得）[V 摘要]。
- Cartridges（Eyuboglu 等，2025，arXiv 2506.06266）：self-study + 上下文蒸馏；原文下一词预测不如它 [V 摘要]。
- MoRA（arXiv 2506.21035，2025）：按秩一分量稀疏路由做持续学习 [只看了搜索片段]。检索未发现把克隆选择用于 LoRA 持续学习的论文（2026-11 检索，不能证明没有）。
- 本地文献：cards/sleep.md 第 6 卡（稀疏记忆微调：只改被访问的少数槽，遗忘远小于 LoRA）；topics/continual-sleep.md（SuRe、自生成回放的饱和问题）；cards/sleep-2.md 第 14 卡（换名反事实探针，直接用作亲和力测试）、第 13 卡（档案）；topics/chat-data.md。
- 本项目实验：E25、E29、E31、E33、E36、E37（在线与睡眠）；E18、E23（小模型从自然文本学不会复制名字 → 不从零训）；E35（硬竞争 + 冻结导致锁死 → 本方案的门只管新增参数，不冻结主干通路）；E38、E40（小规模下给新结构分参数会输 → 不动主干容量）。

### 9. 验证实验（按顺序）

1. **V1 连续 200 条事实（2–3 小时）**。数据：data/ 里模板记忆对话的事实 + 自动改写。对照组：A 完整方案；B 单个共享 LoRA 在线微调（学习率扫 3 档）；C 去掉阴性选择；D 只造 1 份候选；E 检索进上下文；F 事实直接放在上下文里（上界）。指标：学完即测与全部学完后的改写问法正确率；500 段普通对话上的困惑度漂移；自体集误开门率。门槛：A 末尾正确率 ≥ F 的 85%，漂移 ≤1%，比 B 的保持率高 30 个百分点以上。不过怎么办：正确率低 → 换钥匙层、把钥匙取在多个问法的均值上；漂移高 → 收紧 δ；若 A 比 E 低 10 个百分点以上 → 退成“克隆开门时把存的原文也放进上下文”的混合版，创新点缩小为“学出来的钥匙”。
2. **V2 选择消融**：A 对 D（同算力）。门槛：间接问法 +5 个百分点。不过 → 固定 N=1，删掉群体部分。
3. **V3 1,000 条 + 修订 + 删除**：含 100 条改值、50 条删除。门槛：旧值复现 <3%，删除后答对率回到学前水平；测 H3 的步数曲线。
4. **V4 能力**：选一个话题，空闲训练领域克隆；对照为不带门的同数据 LoRA。门槛：领域问答 +8 个百分点且普通对话漂移 ≤1%。
5. **V5 适应用户**：3 种模拟偏好，10 个会话后遵守率 ≥80%。
6. **V6 综合**：30 个模拟会话，容量打满后淘汰是否伤到常用记忆。

### 10. 最可能失败的地方，以及失败能学到什么

- **钥匙不可靠**：0.5B 模型的隐状态未必把“问的是同一件事”的不同问法聚在一起，漏开门则答不出，误开门则到处说猫的名字。学到：小模型隐空间能否支撑局部编辑，这也决定任何“参数内海马索引”类想法的可行性。
- **打不过检索**：纯事实回忆上，把原文检索进上下文又简单又准。若 V1 的 A 显著输给 E，说明“参数化记忆”在这个规模只对能力与风格有价值，事实应留在文字里。
- **单条事实过拟合**：几步训练可能只背住训练问法；H2 的选择机制就是为此设的，若 H2 不成立，这条风险没有解药。
- **合并伤记忆**：领域克隆合并可能丢掉成员事实；合并有逐成员验收，失败的代价只是不合并、容量吃紧。
