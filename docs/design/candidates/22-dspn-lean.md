## 22　DSPN 精简（v0.18 候选）：还能删什么，能力不丢

2026-11-20。用户要求：在 v0.17（XL 档，[current/1-runtime.md](../current/1-runtime.md)）上继续删，架构更简洁，能力保留。借 TraceCols（第 21 章）的惊讶定边界，保留 DSPN 有证据的机制。状态：C1–C4（删 1–5 与惊讶跃升分块）已实施为 v0.18（现行设计见 [current/1-runtime.md](../current/1-runtime.md)）；22.4 的把关已跑（E59：v0.18 过关；删中枢持平，待长间隔 MQAR）；新奇信号未做。经一次独立审查并修订（22.7）。

### 22.1　现状：v0.17 层外的部件与重叠

| 部件 | 作用 | 重叠 / 问题 |
|---|---|---|
| 中枢（4 头 delta，τ 300–30k 字节） | 会话内长程、按内容取回（键含字节嵌入） | 有证据：E21 加中枢 bpc −0.059；E34 中 2 模块去中枢差 0.05 |
| 窗口级广播 | 中枢读出按窗口送到所有层 | 从未单独验证；带来窗口循环、`T % bc_window` 约束、状态里的整数位置 |
| 滑窗注意力 | 原样照抄 | 无 |
| 分块路由 4 件套（余弦路由、压缩率损失、平滑、直通置信度） | 让边界可导 | 4 件只为一件事 |
| 预测头族（pred_self、pred_down，MSE） | 辅助学习信号（E51：pred_self −0.015，两者相近不叠加） | 需要“按均方值归一化”的防坍缩补丁（E45） |
| pred_detach 开关 | 原为惊讶门控的旁观模式 | 惊讶门控已删，成孤儿 |
| 冷启动评估 evaluate | 随机窗口、零状态 | 与流式评估并存；E47 已注明冷启动数不可比 |

### 22.2　主方案

**删 1：窗口级广播。** 连同窗口循环、广播投影、广播状态、训练里的窗口整除约束。会话级上下文由中枢逐拍提供（中枢之上的层已在用）。

**删 2：分块路由 4 件套 → 编码层惊讶定边界**（TraceCols 21.2，同 BLT 熵分块）。
- 编码层加一个预测下一字节的局部头，读 `h0.detach()`（不让辅助损失与主干冲突，E45 的教训），交叉熵，权重 0.1。惊讶 s_t = 该头对实际字节的负对数似然。
- 开块用**惊讶的跃升**而不是绝对值：s_t − s_{t−1} > θ 即从 t 开新块（BLT 的近似单调条件）。原因：随机串、数字表这类整段难预测的片段里，绝对惊讶每拍都超阈值，块数会超过 K，超出的边界全部并进第 K 块，窗口后段被压成一块（代码现状：DSPNLayered._run_chunked 的定长收集）；跃升条件下整段持续高惊讶不再逐拍开块。
- **最大块长 L_max = 3N**：当前块已累积 L_max 字节就强制开块，防止低熵长段（重复空格、缩进、套话）拖成上百字节的一块。会话边界也强制开块。
- θ 是模型里的 buffer，不是状态：训练时按“块率 1/N”用 EMA 追分位数原地更新（CUDA Graph 下可用），推理与评估时冻结。冷启动、零状态评估、`scale_state_` 清零都不影响它。
- 状态里保留：上一字节局部头的对数概率与惊讶 s_{t−1}（跨段算 s_t 和跃升要用）、当前块已累积的字节数（L_max 要用）、当前块的输出（块输出放回字节要用）。
- 删：路由投影 Wr、压缩率损失、平滑扫描、直通置信度、路由键状态。放回字节直接取所在块的输出。边界不需要梯度；编码层仍经消息、读出、解码层得到梯度。

**删 3：预测头族 → 编码层局部头。** pred_self、pred_down、PredHead、_predict 一并删。预测学习改为“预测外部字节”（交叉熵，无坍缩问题）。风险：E51 的 −0.015 来自 pred_self，按 22.4 消融把关，过不了就恢复 pred_self。

**删 4：pred_detach 开关。**

**删 5：冷启动评估。** 训练日志与 JSON 只报流式 bpc（预热后）；冷启动表现另由一致性测试与把关里的冷启动项看。

**新奇信号（fast-clean B3，原未实现）：** 用 OnlineLearner.read 已经算出的主模型损失，做成平滑门：在线学习率乘 sigmoid((L − L̄)/τ)，L 是句均值损失、L̄ 是它的 EMA（不存近 64 句、没有硬开关）；海马写入是二值决定，取门值 > 0.5。不用编码层惊讶——编码层看不到会话记忆，重复说过的事也会“惊讶”。于是两个信号各一个主人：编码层惊讶只管切块，主模型损失只管海马写入与在线学习门。

**合：在线学习二选一**（fast-clean B4，已排期）：低秩偏移或 e-prop，E31 协议比较后删输的。

### 22.3　不删的，和理由

| 部件 | 为什么留 |
|---|---|
| 中枢 | E21、E34 有 bpc 证据；键含字节嵌入，S 的键只来自 c，精确取回可能变弱。删中枢提前进本轮把关（22.4 的 D 组），不预先删 |
| 慢通道 c | 时间尺度层级在 c 的门上自发长出（E46）；e-prop 精确资格迹只对这种对角递推成立 |
| 快记忆的 delta 规则 | 覆盖同键旧内容（E20、E26） |
| 每层 2 个模块 | 证据弱（E32：1 个模块只差 0.011，在种子噪声内）；不删也不加，放大后再看 |
| 消息瓶颈 q=32 | XL 中相对 d=704 很窄，值得单测，不在本轮 |
| 滑窗注意力、读出接所有层 | 照抄名字；各层读出占比 0.21–0.38（E46） |
| 动态分块本身 | 依据是第 20.8 节的涌现目标与 E54 的速度（bpc 在 E54 里差 0.065，用户接受） |
| local 开关 | 用户要求学习规则可替换 |

### 22.4　把关（开工前写定）

配置：C 档结构缩小到约 200 万参数，mix 数据，1500 步，2 个种子（噪声约 0.013–0.02，E30、E51）。逐项消融，基线为 v0.17 去掉广播（删 1 证据为零、直接删）：

| 组 | 改动 |
|---|---|
| A 基线 | v0.17 − 广播（git 98885d5 的代码，`bcast=0`，保留 pred_self 0.01） |
| B | v0.18（删 2 + 删 3 一起；B 不过关再拆成两组找原因） |
| D | B − 中枢：块层各模块快记忆保持时长初值在 64 到 T/N 块步间对数铺开（`fm_tau`），省下的参数加到块层宽度 d，总参数与 B 持平 |
| E（可选） | B，局部头不停梯度、权重 0.01（预测后一字节同时给主干信号，对应 E51 pred_self 的小收益） |

| 指标 | 过关 |
|---|---|
| 流式 bpc | 不差于基线超过 0.03（用户接受略降） |
| MQAR（E28 协议） | 不低于基线 |
| 复制（随机串重复两遍，第二遍逐字节准确率） | 不低于基线 |
| 切词（边界落在空格 / 标点后的比例；训练全程块率、K 溢出次数） | 高于基准率；溢出 < 1% |
| 高熵段溢出（复制测试的随机串那一段单独统计 K 溢出与强制开块比例） | 不溢出（溢出即说明跃升条件失效） |
| 速度 | 不低于基线 |

| 涌现五项（第 20.8 节） | 时间尺度层级、自发切词、单元分工、复制相变、中枢分工都不明显差于基线（切词是 C2 最大的风险：边界由可学的路由改为预测器惊讶，“切”本身不再可学） |

另需测试：逐拍与整段一致、冷启动（零状态起读）有限且合理。不过关的组不合入。

### 22.7　独立审查后的修订（2026-11-20）

采纳：中枢保留（E21、E34 核实属实）；阈值改为冻结的 buffer；状态补上一字节对数概率与块输出；局部头读 detach 后的 h0；新奇信号改用主模型损失；pred_down 一并删；冷启动评估删；把关改为 2 种子、逐项消融、MQAR，加一致性测试；E57 的引用改正（分块依据是 E54 速度与涌现目标，E57 只证明 pre-norm）；M=2 的说法改弱。
未采纳：无。

第二次外部意见（2026-11-20，用户转来）。采纳：开块改为惊讶跃升（高熵段不再逐拍开块、溢出 K）；加最大块长 L_max = 3N；把关加“高熵段溢出”一项。未采纳：UTF-8 续字节掩码与分开统计（数据只有英文）；训练数据里加结构化重复（复制相变是主模型的能力，mix 本身有大量自然重复）；“局部头只看滑窗、退化为静态词频切分”（前提不对：h0 含慢通道 c 与快记忆 S，惊讶随上下文变）；前期边界抖动（由 1500 步把关直接看，不预先加补丁）。

第三次外部意见（2026-11-20，用户转来，“苦涩教训”视角）。采纳：删中枢提前进把关（D 组，删后为“滑窗注意力 + 线性递推”，与 Samba / Jamba 一类混合架构同形）；局部头不停梯度、小权重作可选 E 组；新奇信号改为平滑门（sigmoid(L − EMA)），去掉近 64 句中位数。已有：快权重往零回弹（在线低秩参数组带解耦权重衰减，online.py）。未采纳：去掉 θ 改固定阈值（局部头越学越准，惊讶从约 5.5 nats 降到 1–2，固定阈值下块率漂移、定长块序列溢出或浪费；θ 只定切多少，切在哪仍由数据决定）；改用相邻字节余弦切块（即刚删的 H-Net 路由，不带梯度时无意义，带梯度要请回四件套）；用主干预测误差定边界（边界依赖上层，必须逐拍串行）；用在线低秩快权重取代中枢（中枢与快记忆 S 的门控 delta 规则本身就是每拍对键值重构误差做一步梯度下降、带衰减的快权重，与 TTT-Linear 等价；秩 2、每句一次、要元学习，容量与速度都更差，E44、E50）；在线学习二选一按 E31 协议由数据定（e-prop 只依赖对角递推形式，加宽不用重推）。
