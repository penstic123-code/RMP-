## 21　迹柱网络 TraceCols v2：e-prop + 涌现，训练要快（净室候选）

2026-11-20。用户要求：以 e-prop 和涌现为核心，有对话、记忆、学习能力，不灾难性遗忘；训练快、迹省显存；部件不重复、不打架、不打补丁。按绝对能力验收，不和现行 DSPN 比。实现、迹的算法、提速与验证见 [21-tracecols-impl.md](21-tracecols-impl.md)。v1 原型（[tracecols.py](../../../tracecols.py)：逐字节多柱、软事件门、全参数迹）只作对照，v2 实现后替换它。本版已经过一次独立审查并按审查修订。

### 21.1　原则

1. **一种块、一个新奇信号、一条稳态规则。** 两级用同一种块；“值得学 / 值得存”只由新奇信号决定；路由负载与片段长度由同一条稳态规则调。
2. **只有赢家算，只有事件算。** 路由只让一个专家计算；上级只在下级的片段起点计算。
3. **迹只给衰减参数。** 衰减决定记多久，需要远超块长的信用，所以带跨块资格迹；其余参数在长块内拿精确梯度。迹显存因此等于状态显存。
4. **醒时只动权重，睡时才动结构。** 路由原型与各个稳态量醒时冻结，只在睡眠中更新，免得在线漂移把旧输入重新路由、重新切分。

### 21.2　结构

```
字节 x_t
 第 0 级（窄，d₀）：嵌入 → 编码块 ×N₀ → 局部头 h⁰ 预测下一字节 → 惊讶 s⁰_t
   边界：s⁰_t > 阈值（阈值是块前的滑动值），或片段已达最大长度 → 新片段从 t 开始
   每行每块的片段数有上限，到上限后不再开新片段（只看过去，因果）
 压缩：只取片段起点位置 → 第 1 级序列（长度约 1/5）
 第 1 级（宽，d₁）：块 ×N₁ → 局部头 h¹ 预测下一片段的前 4 个字节
 展开：第 1 级在片段起点的输出复制到本片段各字节位置，加第 0 级残差 → 解码块 → 下一字节
模型外：海马（新奇句原样存）、睡眠（重放 + 做梦）
```

- **因果。** 第 1 级在起点 p_j 只看到 x_≤p_j；展开只用片段起点，不用下一个边界位置，也不用片段长度。
- **块** = 时间混合 + 专家，各带残差与 RMS 归一化：
  - **时间混合**：多头线性矩阵记忆 S_t = γ_t·S_{t−1} + v_t k_tᵀ，读 o_t = S_t q_t；每头一个随输入变化的标量衰减 γ_t = σ(a·u_t + b_h)。各头衰减初值对数均匀铺开（本级 2 到 10⁴ 拍），同一机制覆盖短时复制、慢上下文，第 1 级的长衰减头就是会话级全局记忆。
  - **专家**：C 个专家 MLP，每拍只有一个计算。路由 = 输入与各专家原型的余弦相似度 + 稳态偏置，最大者胜。容量系数 1.25：超出容量的位置不进专家，只走残差。

### 21.3　每样东西只有一个主人

| 东西 | 唯一主人（谁写） | 谁读 / 用途 | 何时变 | 会话边界 |
|---|---|---|---|---|
| 记忆状态 S | 该级时间混合 | 本级读出 | 每拍 | 清空 |
| 衰减迹 E（与 S 同形） | 该级时间混合 | 跨块累进 b_h 的梯度 | 每拍 | 清空 |
| 惊讶 s⁰ | 局部头 h⁰ | 第 1 级边界；新奇 N 的来源 | 每拍 | — |
| 新奇 N（句级） | s⁰ 的句均值高于近 64 句的第 80 百分位 | 在线可塑门 M、海马写入 | 每句 | — |
| 边界阈值、路由偏置 | 稳态规则（目标边界率约 1/5；各专家负载均等） | 切分、路由 | 预训练中、睡眠中 | 保留 |
| 专家原型 | 竞争学习（胜者原型向输入移一小步，不求导） | 路由 | 预训练中、睡眠中 | 保留 |
| 海马条目 | 海马，N 高时写 | 召回读回、睡眠重放 | 写入时；睡眠中重编码键 | 保留 |
| 慢权重 | 优化器 | 模型 | 每次学习 | 保留 |

h⁰ 只看第 0 级、不依赖上级，是为了所有边界能在第 0 级一遍算完，上级再整段并行（若用解码器的惊讶定边界，各级就得逐拍串行）。

### 21.4　学习

- **规则**：Δθ = −η · M · g。g 来自“长块内反传 + 跨块衰减迹”；块长约 2048 字节（第 1 级约 400 步）。M：预训练恒为 1，上线后 = N。
- **学习信号**：每个预测器都预测外部字节，只是时间尺度不同。
  - 解码器：全部层级 → 下一字节（模型输出，自上而下）。
  - h⁰：第 0 级 → 下一字节（预测自身的输入流），误差即惊讶。
  - h¹：第 1 级 → 下一片段的前 4 字节。
  - 都是交叉熵，没有表示坍缩问题；局部头权重 0.1。
- **信用开关**：`global` 交叉熵贯穿两级（默认）；`local` 级间停梯度，每级只靠自己的局部头（局部学习对照，不作提速手段）。
- **明确的缺口**：写什么（Wk、Wv、衰减输入权重 a）只在块内（约 2048 字节）有信用，跨块只有“记多久”（b_h）有信用。给 a 带迹要“输入维 × 状态”的显存，违背原则 3，所以不做；长延迟测试按此设计（21.13）。
- **切分不是学出来的**：边界由惊讶决定（与 BLT 的熵分块同类），学出来的是预测器；“自发切词”指标量的是惊讶峰与词首是否自己对齐。

### 21.5　记忆与不遗忘

| 时间尺度 | 载体 |
|---|---|
| 字节到词 | 第 0 级短衰减头 |
| 词到会话 | 第 1 级各头（长衰减头即会话记忆，会话边界清空） |
| 终身原句 | 海马 |
| 永久 | 慢权重 |

不遗忘，每道防线管一件事：

| 防线 | 管什么 |
|---|---|
| 一专家路由 | 干扰：新内容落在少数专家上 |
| 醒时冻结结构（原则 4） | 漂移：旧输入的路由与切分不变 |
| 新奇门 M | 学什么：平淡输入只推进状态 |
| 睡眠：海马重放 | 新事实进权重（海马教皮层） |
| 睡眠：早晨模型做梦 + KL | 旧分布不漂移 |

后备：七天门槛不过时，再加元可塑级联（单次改动回落、反复改动下沉），它每个参数要多存两份。

### 21.6　海马与对话

- **海马**：N 高的用户陈述句原样存；键 = 句末第 1 级状态（归一化）。新句到来时按余弦取最相关的两条（超过阈值才取），以 `User: … / Bot: OK.` 格式读回到这句之前。睡眠时用当前权重重编码全部键，免得权重变了键过时。
- **路线**：
  1. 预训练：字节流，M = 1，状态一直延续，随机会话边界（训练里也见到零状态开场）。
  2. 对话微调：含延迟提问的记忆对话，交叉熵只算模型的话。
  3. 使用：按 N 学、写海马；/sleep 或定时睡眠。
- **规模**：本机上限约 1000–3000 万参数（稠密等效），能到“简单对话、记得用户的事”；开放域闲聊要大一个量级以上的数据与算力。

### 21.7　涌现指标（与同配置随机初始化比）

| 指标 | 量法 |
|---|---|
| 切词 | 惊讶边界与词首的精确率 / 召回，平均片段长度 |
| 时间尺度层级 | 各级学到的衰减换算成字节数，第 1 级 / 第 0 级之比 |
| 专家分工 | 胜出专家与字节类别、片段类型的归一化互信息；负载均衡度 |
| 单元分工 | 专家隐层单元的类别选择性；死单元比例 |
| 复制 | 随机串重复两遍，第二遍逐字节准确率 |

### 21.8　绝对验收（开工前写定）

| 能力 | 门槛 |

### 21.9　相对 v1 删掉或合并的

| v1 | v2 | 理由 |
|---|---|---|
| 慢通道 c 与快记忆 S 两套递推 | 合并为带衰减谱的矩阵记忆头 | 都是衰减累加器 |
| 独立中枢 | 第 1 级长衰减头 | 同一机制、同一时间尺度段 |
| 3 级逐字节运行 + 软事件门 | 2 级、硬边界压缩 | 软门不省算力；第 2 级等第 1 级过关后再考虑 |
| 柱按预测误差软竞争（全部柱都算） | 原型路由，只有胜者算 | 软竞争 C 倍算力只换一倍效果 |
| 柱内 k-WTA 与稳态阈值 | 删 | 与一专家路由重复，且不省算力 |
| 学习信号 self / down / ext 三选一 | 所有预测器都预测外部字节，各在自己的时间尺度上 | 无坍缩，分工清楚 |
| 信用 eprop / local / tbptt | global / local | 块内精确梯度 + 衰减迹 |
| 巩固标签、睡眠突触缩放、元可塑级联 | 删；级联留作后备 | 与醒时冻结 + 睡眠重叠 |
| 全参数资格迹 | 只给衰减参数 | 迹显存从“批 × 递推参数”降到“批 × 状态” |
