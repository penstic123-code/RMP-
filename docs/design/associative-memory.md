# 新架构设计：可持续学习的联想记忆网络（Associative Memory + RMP）

> **核心定位**：把 RMP 从 LLM 的残差流旁路移到**独立的联想记忆系统**里。记忆系统先决定「想起哪段经历、为什么相关、要不要继续想、何时停下」，小 LLM 只在最后作为语言接口负责自然表达。
>
> **核心原则**：预先规定网络怎样学习与计算预算；**具体应该联想到什么，完全由经历和训练信号决定**（绝不把“打雷 → 旺财”写死进规则）。

---

## 一、完整架构（5 大组件 + 3 项核心升级）

| 部分 | 负责什么 | 怎么更新 |
|---|---|---|
| **1. 事件记忆（Episodic Store）** | 保存日记/对话片段原文、时间戳、来源、事件 ID、冻结检索句向量（如 `bge-small-zh-v1.5`）及状态（active / superseded） | 随新经历即时写入；更正和删除通过事件 ID 精确生效 |
| **2. 稀疏联想图（Sparse Associative Graph）** | 每个事件维护最多 16 条候选连接（初始由「语义近邻 + 稀疏词法重叠 + 同日相邻」三路合并生成）；每条边附带相对时间差 $\Delta t$、新鲜度/覆盖标记与相似度特征 | 随新事件动态加边；网络根据当前语境动态打分，同一条边在不同场景权重不同 |
| **3. 循环回想（Iterative Recall）** | 保留原问题与已找到线索，每轮输出**残差悬念查询向量** $q_{t+1} = \text{Norm}(q_t + \Delta q(q_t, h_t, e_{\text{found}}))$，支持**沿图边扩展 + 跳出图全库重搜**双路候选（每轮保留 Top-4 路径、最多 3 轮）；配**独立二分类停机/拒答门控头（Sigmoid）**判断「还缺什么、是否继续或放弃」 | 从事件补全、跨事件补全、缺证/充分性判断、难负例与用户纠正中学习；反复验证有用的跳图路径在巩固时强化成图边 |
| **4. 巩固与抗遗忘（Consolidation / RMP）** | E1–E2 先用共享小网络验证循环回想本身有效；E3 将回想核替换为 **RMP 路由模块池 + SMF 掩码 + 历史回放**，验证持续学习保护旧关联 | 批量睡眠巩固；通过留存与误触发验收门控后才替换旧版本 |
| **5. 语言接口（Language Interface）** | 把最终选中的 0~2 条证据翻译成自然语言回复（小 LLM 或直接展示原文） | 与记忆网络完全独立迭代；E1–E3 期间关闭生成模型 |

## 二、学习信号来源（无硬编码规则）

| 信号 | 构造方式 | 训练目标 |
|---|---|---|
| **事件补全** | 遮掉事件中的名字、地点或结果，从残缺线索找回支持事件 | 线索不完整时的单跳定位 |
| **跨事件补全** | 找两条有原文支持的相关经历，输入仅暴露前一段线索，目标是找齐两条证据（第一批人工核验，训练/评测严格按主题与实体链隔离） | 把刚想起的桥接事件转化为下一轮悬念向量 $q_{t+1}$ |
| **缺证与充分性判断** | 仅给半条线索（如只找到「旺财怕雷」未找到照看安排）vs 证据已齐 vs 库中确实无后续记录 | 训练模型判断「我还缺什么」：缺证时继续找，齐了就停，库里真没有就停在已知事实或拒答 |
| **难负例与纠正** | 相似但无关的查询（如“拍闪电的相机设置”）、过期旧安排、证据不足题、用户负反馈 | 训练独立停机/拒答门控头，学会何时不联想、何时放弃旧关联 |

## 三、四阶段可证伪实验路线（E1 → E4）

### E1 · 验证多轮联想是否有真实增益（关闭 LLM，纯评事件 ID）
- **数据**：将 24 篇自然日记切分为带来源的事件库；保留原 6 题作冒烟参照，另建 4 类独立评测题：**直接回想 / 跨事件回想（省去桥接实体名）/ 相似但无关难负例 / 证据不足或已变更**。
- **对照（相同事件库、编码器与搜索预算）**：
  1. 一次语义检索（给足候选预算，避免因预算过小落败）
  2. 固定图两跳传播
  3. 普通两轮检索（第二轮根据首轮结果固定改写查询重搜全库）
  4. 可学习循环回想（主版：**图邻居 + 跳出图全库重搜**；消融：**纯图邻居版** / **纯全库重搜版**，区分图边与跳图增益）
- **必做因果消融**：**移掉桥接事件 vs 移掉无关事件**——若移桥后学习版显著掉分而移无关事件影响甚微，证明确实在利用中间线索。
- **指标**：双事件全中率（Exact Recall）、单事件命中率、无关题误唤起率（False Positive Rate）。

### E2 · 验证新经历能否接通旧经历（时间分批留出）
- 按日期分批写入事件，每批测 3 个时刻：① 写入前 → ② 写入后、训练前（仅加节点与候选边）→ ③ 巩固训练后（用未见过的新问法测新关联 + 重跑固定旧题）。
- 指标：新增关联命中率、旧题留存、最新事实命中率、无关题误唤起率。

### E3 · 验证 RMP 是否保护旧关联（`2×2` 严格消融）
- 同一个回想系统对比：**（共享网络 vs RMP）×（有回放 vs 无回放）**，对齐训练步数与活跃参数预算。
- 重点指标：**退步最多的那一批旧题（Worst-Batch Retention）**。RMP 真能少掉旧关联才保留，否则用更简单的共享网络。

### E4 · 接回小 LLM（验证表达与上限）
- 给同一个小 LLM 分别喂入：① 一次检索证据 / ② 循环回想证据 / ③ 人工 Oracle 正确证据。
- 对比日常闲聊自然度，区分“没想起”与“想起但小模型不会说”。

## 四、第一版硬验收标准与能力演进顺序

> **第一版验收标准**：一段新经历加入后，系统能从从未见过的新线索出发，经由它想起一段旧经历，并且在相似但无关的场景里知道主动停下来。

### 能力定位与优先级顺序（先实测，不预支结论）

- **机制上已具备**：
  - **记忆**：新经历即时存入，名字、时间、原话可按事件 ID 准确取回、更正与删除。
  - **学习**：训练改变网络如何选事件、如何更新悬念线索、何时停机（改变回想方式本身）。
  - **竞争**：多条候选路径争夺有限回想名额，“没有相关记忆”也是明确可选结果。
  - **回答前筛选相关信息**：例如「打雷，我担心家里」唤起旺财，「我想拍闪电」走另一路径或停机。
- **需由实验逐步验证与生长（严格按顺序）**：
  1. **跨事件合作（E1–E2）**：第二轮利用第一轮找到的线索，两段经历共同支撑答案；在无关场景主动停机。
  2. **抗遗忘（E2–E3）**：旧事件虽仍在库中，但新训练可能破坏召回通路；每批更新后必测旧经历召回率 + 改口后是否误把旧值当现状，并验证 RMP 模块分工是否减少旧通路退步。
  3. **真正的层级与高层涌现（E4 之后 / Phase 2）**：走两跳本身只是**搜索深度**而非层级；真正的层级是网络把反复共现的一组事件压缩成可复用的高层内部表征（如自发长出类似「宠物照看」的抽象概念），并学会在需要时从抽象表征回到具体经历。

## 五、实证结论与架构判决（参见 E111–E123）

- **已证实保留（当前最优通用主线）**：
  - **纯通用神经回想架构（v2.4，遵循「苦涩的教训」）**：删掉手工词法/IDF/MMR 标量特征，采用 **检索编码器顶 2 层轻量 LoRA（配语义锚定 + 难负例对比边界）+ 64K 参数 Pre-Norm Token 注意力 Transformer + 沿图/跳图双路束搜索**。实证全面反超手工特征版 v1：见 **E117–E119**（零主题泄露 E1 全面新高与纯因果依赖）、**E120–E121**（3 跳长链自适应深度 + 接回冻结 1.5B LLM 端到端追平 Oracle 且零串台）、**E123**（时间分批留出 E2 全批最新事实满分、零旧值泄露与旧题零退步）、**E115**（千条规模下双路融合同时反超纯图与纯全库，路径巩固硬化进图边兼得高召回与低延迟）。
  - **冻结小 LLM 仅作纯语言接口**：见 **E114 / E121**（表达缺口为 0%，与记忆系统完全解耦）。
- **已证伪/暂缓**：
  - 回想核替换为 RMP 路由池：见 **E113**（独立记忆架构的回想核学的是跨主题通用检索算子，共享核 + 回放即可近零遗忘，强拆专家反致冷启动碎片化；RMP 留给大尺度权重记忆线如 **E110**）。
  - 浅层/小样本高层表征节点（纯语义聚类、向量平均、1.5B 极短口号、12 主题 512 维独立投影头）：见 **E116 / E122**（纯语义聚类反增误触发，小样本独立投影过拟合，Phase 2 真层级抽象待更大规模干净抽象-具体配对数据）。
